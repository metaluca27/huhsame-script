🐞 무당벌레 형광펜

보고 있는 웹페이지에 무당벌레를 풀어놓으면, 문장을 따라 기어 다니며 형광펜을 칠하고 낙서를 남겨요. 무당벌레를 톡 치면 날개를 펴고 날아가요.

폰에서 아무 사이트에나 풀어놓기

  1. 아래 복사하기 버튼 누르기
  2. 크롬 ⋮ → ☆로 아무 페이지나 북마크 → 바로 수정
  3. 이름은 무당벌레, 주소(URL) 칸은 싹 지우고 붙여넣기 → 저장
  4. 풀어놓을 페이지에서 주소창에 무당벌레 입력 → 엔터 말고 목록에 뜬 ⭐ 항목 누르기
복사됐어요! (16,000자)
