■ 나좀봐는 이런 앱입니다
- 상대방의 말이 화면에 큰 글씨 자막으로 실시간 표시됩니다
- 사용자가 글을 입력하면, 미리 고른 '내 목소리'(남녀노소 8종 중 선택)가
  스피커로 대신 말해줍니다
- "천천히 말씀해 주세요", "글로 써주시겠어요?" 같은 자주 쓰는 문장을
  버튼 한 번으로 말할 수 있습니다
- 처음 만난 상대에게 "저는 소리가 잘 들리지 않아요. 이 화면에 대고
  말씀해 주세요" 안내를 전체 화면으로 보여주는 기능이 있습니다
- 소리가 나가는 동안 화면에 파형이 표시되고 진동으로도 알려주어,
  소리를 듣지 못해도 재생 상태를 확인할 수 있습니다
