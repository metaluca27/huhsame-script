요즘 유튜브에서 많이 보이는 'JEV 같은 판단 AI'를 제 윈도우 컴퓨터에 직접 깔아봤어요.
설치는 10분이면 되는데, **윈도우에서는 영상 속 명령어가 그대로 안 돼요.** 막히는 곳 세 군데와 해결법, 실제로 써보니 얼마나 맞히는지까지 정리해 둘게요.

저는 코딩을 못 하는 비개발자예요. AI(클로드 코드)한테 시키면서 했어요.

## 한눈에 요약

- 판단 AI = 문장을 주면 정해둔 칸 중 어디에 들어가는지 **확률로** 골라주는 작은 AI
- 모델: `tev1:0.8b` (용량 약 800MB), 올라마 **0.35 이상** 필요
- 운영비: **0원** (내 컴퓨터에서 돌아감)
- 정확도: 실제 유튜브 댓글 + 가짜 스팸 1개, **12개 중 9개** 맞힘
- 속도: 질문 하나에 처음엔 약 2.5초, 몇 번 돌리고 나면 0.1초 안쪽
- 윈도우에서 막히는 곳: ① curl 따옴표 오류 ② HTML 파일 더블클릭 시 접속 차단 ③ 질문 묶어 보내면 정확도 폭락

## 1. 설치 (윈도우)

1) 올라마 설치 또는 업데이트: ollama.com/download
2) 명령 프롬프트나 파워셸에서 버전 확인

```
ollama --version
```

0.35.0 이상이면 돼요. 저는 다섯 달 전에 깔아 놓고 잊은 게 있었는데 마침 0.35.0이었어요.

3) 판단 AI 받기

```
ollama pull tev1:0.8b
```

4) 확인

```
ollama list
```

목록에 `tev1:0.8b 811 MB`가 보이면 성공이에요.

⚠️ `ollama run tev1:0.8b`로 대화창을 열면 판단 결과가 안 나와요. 판단은 아래처럼 **요청을 보내는 방식**으로만 받을 수 있어요.

## 2. 막힌 곳 ① — 윈도우에서 curl 오류

영상 설명란의 curl 명령을 윈도우에 그대로 붙여넣으면 이런 오류가 나요.

```
{"error":"invalid character '\'' looking for beginning of value"}
```

영상 댓글에도 똑같이 막힌 분이 계셨어요.

**원인**: 명령어가 맥 기준이라서 그래요. 내용을 작은따옴표 `' '`로 감싸는데, 윈도우 명령 프롬프트는 작은따옴표를 따옴표로 안 쳐줘요. 작은따옴표까지 내용으로 보내 버려서 생기는 오류예요.

**해결법: 파워셸에서 아래를 통째로 붙여넣기** (직접 돌려서 확인한 명령이에요)

```
$body = @{ model = "tev1:0.8b"; state = "[YouTube comment] 코랩 3번째 칸에서 에러가 나요"; questions = @{ type = @{ type = "choice"; instructions = "What kind of YouTube comment is this?"; criteria = @{ question = "Asks how to do something"; error = "Stuck with an error and needs help"; thanks = "Thanks or support"; spam = "Ads or unrelated" } } } } | ConvertTo-Json -Depth 5
$r = Invoke-RestMethod -Uri http://localhost:11434/v1/systemone -Method Post -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
$r.answers.type | ConvertTo-Json
```

결과는 이렇게 나와요.

```
"choice": "error",
"probabilities": { "error": 0.959, "question": 0.021, "spam": 0.011, "thanks": 0.010 },
"confidence": 0.846
```

→ "에러 문의일 확률 96%". 한글이 깨지지 않게 `UTF8.GetBytes` 부분을 꼭 넣어 주세요.

## 3. 실제로 얼마나 맞히나 — 유튜브 댓글 12개 테스트

그 영상에 달린 진짜 댓글 11개에, 제가 만든 가짜 스팸 1개를 섞었어요.
분류 칸은 질문 / 에러 / 감사 / 스팸 네 개예요.

| 댓글 | AI 판단 | 결과 |
|---|---|---|
| 넣었더니 이런 오류 메시지가 떠요 | 에러 96% | ✅ |
| 컴퓨터 사양 추천 부탁드려요 | 질문 91% | ✅ |
| LM 스튜디오에서는 힘든가요? | 질문 88% | ✅ |
| 강의 퀄리티 와우, 감사합니다 | 감사 88% | ✅ |
| 최고🎉 진짜 최고입니다 | 감사 83% | ✅ |
| 감기 조심하세요! | 질문 49% | ❌ (인사인데) |
| 보고 따라하기 어렵다 | 에러 58% | 🤔 애매 |
| 부업으로 월 300… 링크 클릭 (가짜 스팸) | **질문 91%** | ❌ |

**12개 중 9개 정답.** 애매한 건 확률이 낮게 나와서 "사람이 볼 것"으로 거르면 돼요.
문제는 **스팸을 91%나 확신하면서 틀린 것**이에요. 작은 모델이라 아직 삭제 같은 건 맡기면 안 돼요.

## 4. 막힌 곳 ② — 정확도 올리는 요청법 3가지

이건 클로드가 여러 번 실험해서 찾았어요. 정확도 차이가 꽤 커요.

**① 메시지는 한 줄 글로 보내기**
- ❌ `"state": {"sender": "...", "subject": "...", "body": "..."}` → 칸을 나눠 주니 거의 다 틀림
- ⭕ `"state": "[Email] 안녕하세요 OO브랜드입니다. 협찬 가능할까요?"` → 잘 맞힘

**② 질문은 한 번에 하나씩**
- 질문 다섯 개를 한 요청에 묶었더니 모든 메시지를 "질문"으로 판단했어요.
- 하나씩 따로 보내니 제대로 나왔어요.

**③ 선택지 설명은 영어로, 자세하게**
- 짧게: `"Sponsorship or business offer"` → 협찬 메일 68%
- 자세히: `"Business proposal, sponsorship, collaboration or lecture invitation"` → **99%**

참고로 '예/아니오형(noul)'과 '점수형(score)' 질문도 되는데, 점수형은 확신도(confidence)가 늘 0.05~0.35로 낮게 나와서 기준으로 쓰기 어려웠어요. "얼마나 급한가?" 같은 건 거의 찍기 수준이었어요.

## 5. 막힌 곳 ③ — HTML 파일을 더블클릭하면 접속이 막힘

영상 프롬프트로 화면(HTML 파일)을 만들어서 더블클릭으로 열면, 올라마가 보안 때문에 접속을 막아요.

**해결법**: 그 폴더에서 아래 명령으로 작은 웹서버를 띄우고, 브라우저 주소창에 `http://127.0.0.1:8787` 을 넣어 여세요.

```
python -m http.server 8787 --bind 127.0.0.1
```

`localhost`나 `127.0.0.1`로 열면 올라마가 기본으로 허락해 줘요. 윈도우 환경변수(OLLAMA_ORIGINS)를 바꾸는 방법도 있지만, 컴퓨터 설정을 건드리는 거라 이 방법이 더 간단해요. 저는 이 명령을 `.bat` 파일로 만들어서 바탕화면에서 더블클릭으로 열어요.

## 6. 제가 만든 것 — 우편함 분류 사무실

영상 프롬프트를 제 상황에 맞게 바꿔서, 유튜브 댓글·카톡 문의·이메일을 분류하는 화면을 만들었어요.

- 질문 1: 어떤 메시지? (질문 / 문제 신고 / 응원 / 제안·협찬 / 스팸)
- 질문 2: 질문이면 → 무엇에 대한 질문? / 문제면 → 돈이 걸렸나? / 제안이면 → 얼마나 구체적인가?
- 확신이 50% 아래면 → 사장(나)에게 넘김

【캡처: 사무실 전체 화면】

영상 속 비교표에서 클로드는 "강화학습 기능 ❌"였어요. 그래서 이 기능을 넣어 달라고 따로 요청했어요.
- 👍 / 👎 + 정답을 고르면 → 틀린 선택지엔 벌점, 정답 쪽엔 보상 점수를 줘요. 다음 판단 확률에 이 점수가 반영돼요.
- 비슷한 문장을 전에 사람이 정해준 적 있으면 → 그 답을 따라가요.

**결과**: 처음엔 사장 결재 대기가 20건까지 쌓였어요. 18번 가르친 뒤에는 92통을 처리하는 동안 대기 0건이 됐어요.

**주의할 점 (직접 겪음)**
- 학습 점수가 AI가 이미 맞힌 답까지 깎을 수 있어요(89% → 76%). AI가 80% 이상 확신할 땐 학습을 적용하지 않게 고쳐서 해결했어요.
- 이건 모델 자체를 다시 훈련하는 게 아니에요. 판단 위에 점수를 얹는 방식이에요.

## 자주 물어볼 만한 것

**Q. 컴퓨터 사양이 좋아야 하나요?**
제 미니PC(램 26GB, 내장 그래픽 AMD 780M)에서 문제없이 돌아갔어요. 모델이 800MB라 가벼워요.

**Q. LM 스튜디오에서도 되나요?**

**Q. 이걸로 진짜 회사 일을 자동화할 수 있나요?**
분류까지는 쓸 만해요. 다만 이 화면은 메일이나 댓글을 자동으로 읽어오지 않아서, 메시지를 직접 붙여넣어야 해요. 그리고 스팸을 자신 있게 틀린 적이 있어서 삭제·결제 같은 건 사람이 확인하는 게 맞아요.
