# [삽질일지] 심사 넣고 까먹었더니 크롬 확장이 출시돼 있었어요 — 개발 몰라도 웹스토어에 올린 순서

제가 만든 크롬 확장 프로그램이 크롬 웹스토어에 올라가 있었어요.
문제는 만든 제가 몰랐다는 거예요.

심사를 넣고 다른 일을 하다 까맣게 잊었어요.
오늘 다른 작업을 하다가 스토어 주소를 열어 보니 이미 공개돼 있더라고요.
바로 설치했고, 사용자 수에 1이 찍혔어요. 그 1명이 저예요.

📷 [여기에 사진: 스토어 화면 캡처 — 무당벌레 형광펜, Remove from Chrome, 1 user]
(사진 설명: 첫 사용자는 만든 사람)

## 한눈에 요약

- 만든 것: 웹페이지를 기어 다니며 형광펜을 칠하는 무당벌레
- 저는 개발을 배운 적이 없고, AI와 함께 만들었어요
- 등록비: 5달러 (개발자 등록할 때 결제)
- 제 경우 10월 30일에 제출했고, 스토어에는 10월 31일 업데이트로 표시돼요
- 제일 헤맨 곳: 인증 메일이 스팸함으로 갔어요

⚠️ 제가 2026년 10월에 겪은 내용이에요. 심사 기간과 화면은 달라질 수 있으니 공식 안내를 꼭 확인하세요.

## 1. 왜 만들었냐면요

남이 만든 거미 확장 프로그램 소개 글을 보다가 생각했어요. 나는 무당벌레로 해 봐야지.
풀어놓으면 문장을 따라 꼬물꼬물 기어 다니면서 형광펜을 칠하고, 톡 치면 날개를 펴고 날아가요.

쓸모보다 재미로 만든 건데, 강의에서 먼저 써먹었어요.
수업 중에 집중이 흐트러질 때 풀어놓았더니 수강생분들이 "저게 뭐야?" 하면서 엄청 재밌어하셨어요.

📷 [여기에 사진: 글 위를 기어 다니는 무당벌레 화면]

## 2. 폰에서 돌리려다 며칠 날렸어요

여기가 진짜 삽질이었어요.
폰 크롬은 확장 프로그램을 지원하지 않아요. 그래서 북마크로 돌려 보려고 했어요.

- 카톡으로 긴 코드를 옮기다 잘렸어요
- 폰 크롬 주소창에 북마크가 아예 안 떴어요
- 삼성 인터넷에서도 안 됐어요

결국 포기하고, 폰에서는 데모 페이지에서만 놀 수 있게 정리했어요.
안 되는 걸 붙들고 있기보다 빨리 접는 것도 실력이더라고요.

## 3. 스토어에 올린 순서

처음부터 올릴 생각은 없었어요.
앱 커뮤니티 운영자님이 "보고 있는 페이지엔 어떻게 풀어요?"라고 물어보신 게 계기였어요.
그 전까지는 저만 쓰는 방식이라 남들은 설치할 수 없었거든요.

제가 한 순서는 이래요.

1. 확장 프로그램 파일을 압축 파일(zip) 하나로 묶기
2. 크롬 웹스토어 개발자 대시보드에서 개발자 등록, 5달러 결제
3. 연락 이메일 인증
4. 압축 파일 올리기
5. 스토어 설명, 카테고리, 언어 입력
6. 스크린샷(1280×800)과 작은 홍보 이미지(440×280) 올리기
7. 권한을 왜 쓰는지 설명 적기
8. 개인정보처리방침 페이지 주소 넣기
9. 심사 제출, 통과하면 자동 공개로 체크

💡 설명 문구와 개인정보처리방침은 AI에게 초안을 맡겼어요. 그래도 "이 확장이 실제로 뭘 하는지"는 제가 직접 확인해야 해요.

📷 [여기에 사진: 스토어 소개 화면 또는 등록 자료]

## 4. 헤맨 곳 두 가지

**인증 메일이 스팸함으로 갔어요.**
받은편지함에는 안 보였어요. 메일이 안 오면 스팸함부터 보세요. 인증 링크는 유효 시간이 짧으니 바로 눌러야 해요.

**자동 공개를 켜 두고 잊어버렸어요.**
통과하면 알아서 공개되게 해 둔 건 편했어요. 그런데 결과를 챙겨 보지 않으니 제 앱이 나온 줄도 몰랐어요. 심사를 넣었다면 스토어 주소를 며칠에 한 번씩은 열어 보세요.

## 5. 해 보니 이랬어요

거창한 앱만 스토어에 올라가는 줄 알았어요.
그런데 문장 따라 기어 다니는 무당벌레도 올라가더라고요.

개발을 몰라도 AI와 함께라면, 5달러와 약간의 삽질로 내 확장 프로그램을 낼 수 있어요.
저는 꼭 필요한 권한만 달았고, 왜 필요한지도 설명에 적었어요.
