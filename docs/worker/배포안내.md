# my scan2677 — 백엔드 배포 안내 (비개발자용)

이 문서는 `worker.js`를 실제 서버(공용 Cloudflare Worker `small-recipe-9345`)에 반영하는
방법을 순서대로 설명합니다. 화면 캡처 없이 텍스트로만 안내하니, 순서대로 천천히 따라 하시면 됩니다.

이 작업으로 `/scan`(my scan2677 글자 스캔)이라는 새 기능만 "추가"됩니다. 기존에 잘 쓰고 있는
메디앱(/triage, /hospitals), 전통시장 앱(/recipe), 심연의 타로(/tarot)의 코드는 한 글자도
바뀌지 않았으니 안심하고 진행하셔도 됩니다.

---

## 1단계. GitHub에 새 코드 반영하기

1. 웹 브라우저에서 GitHub 저장소 페이지로 이동합니다:
   `https://github.com/metaluca8560/metaluca8560`
2. 저장소 안에서 `medi` 폴더 → `server` 폴더 → `worker.js` 파일을 클릭해서 엽니다.
3. 화면 오른쪽 위에 있는 연필 모양 아이콘(편집, Edit this file)을 클릭합니다.
4. 편집 화면에서 코드 전체를 선택합니다.
   - 코드 박스 안을 한 번 클릭한 뒤, 키보드에서 `Ctrl + A`를 눌러 전체를 선택하고,
     `Delete` 키를 눌러 기존 내용을 모두 지웁니다.
5. 이 작업 폴더의 `docs/worker/worker.js` 파일을 열어 내용 전체를 복사한 뒤,
   방금 비운 편집 화면에 그대로 붙여넣습니다.
   - 파일 위치: `C:\Users\atlia\Desktop\huhsame-script\docs\worker\worker.js`
   - 메모장이나 VS Code 등으로 이 파일을 열어서 전체 선택(Ctrl+A) → 복사(Ctrl+C) 하시면 됩니다.
6. 화면 아래로 스크롤하면 "Commit changes" 버튼이 있습니다. 커밋 메시지는 기본값 그대로 두거나
   "tarot 엔드포인트 추가"처럼 짧게 적고, **Commit changes** 버튼을 클릭합니다.

이제 GitHub 저장소에는 새 코드가 반영되었습니다. (이 저장소 자체는 실제 서버가 아니라
"코드 보관소" 역할이라, 이 단계만으로는 아직 실제 앱이 바뀌지 않습니다. 다음 단계가 진짜 배포입니다.)

## 2단계. Cloudflare에 실제로 배포하기

1. 웹 브라우저에서 `https://dash.cloudflare.com` 으로 이동해 로그인합니다.
2. 왼쪽 메뉴에서 **Workers & Pages**를 클릭합니다.
3. 목록에서 `small-recipe-9345` 워커를 클릭해서 들어갑니다.
4. 상단 또는 우측에 있는 **Edit code** (또는 "Quick edit") 버튼을 클릭합니다.
5. 코드 편집 화면이 열리면, 기존 코드 전체를 선택합니다.
   - 코드 영역을 클릭한 뒤 `Ctrl + A`로 전체 선택 → `Delete`로 삭제합니다.
6. 1단계에서 GitHub에 올린 것과 동일한 내용(`docs/worker/worker.js` 전체)을 다시 붙여넣습니다.
   - 이미 복사해 둔 내용을 그대로 붙여넣으셔도 되고, GitHub에 반영된 새 파일 내용을 다시
     복사해서 붙여넣으셔도 됩니다. 둘은 동일한 내용이어야 합니다.
7. 화면 우측 상단의 **Deploy** (또는 **Save and deploy**) 버튼을 클릭합니다.
8. "Deployment successful" 같은 성공 메시지가 뜨면 배포가 끝난 것입니다.

## 3단계. 배포 후 확인하기

### 기존 앱이 정상 동작하는지 먼저 확인해 주세요

- **메디앱**: 평소 쓰던 문진(증상 안내) 기능을 한 번 실행해서 답변이 정상적으로 오는지 확인합니다.
  또한 병원 찾기(위치 기반) 기능도 한 번 눌러서 목록이 뜨는지 확인합니다.
- **전통시장 앱(우리 시장 가자)**: 요리 추천 기능을 한 번 실행해서 평소처럼 추천 결과가
  나오는지 확인합니다.

위 두 가지가 배포 전과 똑같이 잘 동작하면 성공입니다. 코드는 기존 기능을 건드리지 않고
새 기능만 추가했기 때문에, 정상적으로는 아무 변화 없이 그대로 동작해야 합니다.

### /scan 새 기능 테스트

`/scan` 자체의 실제 호출 테스트(사진 글자 인식이 잘 되는지)는 이 작업을 요청한 컨트롤러 쪽에서
별도로 진행합니다. 사용자께서는 위의 "기존 앱 정상 동작 확인"까지만 해 주시면 됩니다.

## 혹시 문제가 생기면

- 붙여넣기 전에 실수로 기존 코드를 다 지우고 저장했는데 새 코드를 못 붙여넣은 경우,
  Cloudflare 편집 화면에서 새로고침하지 말고 다시 `docs/worker/worker.js` 내용을 붙여넣고
  Deploy를 눌러 주세요.
- 배포 후 기존 앱이 이상하게 동작하면, GitHub 저장소의 커밋 기록(History)에서 이전 버전의
  `worker.js` 내용을 확인해 그대로 Cloudflare에 다시 붙여넣고 Deploy하면 이전 상태로
  되돌릴 수 있습니다.
