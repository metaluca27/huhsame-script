# 3편 「비 오는 다락방」 가사 초안

모델: Popcorn 3.0 Pro (245cr/곡). 루카 취향(감성·소울, 76~80 이하 템포) 반영, 2편 고음 교훈 반영.
모든 스타일 끝에 공통 문장:
> Warm mid-range vocals, no high belting and no vocal ad-libs. The beat keeps playing continuously from start to finish, with no stops, pauses, or silent breaks between sections.

흐름: 비 시작 → 담요 요새 → 회색 하늘 따뜻한 방 → 코코아 → 빗소리랑 대화 → 비 그친 뒤
