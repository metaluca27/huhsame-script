# 숏츠 고정 댓글 달기 (2026-10-24)

**설명란 링크는 이미 다 들어가 있어요.** 빠진 건 **고정 댓글**뿐이에요 (여태 한 번도 안 달았어요).

숏츠는 설명이 접혀 있어서 펼쳐 보는 사람이 거의 없어요. 그래서 링크가 있어도 안 눌린 거예요.
댓글창은 열어 보는 사람이 훨씬 많으니, 고정 댓글이 롱폼으로 가는 진짜 길이에요.

| 편 | 숏츠 합계 | 롱폼 | 전환 |
|---|---|---|---|
| 1편 | 3천 | 20회 | 0.6% |
| 2편 | 3.7천 | 6회 | 0.16% |
| 11편 | 2.2천 | 118회 | 5% |

## 다는 법 (PC 기준)
1. 숏츠 재생 화면 **오른쪽 세로 아이콘** 중 **말풍선(댓글)** 을 누름
2. 댓글창 맨 위 입력칸에 아래 문구를 쓰고 올림
```
허허, 이 뒤가 궁금하시거든 여기서 전체를 보시게. ▶ (링크)
```
3. 올라간 **내 댓글에 마우스를 올리면** 오른쪽에 **⋮** 가 생김
4. **"고정"** 누르기

※ 댓글을 먼저 달아야 고정 메뉴가 생겨요. 영상 자체의 ⋮ 메뉴에는 고정이 없어요.
※ 예약 중인 영상에는 못 달아요. 공개된 날 달아 주세요.
