# 비개발자의 역습 1편 — 루릭 내레이션 대본

화자: 루릭(네다섯 살 톤). 집사(루카)를 옆에서 지켜본 관찰담.
형식: 세로 숏츠, 문장 1개 = 그림 1장. 그림엔 글자 없음(자막은 캔바).

| 번호 | 내레이션 | 장면 (그림 설명) |
|---|---|---|
| 01 | 우리 집사는 코딩을 1도 몰랐다. | 스틱피겨 집사가 물음표 잔뜩 띄우고 멍하니 서 있음. 옆에 낙서 고양이 루릭 |
| 02 | 진짜다. if문이 뭐냐고 물으면 "국어사전에 있나?" 하던 사람이다. | 집사가 두꺼운 사전을 뒤적이고, 루릭이 어이없는 표정 |
| 03 | 어느 날 집사가 시커먼 화면을 열었다. | 노트북 화면이 새까맣고 집사는 놀란 눈 |
| 04 | 하얀 막대기 하나만 깜빡이는 그 창. 개발자만 쓴다는 그거. | 검은 화면 한가운데 하얀 세로 막대 하나, 나머지는 텅 빔 |
| 05 | 집사는 뭘 잘못 누르면 컴퓨터가 터지는 줄 알고 한참을 노려보기만 했다. | 집사가 땀 뻘뻘 흘리며 키보드 위에 손을 띄운 채 얼음. 머리 위 폭발 상상 말풍선 |
| 06 | 나는 옆에서 하품했다. 저러다 잠들겠다 싶었냥. | 루릭이 크게 하품, 집사는 여전히 얼음 |
| 07 | 근데 집사가 딱 한 마디를 쳤다. "이게 뭐야?" | 집사가 손가락 하나로 키 하나 누름, 화면에 물음표 하나 |
| 08 | 그랬더니 화면이 대답을 했다. 하나씩, 차근차근. | 검은 화면에서 말풍선이 줄줄이 나옴, 집사 눈이 동그래짐 |
| 09 | "왜 안 돼?" 하면 같이 원인을 찾아줬다. | 집사와 화면 속 로봇 낙서가 같이 돋보기 들고 벌레(버그) 찾는 중 |
| 10 | 학교 공부랑 달랐다. 필요할 때, 필요한 만큼만. | 왼쪽엔 두꺼운 교과서 더미에 X, 오른쪽엔 작은 조각 하나에 동그라미 |
| 11 | 그렇게 집사는 첫 게임을 만들었다. 60초 스와이프 게임. | 폰 화면에 큰 화살표, 집사가 손가락으로 스와이프, 머리 위 초시계 |
| 12 | 심지어 나랑 푸름이가 캐릭터로 나온다. 잘한 선택이다. | 폰 화면 안에 낙서 고양이 두 마리(귀 큰 루릭, 둥근 푸름이), 루릭이 엄지 척 |
| 13 | 신나서 카톡방에 링크를 올렸는데, | 집사가 폰 들고 신나서 점프, 폰에서 종이비행기 날아감 |
| 14 | 미리보기가 그냥 하얀 화면이었다. 아무도 안 눌렀다. | 채팅 말풍선 안에 텅 빈 흰 네모, 주변에 눈 감은 사람들 |
| 15 | 공유 버튼은 눌러도 반응이 없었다. 집사 얼굴도 하얘졌다. | 집사가 버튼을 쿡쿡 눌러도 아무것도 안 나옴, 집사 얼굴 하얗게 질림 |
| 16 | 그래도 집사는 하나씩 물어보고 하나씩 고쳤다. | 집사가 망치 들고 체크리스트 항목에 하나씩 체크 |
| 17 | 나는 옆에서 쭉 지켜봤다. 응원은 안 했다. 고양이니까. | 루릭이 상자 안에 앉아 무표정하게 구경, 집사는 뒤에서 열심히 |
| 18 | 그러다 정신 차려보니, 앱이 여덟 개가 돼 있었다. | 집사 주변에 폰 아이콘 여덟 개가 둥둥, 집사 본인이 제일 놀람 |
| 19 | 게임, 전통시장 안내 앱, 타로 카드 앱, 여행 번역기까지. | 아이콘 네 개 클로즈업: 화살표, 시장 천막, 타로 카드, 말풍선 두 개 |
| 20 | 집사는 밤마다 검은 화면이랑 수다를 떨었다. | 달과 별 아래 집사가 노트북이랑 마주 앉아 말풍선 주고받음 |
| 21 | 물론 다 잘 된 건 아니다. | 집사 머리 위 먹구름 하나 |
| 22 | 애드센스한테 거절당했다. 또 거절당했다. 또 거절당했다. | 편지봉투 세 개에 큼직한 X 세 개, 집사 어깨 축 |

| 24 | 여기까지 보고 하나만 말하겠다. | 루릭이 화면 정면을 보고 앞발 하나 들고 있음 |
| 25 | 코딩 몰라서 못 할 것 같다고? 우리 집사가 딱 그 생각을 했었다. | 과거 집사 스틱피겨가 물음표 안고 쭈그려 앉음 |
| 26 | 근데 되더라. 진짜 되더라냥. | 집사가 두 팔 번쩍 들고 서 있고, 뒤로 앱 아이콘들이 무지개처럼 |
| 27 | 다음 편은 그 첫 게임에서 집사가 삽질한 얘기다. | 집사가 삽 들고 구덩이 파는 중, 구덩이 안에 폰 |
| 28 | 구독하고 기다려라. 집사 대신 내가 부탁하는 거다. | 루릭이 앞발로 종 모양 낙서를 두드림, 집사는 뒤에서 꾸벅 |
