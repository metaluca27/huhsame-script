# 비개발자의 역습 4편 — 포토샵 없이 배경을 코드로 지운 사람 (루릭 내레이션 대본)

화자: 루릭(네다섯 살 톤, excited). 집사(루카)를 옆에서 지켜본 관찰담. 3편 예고("포토샵 없이 캐릭터 배경을 코드로 지운 얘기")의 후속.
형식: 세로 숏츠, 문장 1개 = 그림 1장. 그림엔 글자 없음(자막은 build.py subs).
원문: docs/비개발자의역습.md "캐릭터 배경을 코드로 지운 사람" 에피소드.
