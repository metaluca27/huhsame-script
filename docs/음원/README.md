## 내레이션 밑에 깔 때

원본이 -13~-16 LUFS라 목소리와 부딪힌다. **-28 LUFS로 낮춰서** 쓴다.

```bash
ffmpeg -i 원본.wav -af loudnorm=I=-28:TP=-2:LRA=7 -ar 44100 배경음.wav
```
