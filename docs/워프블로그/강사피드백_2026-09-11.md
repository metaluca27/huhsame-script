## 전체 공통 결론 (강사 마무리)
1. **포지션 미정인 사람이 너무 많다.** 줍줍으로 최종적으로 무슨 이익을 얻을지 정해라.
2. **링크 활용 제대로 못 하고 있다.** 제휴는 쿠팡으로 바로, 브랜딩은 하다못해 전자책 링크라도.
3. **링크는 3곳**: 시작 부분 하나, 중간 하나, 맨 끝 하나. 사람들이 끝까지 스크롤 안 한다.
4. 제목은 사람들이 검색하는 키워드를 **맨 앞에**. "캔바로 ○○" 말고 "○○ 만들기 위드 캔바". 특수문자(·, ~) 제목에 넣지 말 것.
5. **이미지가 다 똑같다.** 수업 때 보여준 3D 예시 이미지를 전부 따라 해서 쌍둥이 같다. 자기 색깔 넣어라.
6. 링크 깨진 것 많다. 발행 후 직접 클릭해 확인.
7. 제휴 이미지는 쿠팡 원본 그대로 쓰지 말고 필터·밝기 변경 또는 배경 제거 후 AI 재생성.

## 루카 적용 (2026-09-11부터)
1. **본문 이미지 2장 이상.** 도식 1장 + 실제 결과물/캡처 1장. 도식은 글자 크게·항목 적게(한 장에 메시지 하나).
2. **CTA 3분산**: ①첫 H2 끝에 전자책 또는 클래스 링크 한 줄, ②중간 H2 끝에 관련 내 글 링크 한 줄, ③끝에 기존 CTA 2문단. 한 덩어리 금지.
3. 제목: 검색 키워드 맨 앞(이미 규칙), 특수문자 제거.
4. 이미지 스타일: 지금 도식(회색 배경+표)이 다른 수강생과 겹칠 위험 → 다락방 캐릭터·수채화 톤 등 루카 색 넣기.
5. 발행 후 링크 전수 클릭 확인 (클로가 페이지 fetch로 확인 중).
6. 기존 10편 소급: 중간 CTA 한 줄 + 이미지 1장 추가는 시간 되는 대로 (우선순위 낮음, 새 글부터 적용).
