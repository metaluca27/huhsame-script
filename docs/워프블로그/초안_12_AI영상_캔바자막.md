<h2>핵심 요약</h2>
<ul>
  <li>AI 영상 도구의 결과물은 5초 클립이며, 30초 숏폼 한 편은 클립 6~7개를 캔바 세로 영상(1080×1920) 타임라인에 순서대로 놓아 만듭니다.</li>
  <li>캔바 자동 자막은 영상 속 말소리를 인식해 만드는 기능이라 목소리 없는 AI 영상에는 작동하지 않으므로, 대부분 글자 상자로 직접 넣습니다.</li>
  <li>자막은 화면 가운데 아래에 한 화면 한 문장, 글자 뒤에 반투명 박스를 깔고, 위 15%·아래 25%·오른쪽 버튼 영역은 피해야 릴스·숏츠·틱톡에서 잘리지 않습니다.</li>
</ul>

<h2>AI 영상 캔바 자막 작업이 왜 따로 필요한가요?</h2>
<p>AI 영상 도구가 내놓는 것은 완성된 영상이 아니라 장면 하나짜리 클립이기 때문입니다. 클립을 이어 붙이고, 자막을 넣고, 음악을 깔고, 30초에 맞추는 일은 편집 도구에서 해야 합니다.</p>
<p>제 공모전 작업이 그랬습니다. 이미지 생성 AI로 키프레임 7장을 만들고, 영상 생성 AI로 키프레임마다 5초 클립을 뽑았습니다. 클립 7개는 각각 따로 저장되는 파일이었고, 그 상태로는 아무 데도 올릴 수 없었습니다. 순서를 정하고, 장면마다 한 문장씩 자막을 얹고, 배경음악을 깔아 30초로 맞춘 뒤에야 <a href="https://youtube.com/shorts/xxG15t3P718" target="_blank" rel="noopener">유튜브 숏츠</a>와 인스타 릴스, 틱톡에 올릴 수 있었습니다.</p>
<p>결과는 탈락이었지만 만드는 순서는 그대로 남았습니다. 공모전 때는 편집을 코드로 하는 도구를 썼지만, 제 캔바 수업에서 가르치는 흐름은 캔바 영상 편집기입니다. 클릭만으로 같은 결과가 나오고, 자막 스타일과 음악이 캔바 안에 있기 때문입니다.</p>
<p><strong>AI 영상 제작의 절반은 만드는 시간이고 나머지 절반은 묶는 시간입니다.</strong></p>
<blockquote>
  <p><a href="https://kmong.com/self-marketing/803533/YNgTd87HX2" target="_blank" rel="noopener"><strong>전자책 「비개발자의 역습」 보러 가기</strong></a><br>코딩 없이 AI 도구를 하나씩 이어 붙여 앱 11개까지 만든 과정을 51쪽에 담았습니다. 영상도 같은 방식입니다. 도구를 잇는 감각이 궁금하다면 이 책부터 보세요.</p>
</blockquote>

<h2>클립은 어떻게 준비해야 하나요?</h2>
<p>세로 9:16으로 만들고, 클립마다 MP4로 저장하고, 파일 이름에 장면 순서 번호를 붙여 두는 것입니다.</p>
<ol>
  <li>AI 영상 도구에서 처음부터 세로(9:16) 비율로 생성합니다. 가로로 만든 뒤 세로로 자르면 주인공이 잘립니다.</li>
  <li>클립은 5초 기준으로 6~7개면 30초 숏폼이 됩니다. 저는 7개를 만들었고 그중 2개는 마음에 안 들어 다시 뽑았습니다.</li>
  <li>저장할 때 파일 이름을 "01_등장", "02_변신"처럼 순서와 장면으로 붙입니다. 캔바에 올리면 이름순으로 정렬돼 편합니다.</li>
  <li>같은 캐릭터가 여러 클립에 나오면 키프레임 단계에서 캐릭터 시트를 기준으로 만들어야 클립마다 얼굴이 안 바뀝니다. 그 방법은 <a href="https://digitaldarakbang.com/blog/ai-character-consistency-prompt/"><strong>AI 캐릭터 일관성 글</strong></a>에 있습니다.</li>
  <li>클립을 전부 컴퓨터에 내려받아 둡니다. AI 영상 도구는 구독이 끝나면 생성물을 못 받는 경우가 있습니다.</li>
</ol>

<h2>캔바 타임라인에는 어떻게 놓나요?</h2>
<p>캔바에서 "모바일 동영상" 또는 1080×1920 맞춤 크기로 새 디자인을 만들고, 클립을 업로드해 타임라인에 순서대로 끌어다 놓으면 됩니다.</p>
<ol>
  <li>캔바 홈에서 "동영상" → "모바일 동영상"(9:16)을 고릅니다. 없으면 맞춤 크기 1080×1920.</li>
  <li>왼쪽 "업로드"에 클립 MP4를 전부 올립니다.</li>
  <li>화면 아래 타임라인에 클립을 순서대로 끌어다 놓습니다. 클립 하나가 페이지 하나가 됩니다.</li>
  <li>클립 사이 전환은 "전환 추가"에서 디졸브 정도만 씁니다. 화려한 전환은 AI 영상과 겹쳐 어지럽습니다.</li>
  <li>전체 길이를 확인합니다. 릴스·숏츠·틱톡 모두 세로 60초까지 되지만, 공모전이나 광고는 30초 제한이 흔합니다.</li>
</ol>
<p>음악은 캔바 "오디오"에서 고르거나 직접 올립니다. 제 공모전 영상은 보컬을 뺀 반주 버전을 따로 만들어 깔았는데, 캔바 오디오 라이브러리에서 무보컬 곡을 고르면 그 과정을 건너뛸 수 있습니다.</p>

<h2>자막은 자동으로 넣을 수 있나요?</h2>
<p>영상에 말소리가 있을 때만 됩니다. 캔바 자동 자막은 음성을 인식해 글자로 바꾸는 기능이라, 목소리 없이 음악만 깔린 AI 영상에는 만들 자막이 없습니다.</p>
<p><a href="https://www.canva.com/help/generate-edit-captions-on-videos/" target="_blank" rel="noopener">캔바 고객센터의 자막 생성·애니메이션 안내</a>에 따르면 자동 자막은 텍스트 메뉴의 "동적 텍스트 → 자막 → 자막 생성"으로 만들고, 디자인이 동영상 유형이어야 하며, 음성이 들어 있어야 하고, 언어를 직접 지정하면 인식이 더 정확해집니다. 생성된 자막은 타임라인의 별도 층으로 들어가 <a href="https://www.canva.com/help/edit-manage-video-captions/" target="_blank" rel="noopener">자막 편집 안내</a>대로 글자와 시간을 고칠 수 있고, 20가지가 넘는 스타일 묶음(폰트·색·움직임)을 고를 수 있습니다.</p>
<p>그래서 흐름은 둘로 갈립니다.</p>
<ul>
  <li>나레이션을 넣은 영상: 나레이션 먼저 깔고 → 자동 자막 생성 → 오타만 수정. 가장 빠릅니다.</li>
  <li>음악만 깔린 AI 영상: 텍스트 상자로 클립마다 한 문장씩 직접 넣습니다. 대부분의 AI 숏폼이 여기 해당합니다.</li>
</ul>
<p>직접 넣을 때는 텍스트 상자 하나를 만들어 스타일을 잡은 뒤 복제해서 페이지마다 문장만 바꾸면 통일감이 유지됩니다.</p>
<p><strong>자동 자막은 말을 받아 적는 기능이지 장면을 설명해 주는 기능이 아닙니다.</strong></p>

<h2>내보내기와 업로드는 어떻게 하나요?</h2>
<p>MP4 1080p로 내려받아 릴스·숏츠·틱톡에 각각 올리되, 플랫폼마다 제목과 설명은 따로 씁니다.</p>
<ol>
  <li>"공유 → 다운로드"에서 파일 형식 MP4, 화질 1080p를 고릅니다.</li>
  <li>내려받은 파일을 휴대폰에서 한 번 재생해 자막이 잘리지 않는지 봅니다.</li>
  <li>인스타 릴스, 유튜브 숏츠, 틱톡에 같은 파일을 올립니다. 세 곳 다 세로 9:16, 60초 이내면 됩니다.</li>
  <li>썸네일이 필요한 유튜브는 첫 장면이 아니라 표정이 있는 장면을 따로 골라 씁니다. 기준은 <a href="https://digitaldarakbang.com/blog/youtube-thumbnail-ctr-canva/"><strong>유튜브 썸네일 클릭률 글</strong></a>에 있습니다.</li>
</ol>
<p><strong>영상 한 편은 만든 날이 아니라 세 플랫폼에 올라간 날에 끝납니다.</strong></p>

  <details>
    <summary>캔바 무료로도 영상 편집과 자막이 되나요?</summary>
    <div class="tc-faq__answer">됩니다. 타임라인 편집, 텍스트 상자 자막, 무료 오디오, MP4 내보내기는 무료 기능입니다. 자동 자막과 일부 스타일 묶음, 프리미엄 음악은 유료입니다.</div>
  </details>

  <details>
    <summary>클립 길이가 5초라 30초를 못 채워요.</summary>
    <div class="tc-faq__answer">클립을 7개 만들거나, 좋은 클립을 두 번 써도 됩니다. 같은 클립을 속도만 바꿔 다시 쓰거나, 정지 화면(키프레임 이미지)을 2~3초 넣어 채우는 방법도 흔히 씁니다.</div>
  </details>

  <details>
    <summary>AI 영상에 나레이션을 넣고 싶어요.</summary>

  </details>

  <details>
    <summary>자막 폰트는 뭘 써야 하나요?</summary>
    <div class="tc-faq__answer">굵은 고딕 계열이면 됩니다. 손글씨나 얇은 명조는 5초 안에 안 읽힙니다. 한 영상 안에서는 폰트 하나만 씁니다.</div>
  </details>

  <details>
    <summary>AI로 만든 영상을 공모전이나 SNS에 올려도 되나요?</summary>
    <div class="tc-faq__answer">대부분 됩니다. 다만 공모전은 AI 사용 여부 표기나 사용 도구 명시를 요구하는 경우가 있고, 실존 인물·브랜드가 들어가면 안 됩니다. 요강을 먼저 읽고, 사용한 도구를 설명란에 적어 두는 편이 안전합니다.</div>
