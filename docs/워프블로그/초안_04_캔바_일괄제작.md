<p><strong>캔바 일괄 제작은 엑셀 명단 한 장을 디자인 한 장에 연결해 100장을 한 번에 뽑는 Pro 기능입니다.</strong> 명함·상품 카드·수료증·가격표처럼 틀은 같고 글자만 다른 것을 만들 때, 한 장씩 고치는 대신 명단의 열 이름을 디자인의 글자 상자에 연결하면 줄 수만큼 페이지가 자동으로 생깁니다. 저는 캔바 수업 수료증과 명함 템플릿을 만들 때 이름·직함·날짜 자리를 처음부터 따로 떼어 두는데, 그 이유가 일괄 제작 때문입니다. 이 글은 명단 파일 만드는 법부터 에러 없이 100장을 뽑는 순서까지 정리한 것입니다.</p>

<h2>핵심 요약</h2>
<ul>
  <li>캔바 일괄 제작은 Pro·Business·Education 등 유료 요금제에서 데스크톱으로만 쓸 수 있고, CSV나 XLSX 파일을 올려 최대 300행·150열까지 연결할 수 있습니다.</li>
  <li>명단 파일의 첫 줄(열 이름)과 디자인의 글자 상자가 1대 1로 연결되므로, 열 이름을 한 단어로 짓고 글자 상자를 항목별로 따로 두는 것이 에러를 막는 핵심입니다.</li>
  <li>생성된 100장은 한 디자인의 100페이지가 되며, 수정은 명단 파일을 고쳐 다시 생성하는 방식이 페이지를 하나씩 고치는 것보다 빠릅니다.</li>
</ul>

<h2>캔바 일괄 제작은 무엇이고 누가 쓸 수 있나요?</h2>
<p>디자인 하나에 데이터 파일을 연결해 줄 수만큼 페이지를 자동으로 만드는 기능이며, 유료 요금제 사용자가 데스크톱에서 쓸 수 있습니다.</p>
<p><a href="https://www.canva.com/help/bulk-create/" target="_blank" rel="noopener">캔바 고객센터의 대량으로 디자인 만들기 안내</a>에 따르면 일괄 제작은 Canva Pro, Teams, Business, Enterprise, Education, 비영리 사용자가 데스크톱에서만 쓸 수 있고, 파일은 CSV 또는 XLSX 형식이어야 하며, 최대 300행·150열까지 선택할 수 있습니다. 데이터를 올리면 "자동 매칭" 버튼으로 캔바가 디자인을 분석해 자동으로 연결하거나, 데이터 필드를 디자인 요소에 직접 끌어다 놓을 수 있습니다.</p>
<p>무료 요금제에는 없는 기능입니다. 명함 100장을 매번 손으로 고치고 있다면 이 기능 하나가 <a href="https://digitaldarakbang.com/blog/canva-free-vs-pro/"><strong>캔바 무료 프로 차이 글</strong></a>에서 말한 "Pro 결제 신호"에 해당합니다.</p>
<p><strong>일괄 제작은 디자인 실력이 아니라 명단 파일을 얼마나 깔끔하게 만드느냐로 성패가 갈립니다.</strong></p>
<blockquote>
  <p><a href="https://kmong.com/self-marketing/803533/YNgTd87HX2" target="_blank" rel="noopener"><strong>전자책 「비개발자의 역습」 보러 가기</strong></a><br>코딩 없이 AI로 앱 11개를 만든 과정을 51쪽에 담았습니다. 캔바처럼 도구 하나로 시작해 어디까지 가는지 궁금하다면 이 책부터 보세요.</p>
</blockquote>

<h2>명단 파일은 어떻게 만들어야 에러가 없나요?</h2>
<p>첫 줄에 열 이름을 한 단어로 적고, 그 아래 한 줄에 한 사람씩 넣은 뒤 CSV나 XLSX로 저장하면 됩니다. 병합 셀·빈 줄·숨은 줄이 없어야 합니다.</p>
<ol>
  <li>엑셀이나 구글 시트를 엽니다. 첫 줄에 열 이름을 적습니다. 예: 이름, 직함, 전화, 이메일.</li>
  <li>열 이름은 띄어쓰기 없이 한 단어로 짓습니다. "전화 번호"보다 "전화"가 연결할 때 헷갈리지 않습니다.</li>
  <li>둘째 줄부터 한 줄에 한 사람씩 넣습니다. 100장이면 100줄입니다.</li>
  <li>병합된 셀, 중간의 빈 줄, 제목 행, 합계 행을 전부 지웁니다. 캔바는 첫 줄을 열 이름으로, 그 아래 전부를 데이터로 봅니다.</li>
  <li>CSV(UTF-8) 또는 XLSX로 저장합니다. 한글이 깨지면 XLSX로 다시 저장하면 대부분 해결됩니다.</li>
</ol>
<p>사진을 넣어야 하면 열에 이미지를 직접 넣는 것이 아니라, 캔바에 사진을 먼저 올린 뒤 연결 화면에서 이미지 필드로 지정합니다. 상품 카드처럼 사진이 매번 다른 경우는 텍스트 열 먼저 연결하고 이미지는 마지막에 연결하는 순서가 안전합니다. 상품 사진의 배경을 먼저 지워 두면 카드가 깔끔해지는데, 그 방법은 <a href="https://digitaldarakbang.com/blog/ai-image-background-remove/"><strong>AI 이미지 배경 제거 글</strong></a>에 있습니다.</p>

<h2>디자인은 어떻게 만들어 두어야 하나요?</h2>
<p>바뀌는 항목마다 글자 상자를 따로 만들고, 가장 긴 값이 들어와도 넘치지 않게 상자를 넉넉히 잡아 두는 것입니다.</p>
<ul>
  <li>이름·직함·전화를 한 글자 상자에 넣지 말고 세 개로 나눕니다. 한 상자에 열 하나만 연결됩니다.</li>
  <li>글자 상자 크기는 명단에서 가장 긴 값을 기준으로 잡습니다. "김민지"에 맞춰 두면 "남궁민수정"이 넘칩니다.</li>
  <li>글자 상자에 임시로 열 이름을 적어 두면 자동 매칭이 더 잘 됩니다. 이름 상자에는 "이름", 직함 상자에는 "직함"이라고 써 둡니다.</li>
  <li>바뀌지 않는 요소(로고·배경·안내 문구)는 그대로 둡니다. 연결하지 않은 요소는 모든 페이지에 같이 복사됩니다.</li>
  <li>여러 채널에 쓸 카드면 글자를 가운데 안전 영역에 두는 규칙도 같이 적용합니다. 그 기준은 <a href="https://digitaldarakbang.com/blog/canva-image-size-2-3/"><strong>캔바 이미지 사이즈 2:3 공식 글</strong></a>에 있습니다.</li>
</ul>
<p>제가 수료증 템플릿을 만들 때 이름·과정명·날짜를 각각 다른 상자로 두고 이름 상자를 가장 넓게 잡는 이유가 이것입니다. 한 번 이렇게 만들어 두면 기수가 바뀌어도 명단만 바꾸면 됩니다.</p>

<h2>실제로 100장을 뽑는 순서는 어떻게 되나요?</h2>
<p>앱에서 일괄 제작을 열고, 파일을 올리고, 열을 글자 상자에 연결한 뒤, 생성 버튼을 누르면 100페이지가 한 디자인 안에 만들어집니다.</p>
<ol>
  <li>데스크톱 캔바에서 디자인을 연 뒤 왼쪽 메뉴 "앱"에서 "일괄 제작"을 찾아 엽니다.</li>
  <li>"데이터 업로드"로 CSV 또는 XLSX 파일을 올립니다. 열 이름이 목록으로 나타납니다.</li>
  <li>"자동 매칭"을 누릅니다. 열 이름과 글자 상자 내용이 같으면 자동으로 연결됩니다. 안 된 항목은 열 이름을 글자 상자로 끌어다 놓거나, 글자 상자를 우클릭해 "데이터 연결"에서 고릅니다.</li>
  <li>"페이지 생성"을 누릅니다. 명단 줄 수만큼 페이지가 생깁니다.</li>
  <li>첫 페이지, 마지막 페이지, 가장 긴 이름이 든 페이지 세 장만 확인합니다. 셋이 괜찮으면 나머지는 같습니다.</li>
  <li>"공유 → 다운로드"에서 PDF(인쇄용)로 전체 페이지를 한 번에 저장합니다. 인쇄소에 보낼 땐 여백과 재단선 옵션을 켭니다.</li>
</ol>

<h2>자주 막히는 지점은 어디인가요?</h2>
<p>열 이름이 안 맞아서 연결이 안 되는 것, 긴 글자가 상자를 넘치는 것, 생성 후 한 장만 고치려다 나머지와 어긋나는 것 세 가지입니다.</p>
<ul>
  <li>연결이 안 되면 열 이름을 다시 봅니다. 앞뒤 공백, 특수문자, 같은 이름의 열 두 개가 흔한 원인입니다.</li>
  <li>글자가 넘치면 글자 상자에서 "자동 크기 조정"을 켜거나 상자를 키웁니다. 명단에서 가장 긴 값을 먼저 찾아 그 값으로 상자를 맞춥니다.</li>
  <li>한 사람 정보가 틀렸으면 페이지를 직접 고치지 말고 명단을 고쳐 다시 생성합니다. 페이지를 손으로 고치기 시작하면 명단과 어긋나서 다음번에 또 틀립니다.</li>
  <li>300행이 넘으면 파일을 나눕니다. 300행씩 두 번 생성해 PDF를 합치는 편이 빠릅니다.</li>
  <li>모바일 앱에서는 안 됩니다. 컴퓨터에서 해야 합니다.</li>
</ul>
<p><strong>일괄 제작에서 수정은 항상 디자인이 아니라 명단 쪽에서 합니다.</strong></p>

  <details>
    <summary>캔바 무료 버전에서는 정말 안 되나요?</summary>
    <div class="tc-faq__answer">캔바 고객센터 기준으로 일괄 제작은 Pro·Business·Education 등 유료 요금제 전용입니다. 무료로 비슷하게 하려면 디자인을 복제해서 한 장씩 고치는 방법뿐이라, 20장이 넘어가면 Pro 체험을 켜는 편이 빠릅니다.</div>
  </details>

  <details>
    <summary>사진도 한 번에 바꿀 수 있나요?</summary>
    <div class="tc-faq__answer">가능합니다. 캔바에 사진을 먼저 올려 두고, 연결 화면에서 이미지 요소에 이미지 필드를 지정하면 됩니다. 상품 카드처럼 사진과 글자가 모두 다른 경우에도 한 번에 생성됩니다.</div>
  </details>

  <details>
    <summary>한글이 깨져서 올라가요.</summary>
    <div class="tc-faq__answer">CSV 인코딩 문제입니다. 엑셀에서 "CSV UTF-8" 형식으로 다시 저장하거나, 아예 XLSX로 저장해서 올리면 대부분 해결됩니다.</div>
  </details>

  <details>
    <summary>100장 중 몇 장만 다시 뽑을 수 있나요?</summary>
    <div class="tc-faq__answer">명단 파일에서 필요한 줄만 남기고 다시 생성하면 됩니다. 이미 만든 디자인에서 페이지를 지우는 것보다 명단을 줄여 새로 생성하는 편이 실수가 적습니다.</div>
  </details>

  <details>
    <summary>명함 인쇄소에 보낼 때 파일은 어떻게 해야 하나요?</summary>
    <div class="tc-faq__answer">PDF 인쇄용으로 전체 페이지를 한 파일로 저장하고, 다운로드 옵션에서 재단선과 여백을 켭니다. 인쇄소가 CMYK를 요구하면 Pro의 CMYK 내보내기 옵션을 씁니다.</div>
  </details>
