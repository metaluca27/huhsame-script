## 0. 줍줍 대표 보충 설명 (00:00~06:00)

- 줍줍은 **워드프레스 기반**이 맞음. 워드프레스가 어려워서 네이버 블로그처럼 쓰게 화면만 바꾼 것.
- 무료 vs 유료: 무료는 연습용. AI 봇(크롤러)이 들어와 읽어가게 하는 서버·기술 세팅은 유료(월 9,900원)부터. 글 100개 초과 시 월 1만~1.5만 원 정도 추가 예정(미확정).
- **줍줍에 쓴 글은 다른 워드프레스로 옮겨도 노출 구조가 안 따라감.** 내부 기술 세팅과 연동돼 있어서 복사해 가면 그냥 글만 남음. → 원본 초안은 따로 보관할 것.
- 원래 쿠팡 파트너스 하는 사람들이 상품 쉽게 가져오게 하려고 만든 서비스.
- SEO/GEO 점수는 처음엔 신경 쓰지 말 것. 습관이 먼저. 도메인 붙이고 10일 뒤부터 의미 있음.
- 병원엔 이 세팅을 1,000만 원에 해주는데 수강생에겐 9,900원에 주는 것.

## 1. 제휴마케팅 개념 (07:00~19:00)

- 제휴마케팅 = 내가 영업사원. 물건 없이 추천만 하고 커미션 받음. 해외에선 affiliate. 한국 시장은 짜고 좁음.
- 강사가 캔바를 시작한 계기도 캔바 affiliate였음(지금은 폐지, 앰배서더만 가능).
- 해외 부자 10명(Pat Flynn 등) 전부 **워드프레스+SEO 블로그**로 제휴마케팅. 구글독스 강의안에 목록 있음.
- **왜 쿠팡인가**: 수수료는 3%로 낮지만 전 국민이 로그인돼 있고 한 번에 결제 → 전환율 1위. 다른 몰은 회원가입·로그인에서 이탈.
- **24시간 룰**: 내 링크 타고 들어간 사람이 24시간 안에 다른 물건(냉장고든 뭐든) 사도 내 수익.
- **타겟은 30~50대 주부.** 구매력·가족 단위 대량구매. 남성 타겟 금지(결정권 없음).
- 30~50대 여성 콘텐츠 소비 순위: 1위 건강·다이어트 / 2위 요리·레시피 / 3위 패션 / 4위 뷰티·안티에이징 / 5위 살림·인테리어. 자기 잘하는 분야와 연결해서 방향 잡기.
- 링크 노출 채널: 유튜브 쇼핑태그, 인스타 프로필, 네이버 클립, 페북, 스레드, 틱톡, 그리고 **줍줍 블로그**. SNS 없으면 줍줍에 글 쓰고 링크 달면 됨.

## 2. 쿠팡 파트너스 실습 (19:00~35:00)

**가입 순서**
1. 쿠팡 일반 계정 필요(없으면 먼저 가입)
2. 쿠팡 파트너스 사이트에서 같은 ID로 로그인 → 자동 가입
3. 내 정보에 **활동 채널 링크 등록** (유튜브·블로그·줍줍 주소 중 실제로 쓸 곳)
4. 상품 페이지에서 "간편 링크 만들기"로 제휴 링크 생성

**줍줍 확장 연결 후**
- 줍줍 관리 화면의 3~4분 영상 보고 확장 설치 + 연결 코드 넣기
- 쿠팡 상품 페이지에 **+ 버튼**이 생김 → 원클릭 담기
- "제휴 링크를 막아둔 상품"이라고 뜨면 쿠팡이 막은 것. 그건 안 됨(단톡방 질문의 답)
- 수동 방법: 만들기 → 새 상품 담기 → 파트너스 링크 + 상품명 + 이미지(파트너스 이미지 그대로 써도 됨) → 공개

**글쓰기 (실습 예: 글렌덴제스하르 탈모방지샴푸)**
- 클로드 프로젝트 "GEO 블로그 챌린지"에 상품명만 입력 → 참고자료 물으면 쿠팡 상세페이지 내용 붙여넣기(GEO 점수↑)
- 제목·포커스 키워드·본문 HTML → `</> 코드` 모드에 붙이기 → `비주얼`로 확인
- **링크 넣기는 비주얼에서**: 본문 중간중간 "상품 바로 보러가기" 글자에 링크. 한 상품만 말고 다른 상품 링크도 섞기. 이모티콘·이미지에 링크 걸어도 됨
- 이미지 없으면 SEO 빨간불 → 공식 상품 이미지 캡처 OK(자기 물건 팔아주는 거라 저작권 문제 없음), AI로 배경 바꿔서 만들어도 됨
- **고지문 필수**: "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 맨 위나 맨 아래 고정. 매번 복붙
- 인포크링크(월 1만 원대) 대신 줍줍 스토어를 링크 모음으로 써도 됨. 더 쌈
- 소넷으로 쓸 것. 오푸스는 크레딧 소모 큼

## 3. 키워드 전략 (36:00~50:00)

- **네이버 블로그 제휴는 위험**: 링크 많이 넣으면 저품질. 살아남은 사람들은 일상글 사이에 조심조심 끼워 넣는 중. **줍줍은 공격적으로 링크 넣어도 됨.** 이게 줍줍의 진짜 가치
- 키워드 3단계: 큰 키워드(노트북) X → 중간(LG그램 14인치) → **가장 뾰족한 모델명(14ZD995-GX50K)**. 살 사람만 검색하니 노출 확실. 광고 많은 키워드도 줍줍에선 써도 됨(네이버에선 블랙리스트)
- 가전제품은 모델명 공략. 네이버 자동완성으로 세부 키워드 찾기(삼성냉장고 4도어 → 모델명 RF…)
- **홈쇼핑 편성표 전략**: 방송 하루 전이나 몇 시간 전에 그 제품 글 미리 써두기(뼈엔뼈엔 사례: TV 나오자 검색 폭증)
- 제목: 앞에 키워드 1~2개 + 뒤에는 "충격적인 가격과 할인" 같은 궁금증 문구. 키워드 도배 금지
- 비싼 것만 할 필요 없음. 볼펜 글로 들어와 냉장고 사는 사람도 있음
- 강사 실적 사례: LG 트롬 워시타워(모델명 2개 다), 삼성 그랑데 건조기 DV148, 지워지는 볼펜, 갤럭시 신제품

## 4. 제휴 플랫폼 (50:00~58:00)

| 플랫폼 | 특징 | 수수료 예시 |
|---|---|---|
| 애드픽 | 쇼핑메이트 다양 | 인포크링크 14%, 교복몰 10.5%, 폰케이스 20%, YES24 3.3%, 크몽 3.5~4%. **쿠팡은 2.1%라 파트너스 직접(3.3%)이 나음** |
| 링크프라이스 | CPS 위주, 여행·서비스 | 숨고 44%, 클룩 10%, 아디다스 6%, 아고다·트립닷컴·호텔스컴바인 |
| 텐핑 | 페이스북 위주 | 블로그엔 부적합 |
| 디비디비딥·애드릭스 | DB 수집형 | 초보 비추 |

- 초보는 **애드픽 + 링크프라이스만**. 같은 업체가 여러 곳에 있으면 수수료 높은 곳 하나만
- CPS = 팔려야 수수료 / CPA = 상담 신청·연락처만 남겨도 수수료(호관원류)
- **내 링크로 내가 사면 계정 정지**(IP·주소 추적). 가족에게 링크 보내는 건 됨
- 여행 블로그면 다녀온 후기 쓰면서 숙소 링크만 달아도 됨

## 5. 프리랜서·브랜딩·페르소나 (58:00~66:00)

- 프리랜서 수주: "나 잘해요" 글 말고 **고객이 검색하는 질문 글**(스마트스토어 상세페이지 사이즈 등)을 깔아둬야 신뢰 후 의뢰
- **한 블로그 한 주제.** 예술 블로그면 예술만. 주제 들쑥날쑥이면 전문가로 안 봄(네이버·워드프레스 공통). 브랜딩과 잡식 제휴 둘 다 하려면 **블로그 2개**
- 페르소나 예: 45세 주부, 결혼 n년차, 연봉 5천, 30평 전세, 강아지 털·집안 어질러짐·드라마·요리 → 이 사람의 불편을 해결하는 제품만. "모두를 만족시키면 아무도 만족 못 함"
- 페르소나 못 정하겠으면 챗GPT에 3개 만들어달라고

## 6. Q&A (66:00~74:00)

- **줍줍 블로그에 애드센스 달 수 있나? → 안 됨**(줍줍 측 확인). 애드센스는 키워드 기계적 공부가 필요한 다른 길
- 쿠팡 파트너스 유튜브 등록의 "스크린샷" 칸 → 채널 소개란에 파트너스 고지 문구 넣고 그 화면 캡처
- 디지털파일·전자책 판매는 신뢰 관계가 먼저. 제휴(브랜딩 없이도 팔림)와 결이 다름. 관련 정보 글을 쌓은 뒤 "내가 이런 책 만들었다" 시점에 판매
- 교보문고 링크: 자체 제휴 없음. 애드픽/링크프라이스 중 수수료 높은 곳
- 마무리: 방향 못 정했어도 오늘 하나라도 써볼 것. 손에 익어야 계속 씀

## 루카에게 해당되는 것

1. **줍줍엔 애드센스 안 됨 → InfoLoomia와 역할 분리 확정.** InfoLoomia = 애드센스, 줍줍 = 브랜딩·제휴·강의 유입.
2. **줍줍 글은 이전 불가** → 초안 md를 docs/워프블로그/에 계속 보관하는 지금 방식이 맞음.
3. **한 블로그 한 주제** → 줍줍은 "캔바·AI·비개발자 앱 제작" 축 유지. 제휴 잡식 글 섞지 말 것. 하려면 두 번째 줍줍 블로그.
4. 강사가 말한 "브랜딩 후 전자책 판매" 경로 = 「비개발자의 역습」 판매 경로와 동일. 관련 글 10편 쌓은 뒤 소개 글.
5. 애드픽에 **크몽 3.5~4%**, 링크프라이스에 **클룩 10%**. 캔바 affiliate는 폐지라 캔바 추천으로 수수료 못 받음.
6. 쿠팡 파트너스는 계정 없으니 보류 그대로. 하게 되면 활동 채널은 줍줍 주소로 등록.
7. 페르소나는 이미 있음(디자인 비전공 소상공인·중장년·AI 부업 희망 비개발자).
