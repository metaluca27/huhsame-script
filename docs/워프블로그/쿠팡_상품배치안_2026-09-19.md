## 막힌 곳 (2026-09-19)
- 줍줍 크롬 확장 "스토어 연결하기"는 연결 코드 방식. 기존 연결을 지우고 코드를 새로 받아도 담을 곳이 옛 서브도메인(atlia079318.zoopzoop.shop)으로만 잡히고 "연결 필요"에서 안 넘어감. 옛 서브도메인은 wp-signup으로 튕기는 죽은 주소 → 줍줍 서버가 커스텀 도메인 사이트를 옛 주소로 돌려주는 것으로 보임. 루카가 단톡에 제보.
- 우회: 확장 없이 파트너스 사이트에서 링크 생성 → 글에 직접 삽입(클로가 REST로). 스토어 탭 진열은 줍줍 수정 후.

## 해결 (2026-09-21)
- 줍줍 크롬 확장이 새 도메인(digitaldarakbang.com)으로 "연결됨 · 정상·무제한" 상태가 됨(줍줍 측 수정으로 보임). 남은 건 "파트너스 로그인 → 로그인 상태 확인".
- 옛 서브도메인(atlia079318.zoopzoop.shop)은 09-21에도 여전히 wp-signup으로 302. 외부에 뿌린 옛 링크는 아직 죽어 있음 → 301 요청은 계속 유효.

## 첫 상품 진열 (2026-09-21)
- 스토어에 "프린텍 명함용지 라벨지 백색무광 V5142-20, 10칸, 20개" 등록됨(상품 ID 85, 글 유형 aff_product). 홈에 "상품 / 블로그" 탭과 사이트 전체 파트너스 고지문이 자동 표시됨.
- 상품 링크는 `https://digitaldarakbang.com/go/85/` → 302 → `https://link.coupang.com/a/...`(루카 파트너스 단축 링크). 줍줍이 쓰는 속성: `target="_blank" rel="sponsored nofollow noopener"`.

- 담는 위치: 파트너스 "상품검색" 결과에서 담김(링크 생성 화면에서는 안 됨).
