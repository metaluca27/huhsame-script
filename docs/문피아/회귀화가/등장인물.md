# 「32억을 그린 화가는 0원이었다」 등장인물

나이는 이야기가 시작되는 2017년 기준이에요. (2022년 결말 때는 +5살)

## 주요 인물

| 이름 | 역할 | 하는 일 |
|---|---|---|
| 윤재현 (29) | 주인공, 화가 | 전생에 9년 동안 강태민의 이름으로 대작을 그리다 죽고 계약 전날로 회귀. 그림 위에 낙찰가가 보이는 눈으로 자기 이름을 되찾음 |
| 서하린 (26) | 화가, 재현의 첫 인연 | 묵현 1층 알바생이던 신인 화가. 재현이 처음 산 그림 「막차」의 작가. 베를린으로 가 유럽 신진 작가상을 받음 |
| 민도하 (47) | 최종 악역, 갤러리 묵현 대표 | 다정한 말투로 화가들을 지하에 묶어 남의 이름으로 그리게 함. 재현의 그림과 이름을 빼앗으려 끝까지 방해함 |
| 강태민 (41) | 스타 화가 | 묵현의 간판 작가지만 자기 손으로 그린 그림은 300만 원짜리. 왼손잡이. 마지막에 대작에 서명을 거부함 |
| 정우석 (35) | 묵현 지하의 대작 화가 | 13년 동안 강태민 이름으로 그림을 그림. 그림 구석에 엄마의 노란 우산 물방울을 숨겨 둠. 기자회견으로 폭로함 |
| 박 사장 (66) | 청운표구사 주인, 재현의 스승 같은 어른 | 붓질로 진짜와 가짜를 가려냄. 재현의 동업자이자 버팀목. 젊은 민도하에게 액자 닦는 법을 가르쳤던 사람 |
| 어머니 (60) | 재현의 어머니 | 고향에서 혼자 지냄. 쓰러진 뒤 왼손을 재활함. 재현이 처음으로 그림을 보여 드리고 싶은 사람 |
