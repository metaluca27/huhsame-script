# 작품 소개 (초안)

**제목 후보:** 회귀한 화가, 그림 값이 보임 (등록 직전 확정)
**장르:** 현대판타지, 일반소설 (부장르는 등록 화면 선택지 보고 확정)
**태그:** #화가 #회귀 #현대판타지 #복수 #예술가

## 소개글 (800자 제한 안)

"그림은 이름값으로 팔리는 거야. 넌 이름이 없잖아."

9년 동안 남의 이름으로 그림을 그린 화가, 윤재현.
그가 그린 바다는 32억에 팔렸고,
그는 난방 끊긴 창고 바닥에서 자기 이름을 다 쓰지 못하고 죽었다.

눈을 뜨니 그 계약서에 도장을 찍기 전날.
그리고 그의 눈에 모든 그림의 값이 보이기 시작했다.

스타 작가의 그림, 300만 원.
아무도 모르는 신인의 소품, 9억 원.
자기 습작, 0원.

붓을 들어 서명을 하자 숫자가 바뀌었다.

41억 원.

이번엔 내 그림에 내 이름을 쓴다.
