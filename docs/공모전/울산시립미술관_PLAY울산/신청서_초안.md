## 2. 출품작 정보
- **작품명**: 집 가는 길
- **작품길이**: 1분 00초
- **제작방식**: 생성형 AI, 모션그래픽 (바탕은 본인의 아크릴 원화)
- **생성형 AI 활용**: 활용함

**AI 활용 내용**

> Higgsfield(Nano Banana Pro): 본인이 그린 아크릴 원화 「집가는길」 사진을 입력해, 원화 오른쪽으로 이어지는 풍경을 같은 화풍으로 확장 생성(이미지). Claude Code: 확장 이미지 합성과 새·별·하늘색 변화 애니메이션을 코드로 제작, ffmpeg로 인코딩. 영상 생성 AI는 사용하지 않음. 화면 맨 왼쪽은 원화 사진을 그대로 사용.

**작품설명 (200자 내외)**

> 직접 그린 아크릴화 「집가는길」을 40m 화면으로 펼쳤습니다. 화면 왼쪽 끝에는 원화가 그대로 있고, 그림 속 새들이 캔버스를 벗어나 전깃줄을 따라 날아갑니다. 새들은 사람이 걷는 속도로 화면을 건너, 노을이 저물고 별이 뜰 무렵 반대편 끝 전깃줄에 내려앉습니다. 미술관 앞을 지나는 시민이 새들과 나란히 걸으며 저마다의 집 가는 길을 떠올리기를 바랍니다.
