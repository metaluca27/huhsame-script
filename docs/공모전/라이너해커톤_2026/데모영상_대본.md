# 데모 영상 대본 (3분)

목표 길이는 3분이다(제출 기준은 5분 이내). 실제 실행 화면만 쓰고, 결과를 꾸미지 않는다. 화면에 나온 숫자와 판정은 그날 실제로 나온 것을 그대로 말한다.

## 구성을 이렇게 잡은 이유

- 검사를 처음부터 끝까지 보여 주는 자료는 **가상 사내 교육자료 6장**으로 한다. 30초쯤이면 끝나서 빠르게 돌리지 않고 그대로 보여 줄 수 있고, 낡은 정보 네 개를 심어 둔 자료라 무엇이 잡혀야 하는지 분명하다.
- **실제 강의 자료 28장**은 미리 돌려 둔 결과 화면만 보여 준다. 3분 가까이 걸리고, 어떤 내용이 뽑히고 잡히는지가 실행마다 달라서 영상의 중심 장면으로 삼기 어렵다(2026-11-18에 돌렸을 때는 발표 노트의 "최신은 2.31.0"이 뽑히지 않았다).
- 가상 자료라는 사실과 낡은 정보를 일부러 심었다는 사실은 영상에서 말로 밝힌다.

## 찍기 전에 준비할 것

- [ ] 브라우저를 **시크릿 창**으로 연다. 프로필 사진, 이메일, 즐겨찾기가 화면에 나오지 않게 한다.
- [ ] 시크릿 창에 탭을 두 개 연다. 둘 다 `https://vaulted-bus-346411.web.app/fresh`
  - 첫째 탭: 비워 둔다. 영상에서 가상 사내 자료를 올릴 탭이다.
  - 둘째 탭: 찍기 전에 **실제 강의 PPT를 미리 올려 결과 화면까지** 띄워 둔다. 공식 사이트는 `antigravity.google`.
- [ ] 올릴 파일은 바탕화면의 빈 폴더에 둔다. 다른 파일 이름이 탐색기에 보이지 않게 한다.
  - 가상 사내 자료: `한빛물산_신입사원_AI도구_안내_v3.pptx`
  - 실제 강의 자료: 강사 이름을 지운 사본
- [ ] 강의 슬라이드를 보여 주는 첫 장면은 **슬라이드 쇼(F5) 전체 화면**으로 찍는다. 한쇼나 PowerPoint 창의 제목 줄에 로그인한 계정의 이메일이 보이기 때문이다.
- [ ] 찍기 직전에 가상 사내 자료를 한 번 돌려 본다. 공식 문서가 바뀌면 결과도 바뀐다. 대본과 다르면 **화면에 나온 대로** 말한다.
- [ ] 화면 녹화는 1920×1080, 브라우저 확대 110~125%.
- [ ] 다 찍고 유튜브에 "일부 공개"로 올린 뒤, 시크릿 창에서 링크가 열리는지 확인한다.

## 말할 때 지킬 것

- "Liner Search", "Liner Model"은 소리 내어 말한다. 화면만으로는 어디에 API가 쓰이는지 보이지 않는다.
- 걸린 시간, 개수, 버전은 **화면에 나온 값**을 읽는다.
- "50분쯤"은 제작자가 기억하는 시간이다. 시계로 잰 값처럼 말하지 않는다.
- 가상 자료의 측정 수치(마흔여덟 번 중 마흔다섯 번)는 2026-11-15와 11-18에 잰 열두 번의 합이다. 영상에서 돌린 판에서 네 개를 다 잡지 못해도 그대로 둔다. 놓친 것은 "확인 못 함"으로 나온다.
- 가상 자료에서 "바뀜"이 네 개보다 적게 나오면 나온 개수를 그대로 말한다. 다시 돌려서 잘 나온 판을 고르지 않는다.
- 실제 강의 자료의 결과에 "바뀜"이 있으면, 앱에서 직접 확인한 것만 "잡아냈다"고 말한다. 확인하지 않은 것은 "확인해 볼 항목으로 나왔다"고 말한다.
- 화면에 이메일, 사용자 이름, 다른 탭의 제목이 보이지 않는지 마지막에 한 번 돌려 본다.
