# 다락방 그림창고 · 작품 영상 기획서

- 용도: 스레드·릴스용 작품 소개 (Foresto 전시 「다락방 그림창고」 안내)
- 크기: 1080 x 1920 (9:16), 30 fps, 15초, 반복 없음, 소리 없음
- 스타일: swiss-grid (흰 바탕, 검정 글자, 회색 격자선, 빨간 점 하나)

1. 다락방 / 그림창고
2. 집가는길
3. 달항아리
4. 염소자리 / 여인의 사색
5. 연 (緣)
6. 선물
7. 메타루카 / foresto.co.kr/@metaluca
- 위쪽 라벨: 왼쪽 번호(01 / 05), 오른쪽 주소(foresto.co.kr/@metaluca)

## 색 (hex)
- 바탕 #FFFFFF, 글자 #111111, 격자선 #E6E6E6, 강조 #E4002B (빨간 점 하나만)
- 그림은 원래 색 그대로

## 글꼴 (모두 무료, 구글 폰트 링크)
- 한글: Noto Sans KR 900 (제목), 600 (라벨)
- 영문·숫자: Inter 900, 600
- 제목 150px, 자간 -0.04em / 라벨 30px

## 배치
- 여백 96px, 12단 격자
- 그림 칸: x 96, y 200, 888 x 1230, 모서리 직각
- 제목 줄: y 1486부터 두 줄(줄 높이 168px), 왼쪽 여백에 붙임
- 그림 위에는 글자를 얹지 않음

## 움직임 (숫자)
- 그림 교체: 옆으로 한 칸 밀려 들어옴, power3.inOut 1.0초
- 제목 교체: 줄 가림막 안에서 위로 밀려 올라감, expo.inOut 0.8초
- 빨간 점: 새 제목 끝으로 뛰어가 착지하며 살짝 눌림 (0.66초)
- 그림이 머무는 동안: 1.12 → 1.00 느린 움직임(sine.inOut), 가로 그림은 전체를 여백 위에
- 교체 시각: 1.5 / 3.9 / 6.3 / 8.7 / 11.1 / 13.5초

## 금지
- 그라데이션, 그림자, 빛 번짐, 흐림, 둥근 모서리
- 전부 가운데 정렬, 두 번째 강조색
- 0에서 커지는 등장, 눈이 따라가는 것에 등속 움직임
- 화면에 6단어 초과
