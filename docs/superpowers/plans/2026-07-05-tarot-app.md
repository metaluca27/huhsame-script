# 심연의 타로 앱 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 78장 타로 + 점성학 + 수비학을 결합한 5장 스프레드 타로 앱을 `landing/tarot/`에 만들어 Firebase로 배포한다.

**Architecture:** 기존 `/cards` 게임과 동일한 바닐라 JS 정적 페이지(단일 index.html + JS/CSS 분리). 카드 기본 해석은 내장 데이터로 즉시 표시하고, AI 심층 리딩만 공용 Cloudflare Worker의 신규 `/tarot` 엔드포인트를 호출한다. 안내 캐릭터는 푸름이(기존 이미지 재사용).

**Tech Stack:** 바닐라 HTML/CSS/JS, Firebase Hosting, Cloudflare Worker(Gemini + Anthropic 폴백), 라이더-웨이트 퍼블릭 도메인 이미지.

핵심 로직:
```js
function getLifePath(dateStr){ // "1990-03-18"
  let n = dateStr.replace(/\D/g,"").split("").reduce((a,b)=>a+ +b,0);
  while(n > 9 && n !== 11 && n !== 22)
    n = String(n).split("").reduce((a,b)=>a+ +b,0);
  return n;
}
```
