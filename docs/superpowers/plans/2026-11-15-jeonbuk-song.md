# 「남원에 오면 나도 춘향이」 제작 계획

**Goal:** 전북에 빠졌쏭 공모전(마감 2026-11-19 24:00)에 낼 50초 안팎 세로 뮤직쇼츠와 접수 자료를 11-18까지 완성한다.

**방식:** 아보카도로 노래 → 힉스필드로 컷별 그림 → 핵심 3컷만 영상 생성 → ffmpeg로 편집. 이 세션에서 순서대로 직접 진행하고, 크레딧이 나가는 단계마다 루카 승인을 받는다.

**Spec:** `docs/공모전/전북_빠졌쏭_2026/기획.md`

## 전체 제약 (요강 그대로)
- 세로 9:16, 30~60초, MP4 1GB 이하, 자막 필수
- 영상 안에 "공모전 출품작" 표기와 "AI를 활용해 만든 영상" 표기
- 무료 요금제(상업 이용 제한)로 만든 음원 불가
- 실존 인물 얼굴·목소리 사용 안 함, 루카의 옛 사진은 영상에 넣지 않음
- 미발표작이므로 접수 전 SNS 공개 금지

## 놓치기 쉬운 것
- 광한루·오작교가 중국풍으로, 한복이 한푸로 나오는 것 → 컷마다 눈으로 확인, 나오면 재생성
- 주인공 얼굴·옷이 컷마다 달라지는 것 → 첫 컷을 기준 그림으로 고정하고 참조로 넘김
- 노래 길이가 60초를 넘는 것 → 편집에서 60초 미만으로 자르고 ffprobe로 길이 확인
- 가사 자막과 실제 노래 가사가 어긋나는 것 → 노래를 받아쓰기(whisper)해서 대조
- 작업 기록 누락 → 생성할 때마다 요청 문장·도구·요금제를 `작업기록.md`에 바로 적음

## 파일
모두 `docs/공모전/전북_빠졌쏭_2026/` 아래.
- `가사.md` 가사 전문 (제출용)
- `작업기록.md` 도구·요금제·요청 문장 (제출용)
- `audio/` 노래 원본과 자른 버전
- `images/S01.png ~ S09.png` 컷별 그림
- `clips/` 움직이는 컷
- `build/make_video.py` 편집 스크립트
- `남원에오면나도춘향이.mp4` 최종본
- `접수_붙여넣기.md` 신청서 칸별 문구

## 작업

### 1. 아보카도 상업 이용 조건 확인
- [ ] abocado.ai 약관·요금 안내에서 생성물 상업 이용·배포 조항을 찾는다.
- [ ] 허용이 확인되면 `작업기록.md`에 조항과 확인 날짜를 적는다.
- [ ] 확인이 안 되면 루카에게 알리고 대안(상업 이용이 명시된 유료 음악 도구)을 제시한다.
- 통과 기준: 조항 출처가 기록돼 있다.

### 2. 노래
- [ ] `가사.md` 작성 (기획서 가사 그대로).
- [ ] Popcorn 3.0 Pro 견적(abocado_check_cost) → 차감액·잔액을 루카에게 알리고 승인.
- [ ] 생성: 밝은 어쿠스틱 팝, 여성 보컬, 경쾌한 템포. 프롬프트에 줄표·슬래시 금지.
- [ ] 내려받아 `audio/`에 저장, 길이·가사 발음을 확인하고 루카에게 들려준다.
- 통과 기준: 루카가 "이 노래로 가자"고 한다. 아니면 프롬프트를 고쳐 한 번 더(재승인).

### 3. 컷별 그림 (S01~S09)
- [ ] 광한루원·오작교·그네의 실제 모습을 찾아 프롬프트에 반영한다.
- [ ] 주인공 기준 그림 1장(줄무늬 스웨터·흰 바지, 따뜻한 애니메이션 일러스트풍)을 먼저 뽑아 루카 확인.
- [ ] 기준 그림을 참조로 넘겨 나머지 컷 생성(9:16).
- [ ] 컷마다 직접 보고 중국풍·한푸·얼굴 불일치를 거른다.
- 통과 기준: 9컷이 모두 있고 루카가 한 번 훑어봤다.

### 4. 움직이는 컷 3개 (변신·치맛자락·그네)

- [ ] 해당 그림을 시작 장면으로 영상 생성(각 5초 안팎), `clips/`에 저장.
- 통과 기준: 3컷 모두 변형·깨짐 없이 재생된다.
