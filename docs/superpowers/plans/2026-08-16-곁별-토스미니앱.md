> **주의:** 이 계획은 두 저장소를 오가고(곁별 웹 = huhsame-script, 미니앱 = metaluca-fresh), 콘솔 등록·API 키·실기기 확인·심사 등 **사용자(루카)가 직접 해야 하는 단계**가 섞여 있다. 그런 단계는 "🙋 사용자 액션"으로 표시했다. 이 특성 때문에 인라인 실행(사용자와 함께 진행)이 권장된다.

**Goal:** 이미 웹으로 배포된 곁별을 앱인토스 미니앱(`gyeotbyeol`)으로 올리고, 내 정령 카드 공유 기능을 더한다.

**Architecture:** 타로 미니앱(`metaluca-fresh/miniapp-tarot`) 패턴을 그대로 따른다. `miniapp-byeol/`에 셸(granite.config·package·sync)을 두고, `sync.mjs`가 곁별 웹 원본(`huhsame-script/landing/byeol`)을 `public/`으로 복사한다. 곁별은 순수 로컬 계산이라 서버 없이 그대로 동작. 토스 웹뷰 맞춤(안전영역·뒤로가기)과 정령 카드 공유(토스 SDK 우선, 폴백 포함)를 곁별 웹에 더한다(웹 배포와 공유).

**Tech Stack:** `@apps-in-toss/web-framework` + vite, ait CLI, 바닐라 JS(곁별), canvas(공유 이미지).

// 번들링하지 않고 public/으로 그대로 복사(vite가 원본 그대로 배포).
import { readFileSync, writeFileSync, mkdirSync, copyFileSync, cpSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const here = dirname(fileURLToPath(import.meta.url));
// 곁별 웹 원본 절대경로 (개인 PC 전용). 경로가 바뀌면 이 상수만 수정.

mkdirSync(join(pub, 'lib'), { recursive: true });

// 클래식 스크립트·스타일·라이브러리 복사
['data.js','saju.js','compat.js','people.js','map.js','app.js','styles.css'].forEach(function (f) {
  copyFileSync(join(src, f), join(pub, f));
});
copyFileSync(join(src, 'lib', 'lunar.js'), join(pub, 'lib', 'lunar.js'));
cpSync(join(src, 'images'), join(pub, 'images'), { recursive: true });

let html = readFileSync(join(src, 'index.html'), 'utf8')
  .replace(/(href|src)="\/byeol\//g, '$1="/');

writeFileSync(join(here, 'index.html'), html);
console.log('miniapp-byeol/index.html + public/ generated from huhsame-script/landing/byeol');

function showScreen(id, fromPop) {
  document.querySelectorAll('.screen').forEach(function (s) { s.classList.remove('active'); });

// 내 정령 카드를 1080x1080 PNG dataURL로 생성 (SVG 정령을 canvas에 그림)
function buildShareCard() {
  return new Promise(function (resolve) {
    var me = state.me, sp = SPIRITS[me.wuxing];
    var W = 1080, H = 1080;
    var cv = document.createElement('canvas'); cv.width = W; cv.height = H;
    var ctx = cv.getContext('2d');
    // 배경(성좌 다크)
    var g = ctx.createRadialGradient(W/2, H*0.42, 60, W/2, H*0.42, W*0.8);
    g.addColorStop(0, '#1b2a5c'); g.addColorStop(0.55, '#0b1330'); g.addColorStop(1, '#05070f');
    ctx.fillStyle = g; ctx.fillRect(0, 0, W, H);
    // 텍스트
    ctx.textAlign = 'center'; ctx.fillStyle = '#eaf0ff';
    ctx.font = 'bold 64px "Malgun Gothic", sans-serif';
    ctx.fillText('나의 오행 정령', W/2, 150);
    ctx.fillStyle = '#ffcf5b'; ctx.font = 'bold 88px "Malgun Gothic", sans-serif';
    ctx.fillText(me.typeName, W/2, 900);
    ctx.fillStyle = '#c8d3f0'; ctx.font = '40px "Malgun Gothic", sans-serif';
    ctx.fillText(sp.el + '(' + sp.hanja + ') 정령 · ' + sp.tagline, W/2, 970);
    ctx.fillStyle = '#9fb0d6'; ctx.font = '38px "Malgun Gothic", sans-serif';
    ctx.fillText('너는 어떤 정령? · 곁별', W/2, 1030);
    // 정령 SVG를 이미지로 로드해 중앙에 그림
    var svg = spiritCharSVG(me.wuxing);
    var img = new Image();
    var url = 'data:image/svg+xml;charset=utf-8,' + encodeURIComponent(svg);
    img.onload = function () {
      var size = 520; ctx.drawImage(img, (W - size)/2, 260, size, size * 108/100);
      resolve(cv.toDataURL('image/png'));
    };
    img.onerror = function () { resolve(cv.toDataURL('image/png')); }; // 정령 없이라도 카드
    img.src = url;
  });
}
```

    // 1) 토스 SDK (미니앱 환경) — 전역에 노출되면 사용
    if (window.AppsInToss && typeof window.AppsInToss.share === 'function') {
      try { window.AppsInToss.share({ message: text, url: pageUrl }); return; } catch (e) {}
    }
    // 2) navigator.share (이미지 파일)로 폴백
    if (navigator.share && navigator.canShare) {
      fetch(dataUrl).then(function (r) { return r.blob(); }).then(function (blob) {
        var file = new File([blob], 'byeol.png', { type: 'image/png' });
        if (navigator.canShare({ files: [file] })) {
          navigator.share({ files: [file], text: text }).catch(function () {});
        } else {
          navigator.share({ text: text, url: pageUrl }).catch(function () {});
        }
      });
      return;
    }
    // 3) 최종 폴백: 링크 복사 + 안내
    try { navigator.clipboard.writeText(text + ' ' + pageUrl); alert('공유 문구를 복사했어요! 붙여넣기 해서 자랑해봐요.'); }
    catch (e) { alert(text + '\n' + pageUrl); }
  });
}
```
**주의:** 토스 SDK의 정확한 전역/호출 방식(`window.AppsInToss.share` vs import)은 공식 문서(developers-apps-in-toss.toss.im)와 실기기로 Task 8 배포 후 확인해 이 분기를 조정한다. 여기서는 "있으면 사용, 없으면 폴백"으로 웹·토스 양쪽에서 안전하게 동작하게 둔다.
