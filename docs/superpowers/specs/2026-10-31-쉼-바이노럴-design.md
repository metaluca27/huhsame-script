# 「쉼」 — 바이노럴 파동 + 자연소리 릴렉스 웹앱 (시제품)

2026-10-31 · 계기: 루카가 본 Anima(바이노럴 비트 앱, 연 6.5만원 구독)

## 목적
마음 편해지는 소리를 들려주는 웹 시제품. 건강·치료 효과는 주장하지 않는다("쉬는 소리").
루카가 며칠 직접 들어보고 플레이 앱으로 키울지 판단하는 게 이번 목표.

## 핵심 원칙
- **소리가 주인공**, 그림은 배경. 대표 장면은 metaluca's time(모닥불+바다).
- 효과 수치·의학 표현 금지 ("불안 75% 감소" 같은 문구 X).
- 로그인·결제·설치 없음.

## 소리 3층
1. **파동(바이노럴)** — Web Audio로 생성. 왼쪽 반송파 f, 오른쪽 f+Δ. 장면별 Δ(4~10Hz)와 반송파(약 150~220Hz).
2. **자연소리** — 상업 이용 가능한 무료 녹음(CC0 또는 Pixabay 라이선스) 5종: 모닥불, 파도, 비, 바람, 숲·시냇물. 반복 이음새 없이 루프. 출처·라이선스는 `landing/shim/sounds/CREDITS.md`에 기록.
3. **음악(앰비언트 패드)** — Web Audio로 느린 화음을 계속 새로 생성(반복 구간 없음).

## 장면 5개
| 장면 | 그림 | 자연소리 | 파동 Δ |
|---|---|---|---|
| 불멍 (기본) | metaluca's time | 모닥불 + 파도 | 6Hz |
| 하루 끝 | 집가는길 | 바람 | 5Hz |
| 멍 | 26.10 달항아리 | 옅은 바람 | 7Hz |
| 밤 생각 내려놓기 | 염소자리 여인의 사색 | 비 | 4Hz |
| 초록 숨 | 매실아님 | 숲·시냇물 | 10Hz |

## 화면
- 첫 화면: 대표 그림 전체 배경, 가운데 큰 ▶, "🎧 이어폰을 끼면 파동이 더 잘 느껴져요".
- 하단: 장면 카드 5개(썸네일). 누르면 그림·소리 3초 크로스페이드.
- 믹서: 파동/자연소리/음악 슬라이더 3개.
- 타이머: 15·30·60분·무한. 끝날 때 60초 페이드아웃.
- 모바일 세로 화면 우선.

## 파일
`landing/shim/` — index.html, app.js(UI), audio.js(소리 엔진), img/(장면 그림 축소본), sounds/(자연소리 + CREDITS.md).

## 확인 방법
- 로컬 서버에서 열어 콘솔 오류 없음, 장면 전환·슬라이더·타이머 동작 확인.
- 파동: 좌우 채널에 실제로 다른 주파수가 나가는지 코드로 확인.
- 최종 "듣기 좋은가"는 루카가 이어폰으로 판단.

## 범위 밖
