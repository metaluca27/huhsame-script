# my scan2677 — 스캔(OCR) 웹앱 설계서

날짜: 2026-07-07
상태: 사용자 승인 대기

## 한 줄 요약

사진을 올리면 글자를 뽑아주는 모바일 웹앱. 인쇄물 추출·손글씨 인식·번역 세 모드를
기존 Cloudflare 워커 + Gemini 비전 한 번 호출로 처리한다.

## 목표

- 문서·간판 사진 → 텍스트 추출
- 손글씨 메모 → 텍스트 변환
- 사진 속 글자 → 선택한 언어로 번역 (한국어/영어/일본어/중국어, 기본 한국어)
- 결과 텍스트: 복사, 공유, .txt 다운로드, 최근 기록 저장

## 결정 사항

| 항목 | 결정 |
|---|---|
| 앱 이름 | my scan2677 |
| 형태 | 웹앱 (기존 방식) — `vaulted-bus-346411.web.app/scan` |
| 엔진 | 방식 A: Gemini 비전 단일 엔진 (기존 워커 경유, Claude 예비) |
| 프론트 | `landing/scan/index.html` 단일 파일 (타로·카드 앱과 동일 패턴) |
| 백엔드 | 기존 워커(`docs/worker/worker.js`)에 `POST /scan` 엔드포인트 추가 |

## 전체 구조

```
폰 브라우저 (landing/scan/index.html)
   → 사진 촬영/갤러리 선택 → 브라우저에서 축소·압축 (긴 변 1600px, JPEG)
   → POST /scan  { image(base64), mode, targetLang? }
      → Gemini 비전 호출 (모드별 프롬프트)  ※ GEMINI_API_KEY 없으면 Claude로 폴백
   ← { text, translation? }  JSON
```

## 화면 구성

탭 3개:

1. **문서** — 인쇄물·간판 텍스트를 원문 그대로 추출. 줄바꿈·문단 유지.
2. **손글씨** — 손으로 쓴 메모를 텍스트로 변환. 판독 불확실한 글자는 `[?]`로 표시.
3. **번역** — 텍스트 추출 후 대상 언어로 번역. 언어 선택: 한국어(기본)/영어/일본어/중국어.
   결과 화면에 원문과 번역문을 함께 표시.

사진 입력: `<input type="file" accept="image/*">` 로 카메라 직접 촬영과 갤러리 선택
모두 지원.

## 결과 화면 기능

- 텍스트 박스 (수정 가능)
- **복사** 버튼 (클립보드)
- **공유** 버튼 (`navigator.share`, 미지원 브라우저는 복사로 대체)
- **.txt 다운로드** 버튼 (파일명: `scan_YYYYMMDD_HHMM.txt`)
- **기록**: 최근 20건을 localStorage에 자동 저장. 저장 항목은 텍스트·모드·시각만
  (이미지는 저장하지 않음 — 용량·프라이버시). 기록 목록에서 다시 보기·삭제 가능.

## 워커 API 명세

`POST /scan`

요청:
```json
{ "image": "<base64 JPEG>", "mode": "document | handwriting | translate", "targetLang": "ko" }
```

응답 (성공):
```json
{ "text": "추출된 원문", "translation": "번역문 (translate 모드일 때만)" }
```

응답 (실패): `{ "error": "사용자에게 보여줄 한국어 메시지" }` + 적절한 HTTP 상태 코드.

- 모드별 시스템 프롬프트로 Gemini에 이미지+지시 전달. 글자가 없으면 text를 빈 문자열로.
- 기존 엔드포인트(/triage, /recipe, /tarot, /hospitals)와 CORS·키 처리 방식 동일.

## 에러 처리

- AI 호출 실패·무료 한도 초과: "잠시 후 다시 시도해주세요" + 재시도 버튼
- 글자 없는 사진: "사진에서 글자를 찾지 못했어요" 안내
- 업로드 전 클라이언트 축소로 요청 크기 초과는 원천 차단
- 앱 하단 고지 한 줄: 사진은 인식 처리에만 쓰이고 저장되지 않음

## 범위 밖 (이번에 안 함)

- 서버 저장·계정·로그인
- PDF/여러 장 일괄 스캔
- 표·영수증 구조 인식 (텍스트 추출까지만)
- 설치형 앱 / PWA 설정

## 확인 방법

배포 후 폰 브라우저에서 세 종류 사진으로 실사용 테스트:
① 인쇄물(책/전단), ② 손글씨 메모, ③ 외국어 간판 → 번역.
복사·공유·다운로드·기록 각 버튼 동작 확인.
