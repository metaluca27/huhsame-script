# 다락방 그림창고 · 모닥불 전시장 (Three.js) 설계

## 왜
- Foresto(신생 플랫폼)·Spatial(2026-07 종료로 소멸)처럼 남의 땅이 아닌, 루카 사이트에 영구 전시장을 둔다.
- Foresto = 사람 오는 동네 전시장, 이 전시장 = 영구 본진. 이력서·명함·공모전 신청서에 링크.

## 콘셉트
- 사라진 Spatial 전시장의 부활: 밤 풀밭, 가운데 모닥불·통나무, 그림 12점이 흰 액자로 불을 원형으로 둘러섬, 위로 별하늘, 멀리 산 능선.
- 불은 일렁이고 불티가 올라가며, 불빛(점광원)이 깜빡이며 그림을 은은하게 비춘다.

## 구경 방식
- 첫 화면: 제목 「다락방 그림창고」 + 입장하기 버튼(BGM 재생 허용 위해).
- 입장 후 카메라는 원 안쪽에서 그림을 바라봄. 스와이프 / ◀ ▶ / 키보드 화살표로 다음 그림 앞으로 카메라가 원을 따라 부드럽게 이동.
- 그림 앞에 서면 하단 작품 카드: 제목·연도·한두 줄 이야기.
- 그림 탭 → 2D 확대 보기(원본 비율, 닫기).
- BGM: Foresto용 피아노 3분 곡, 음소거 버튼.

## 기술
- 위치: `landing/gallery/` → vaulted-bus-346411.web.app/gallery
- Three.js(고정 버전, CDN import map). 풍경은 전부 코드 생성(외부 3D 모델 없음).
- 작품 이미지는 긴 변 1600px JPG로 줄여 `landing/gallery/art/`에. 원본은 건드리지 않음.
- 작품 데이터(파일·제목·연도·이야기)는 `artworks.js` 한 곳에 모아 루카가 문구만 고치기 쉽게.
