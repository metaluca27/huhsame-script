# 나좀봐 설계 문서

날짜: 2026-07-25
상태: 사용자 승인 (대화로 설계 확정)

## 개요

청각장애인·발화가 어려운 사용자를 위한 대화 도우미 웹앱.
상대방의 말을 실시간 큰 자막으로 보여주고(듣기), 내가 타이핑한 문장을
선택한 "내 목소리"로 대신 말해준다(말하기). 킬링보이스(/voice)와 별개 앱이며,
킬링보이스는 콘텐츠 제작용으로 그대로 유지한다.

이름의 의미: 대화를 시작할 때 "나 좀 봐요" 하고 주의를 끄는 순간 +
자막을 보려면 화면(나)을 봐야 한다는 중의.

향후 앱인토스(토스 미니앱) 포팅 대상은 이 앱이다. 웹 버전을 먼저 완성해
다듬은 뒤 포팅한다 (포팅은 별도 프로젝트).

## 사용자 흐름

### 첫 실행
1. 환영 화면에서 "내 목소리" 선택 (8종 프리셋, 미리듣기 가능)
2. 선택 즉시 대화 화면으로. 이후 실행 시엔 바로 대화 화면

### 대화 화면 (단일 화면, 두 구역)
- **위 = 귀 구역**: "듣기" 버튼을 누르면 상대방 말이 실시간 큰 자막으로 표시.
  브라우저 내장 음성인식(SpeechRecognition) 사용 — 마주톡에서 검증된 패턴.
  인식 중 중간 결과도 흐리게 표시해 즉각 반응이 보이게 한다.
- **아래 = 입 구역**: 텍스트 입력 → "말하기" 버튼 → 폰 스피커로 내 목소리 재생.
  기존 워커 `/voice/tts` 재사용 (preset = 내 목소리, tone = calm 고정).
- **자주 쓰는 말 바**: 입력창 위에 가로 스크롤 칩. 탭 한 번에 즉시 재생.

### 자주 쓰는 말
- 기본 제공: "안녕하세요", "감사합니다", "천천히 말씀해 주세요",
  "글로 써주시겠어요?", "네", "아니요", "잠시만요", "얼마예요?"
- 사용자 추가/삭제 가능 (localStorage 저장)
- 방금 말한 문장을 원터치로 자주 쓰는 말에 추가 가능

### 설정
- 내 목소리 변경 (8종 + 미리듣기)
- 자주 쓰는 말 관리

## 기술 구조

### 프론트엔드
- `landing/look/index.html` 단일 파일, 바닐라 JS (기존 앱 관례)
- 배포: `vaulted-bus-346411.web.app/look`
- 듣기: `window.SpeechRecognition || webkitSpeechRecognition`, lang=ko-KR,
  interimResults=true, continuous=true(길게 듣기). 미지원 브라우저는
  안내 문구 표시 (말하기 기능은 계속 동작)
- 말하기: `POST /voice/tts` → base64 PCM → WAV Blob → Audio 재생
  (킬링보이스의 pcmToWavBlob 패턴 재사용)
- 저장: localStorage — 내 목소리(look_voice), 자주 쓰는 말(look_phrases),
  오디오 캐시(look_cache_*)

### 오디오 캐싱 (한도 절약 핵심)
- 캐시 키: `목소리ID:문장텍스트`
- 같은 문장 재요청 시 TTS 호출 없이 캐시 재생
- localStorage 용량(약 5MB) 고려: 캐시는 자주 쓰는 말 + 최근 발화 위주로
  최대 30개, 초과 시 오래된 것부터 삭제 (자주 쓰는 말 캐시는 우선 보존)

### 백엔드
- 수정 없음. 기존 워커 `/voice/tts` 그대로 사용

## 오류 처리

- 음성인식 미지원/권한 거부 → "이 브라우저에선 자막 기능을 쓸 수 없어요.
  상대방에게 화면의 키보드로 입력을 부탁해보세요" 안내
- TTS 실패(한도 등) → 문장을 큰 글씨로 전체화면 표시하는 "글자로 보여주기"
  폴백 제공 (소리는 못 내도 대화는 이어지게)
- 오프라인 → 캐시된 자주 쓰는 말은 재생 가능, 새 문장은 글자 표시 폴백

## 접근성 원칙

- 자막·버튼 모두 큰 글씨, 고대비. 최소 터치 영역 넉넉하게
- 재생 중 시각 피드백(파형 애니메이션 등)으로 "지금 소리가 나가고 있음"을
  화면으로 확인 가능하게 (사용자 본인이 소리를 못 들을 수 있으므로 필수)
- 용어: 앱 문구에서 "농아" 대신 "청각장애인/농인" 사용

## 범위 밖 (YAGNI)

- 앱인토스 포팅 (웹 완성 후 별도 프로젝트)
- 대화 기록 저장/동기화, 계정
- 다국어 (한국어만)
- 수어 관련 기능

## 성공 기준

- 상대방이 말하면 1초 내에 자막이 뜨기 시작한다
- 타이핑한 문장이 내 목소리로 스피커에서 재생된다
- 자주 쓰는 말은 두 번째부터 TTS 호출 없이(캐시) 즉시 재생된다
- 소리가 나가는 동안 화면으로 재생 상태를 확인할 수 있다
