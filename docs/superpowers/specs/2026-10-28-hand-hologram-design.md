# 손 홀로그램 — 설계 (2026-10-28)

CONNECT AI LAB 4주차 라이브(01:10~02:00)에서 손바닥을 펴면 캥거루가 뿅 나오는 장면을 보고 "나도 가능?" → 만들기로.

## 목적
- 1단계: 루카가 웹캠 앞에서 찍는 **디지털 다락방 숏츠** 촬영용.
- 2단계(나중): 놀이터 `/hand` 공개용으로 다듬기 (폰·권한 안내·가벼운 로딩).

## 화면
- 웹캠 화면(거울 반전) 위에 3D 캐릭터를 겹친다.
- 캐릭터는 **푸른 반투명 홀로그램**: 테두리 빛(프레넬), 위로 흐르는 스캔라인, 가끔 지지직.
- 손바닥 가운데 위에 뜨고, 손을 따라가고, 손이 카메라에 가까우면 커진다.

## 손동작 (한 손)
| 동작 | 결과 |
|---|---|
| 손가락 1 | 푸름이 선택 (구석 이름표 반짝) |
| 손가락 2 | 루릭 선택 |
| 손가락 3 | CLO 선택 |
| 손가락 4 | 주주야 선택 |
| 손바닥 쫙(5) | 고른 친구 등장 — 빛 기둥 + 반짝이 + 효과음 |
| 주먹(0) | 흩어지며 사라짐 |

같은 동작이 약 0.3초 유지돼야 인식(흔들림 방지).

## 촬영
- ⏺ 녹화 버튼: 화면을 세로 9:16으로 녹화해 파일 저장 (MediaRecorder).
- 효과음(뿅·지잉)은 Web Audio로 합성 — 저작권 걱정 없음.

## 재료
- 손 인식: MediaPipe Tasks Vision HandLandmarker (브라우저 안에서만, 영상 외부 전송 없음).
- 3D: Three.js (GLTFLoader + DRACOLoader).
- 캐릭터: 푸름이 = 오늘 만든 서 있는 인형(`tools/pureum-box-sim/figure`, 가는 수염 포함)을 GLB로,
  루릭·CLO·주주야 = 3D 사무실 앉은 인형(`tools/ai-office-3d/web/characters/char_*.glb`).
- 위치: `tools/hand-hologram/`. 2단계 때 `landing/hand` 로 배포.
