# 리버스 스와이프 (Reverse Swipe) — 게임 설계 문서

**날짜:** 2026-07-04
**상태:** 사용자 승인 완료

## 개요

60초 시간제 반사신경 스와이프 게임. 모바일 웹 기준으로 만들고 Firebase Hosting(`landing/game/`)으로 배포한다. 나의 냥이봇들 캐릭터 루릭·푸름이가 게임 안에 등장한다.

## 게임 규칙

- **한 판 = 60초.** 화면 중앙에 화살표(상/하/좌/우)가 하나씩 등장한다.
- **파란 화살표**: 화살표 방향 그대로 스와이프하면 정답.
- **빨간 화살표**: 화살표 반대 방향으로 스와이프해야 정답.
- 정답: 기본 +10점 × 콤보 배율. 오답 또는 화살표별 응답 제한시간 초과: 0점, 콤보 리셋.
- **콤보 배율**: 연속 성공 5회마다 배율 상승 — 0~4콤보 ×1, 5~9콤보 ×2, 10~14콤보 ×3, 15콤보 이상 ×4 (최대).
- **피버 모드**: 10콤보 달성 시 5초간 발동. 피버 중 점수는 콤보 배율에 **추가로 2배** (점수 = 10 × 콤보 배율 × 2). 배경 이펙트 강화. 피버 중 오답은 콤보를 리셋하지 않고(콤보 유지) 피버만 즉시 종료한다. 피버 종료 후 다시 10콤보 경계를 넘으면 재발동 가능.
- **응답 제한시간**: 화살표당 시작 2.0초, 판이 진행되며 서서히 감소해 최소 0.8초. (60초 경과 시간에 비례해 선형 감소)
- **화살표 전환**: 스와이프(정답/오답) 또는 제한시간 초과 즉시 다음 화살표가 등장한다. 화살표 사이 대기 시간 없음 — 빠른 템포 유지.
- 빨간 화살표 등장 비율: 약 30% (랜덤).

## 화면 흐름

1. **시작 화면**: 게임 타이틀, 루릭·푸름이 캐릭터, 최고 점수, 규칙 요약(파랑=그대로 / 빨강=반대), 시작 버튼.
2. **플레이 화면**:
   - 상단: 남은 시간 바(60초), 현재 점수, 현재 콤보/배율.
   - 중앙: 현재 화살표 (파랑/빨강, 방향 명확하게 크게).
   - 하단 구석: 루릭 원형 아바타 + 말풍선 코멘트.
   - 정답/오답 시 즉각적인 시각 피드백(플래시, 흔들림 등 CSS 애니메이션).
3. **결과 화면**: 푸름이 아바타 + 슬랙 알림 스타일 카드로 최종 점수·최대 콤보 표시. 신기록 갱신 시 축하 문구. 다시하기 버튼.

## 냥이봇 캐릭터

캐릭터 성격은 나의 냥이봇들 세계관을 따른다.

- **루릭 (플레이 중 코멘터리)** — 까칠하고 말 짧음. 이모지·감탄사 없음.
  - 상황별 대사 풀(각 3~4종)에서 랜덤 출력: 게임 시작("...시작함"), 미스("그걸 틀림?", "(한숨)"), 콤보 달성("나쁘지 않음"), 피버 돌입("오. 좀 치네") 등.
- **푸름이 (결과 전달)** — 쿨하고 간결한 알림 스타일.
  - 결과 카드: "푸름이: 결과 전달했어요 — {점수}점 · 최대 {콤보}콤보"
  - 신기록: "푸름이: 신기록 갱신 알림 보냈어요"

## 기술 구조

- **바닐라 JS + HTML + CSS 단일 파일** (`landing/game/index.html`) + 캐릭터 이미지 2장. 프레임워크·빌드 도구 없음.
- 내부 모듈 분리 (한 파일 안에서 역할별로 구분):
  1. **게임 상태 머신**: `start → playing → (fever) → result` 상태 전환, 타이머, 점수·콤보 계산.
  2. **입력 처리**: 터치 스와이프 감지(터치 시작/끝 좌표로 4방향 판정) + 데스크톱용 방향키 지원.
  3. **렌더링/이펙트**: DOM + CSS 애니메이션 (캔버스 미사용). 루릭 말풍선, 피버 이펙트, 정답/오답 피드백.
- **최고 점수 저장**: `localStorage`.
- **모바일 최적화**: 뷰포트 고정(`user-scalable=no`), `touch-action: none`으로 스크롤/당겨서 새로고침 방지, 세로 화면 기준 레이아웃, 375px 폭 기준 검증.

## 배포

- 기존 Firebase Hosting(`public: landing`)에 그대로 얹는다 → `landing/game/index.html` = `사이트주소/game`.
- 추가 Firebase 설정 변경 불필요 (`cleanUrls: true`라 `/game`으로 접근 가능).

## 테스트/검증

로컬 프리뷰 서버로 구동하여 다음을 확인한다:

- 4방향 스와이프 판정 (파랑=그대로, 빨강=반대)
- 콤보 배율 단계(×1→×4) 및 피버 발동/종료 조건
- 60초 타이머 종료 → 결과 화면 전환
- 최고 점수 localStorage 저장/갱신
- 루릭 대사 출력, 푸름이 결과 카드
- 모바일 뷰포트(375px)에서 레이아웃과 스와이프 시 화면 스크롤 방지
