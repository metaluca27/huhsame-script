# 킬링보이스 설계 문서

날짜: 2026-07-23
상태: 사용자 승인 대기

## 개요

텍스트 또는 녹음된 말을 남녀노소 다양한 목소리로 변환해 주는 웹앱.
콘텐츠 제작용(캡컷 등 영상 편집에 얹는 나레이션)이 주 용도이며,
결과물은 고품질 WAV 파일로 다운로드할 수 있다.

## 사용자 흐름

1. 입력 — 두 가지 모드
   - **텍스트 모드**: 텍스트박스에 대본을 직접 입력
   - **녹음 모드**: 마이크로 녹음 → Gemini가 받아적기(STT) → 텍스트박스에
     자동 입력 → 사용자가 자유롭게 수정 (말 더듬, "어…" 제거 등)
2. 목소리 선택 — 프리셋 8종 중 택 1
3. 말투 선택 — 4종 중 택 1 (기본: 차분하게)
4. 변환 버튼 → Gemini TTS가 음성 생성
5. 미리 듣기 재생 + WAV 다운로드 (모바일 포함)

## 목소리 프리셋 (8종)

|      | 남              | 여              |
|------|-----------------|-----------------|
| 아이 | 개구쟁이 소년   | 똑부러진 소녀   |
| 청년 | 차분한 청년     | 밝은 아가씨     |
| 중년 | 묵직한 아저씨   | 다정한 아줌마   |
| 노년 | 인자한 할아버지 | 구수한 할머니   |

- 각 프리셋 = Gemini TTS 보이스 이름 + 스타일 프롬프트 조합
- 실제 보이스 매핑은 구현 단계에서 청취 테스트로 확정

## 말투 옵션 (4종)

차분하게 / 신나게 / 속삭이듯 / 뉴스 앵커처럼
— 스타일 프롬프트에 덧붙여 같은 목소리의 분위기를 바꾼다.

## 기술 구조

기존 앱들(타로/스캔/마주톡)과 동일한 패턴을 따른다.

### 프론트엔드
- 위치: `landing/voice/index.html` (단일 파일, 바닐라 JS)
- 배포: Firebase Hosting `vaulted-bus-346411.web.app/voice`
- 녹음: MediaRecorder API (마주톡에서 검증된 마이크 처리 패턴 재사용)
- 다운로드: TTS 결과(PCM)를 브라우저에서 WAV 헤더 붙여 Blob 다운로드

### 백엔드 (공용 Cloudflare Worker)
- 파일: `docs/worker/worker.js` — `small-recipe-9345.atlia0318.workers.dev`
- 엔드포인트 2개 추가:
  - `POST /voice/stt` — 녹음 오디오(base64) → Gemini 오디오 이해로 받아적기 → 텍스트 반환
  - `POST /voice/tts` — 텍스트 + 프리셋 + 말투 → Gemini TTS → 오디오(base64 PCM) 반환
- 키: 기존 `GEMINI_API_KEY` 그대로 사용 (추가 결제 없음)
- 배포: `wrangler deploy` 한 줄

### 데이터 흐름
```
[브라우저] 녹음/텍스트 → [워커 /voice/stt] → 텍스트 → (사용자 수정)
[브라우저] 텍스트+프리셋 → [워커 /voice/tts] → PCM 오디오 → WAV 저장/재생
```

## 오류 처리

- 마이크 권한 거부 → 텍스트 모드로 안내
- STT/TTS 실패(한도 초과 등) → "잠시 후 다시 시도" 안내 문구
- 긴 텍스트: TTS 요청당 글자 수 상한을 두고 초과 시 안내 (상한값은 구현 시 테스트로 결정)

## 제약/비용

- Gemini TTS 무료 한도는 일일 생성량 제한이 있음. 개인 콘텐츠 제작용으로는
  충분하나, 공개 후 다수 사용 시 한도 도달 가능 → 그때 대응 (지금은 범위 밖)

## 범위 밖 (YAGNI)

- 억양·감정 보존형 실시간 음성변조 (ElevenLabs 등 유료 API)
- 사용자 목소리 클로닝
- 생성 이력 저장/계정 기능

## 성공 기준

- 텍스트만 입력해도, 녹음만 해도 8종 목소리로 변환된다
- 결과 WAV를 폰/PC에서 다운로드해 캡컷에 바로 쓸 수 있다
- 기존 워커 키로 추가 비용 없이 작동한다
