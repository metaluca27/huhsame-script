## 집필 워크플로 (챕터 단위 반복)

1. 챕터별 인터뷰 질문 5~8개 제시 (당시 감정, 구체적 사건, 기억나는 대화·에러)
2. 답변 기반 확장 집필 — 톤: 실패담·진행형 서사 그대로, 결말 억지 봉합 금지
3. 사용자 검토 → 수정 → 다음 챕터
4. 집필 순서: 1부(NFT)부터 — 책의 서사적 뼈대를 먼저 세움
