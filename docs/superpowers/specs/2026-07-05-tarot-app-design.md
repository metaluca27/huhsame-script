# 심연의 타로 — 심층 타로 분석 웹앱 설계서

날짜: 2026-07-05
상태: 사용자 승인 대기

## 개요

타로카드 78장을 터치로 5장 뽑고, 상황 설명을 입력하면 타로 + 점성학(조디악) + 수비학
세 축을 결합해 심층 해석을 제공하는 웹앱. 카드의 기본 의미는 내장 데이터로 즉시
표시하고(정적), "심층 리딩"은 AI가 사용자 상황에 맞춰 생성한다(하이브리드).

## 배포와 구조

- 위치: 이 저장소 `landing/tarot/` — 기존 `/game`, `/cards`와 동일한 정적 페이지 방식
- 배포: Firebase Hosting → https://vaulted-bus-346411.web.app/tarot
- 파일 구성:
  - `index.html` — 단일 페이지 (시작 → 셔플 → 선택 → 공개 → 해석 화면 전환)
  - `styles.css` — 스타일 (신비로운 다크 테마)
  - `app.js` — 화면 전환, 셔플/선택/공개 로직, 별자리·수비학 계산, AI 호출
  - `cards-data.js` — 78장 카드 데이터 (이름·정/역방향 의미·키워드·점성학 대응·숫자)
  - `images/` — 라이더-웨이트 원본 78장(webp 최적화) + 카드 뒷면 1장
- 백엔드: 서버 없음. AI 심층 해석만 공용 Cloudflare Worker `small-recipe-9345`의
  신규 `/tarot` 엔드포인트 호출

## 안내 캐릭터: 푸름이

디지털 다락방 세계관의 슬랙 봇 고양이 "푸름이"가 앱 전체의 안내자 역할을 한다.

- 이미지: `landing/cards/img/pureum.png` (투명 배경, 다락방 짝꿍 찾기에서 사용 중)를
  `landing/tarot/images/`로 복사해 사용
- 말투: 쿨하고 간결한 알림 스타일 (예: "생년월일 알려주면 별자리까지 봐요",
  "5장 골라요", "리딩 준비 완료"). 감탄사·호들갑 없음.
- 등장 지점:
  - 시작 화면: 푸름이 + 말풍선으로 앱 소개와 입력 안내
  - 카드 선택 화면: 남은 선택 장수 안내 ("3장 남았어요")
  - AI 로딩 중: "카드 읽는 중..." 류의 대기 멘트
  - 심층 리딩 도착: "리딩 전달 완료" 후 결과 표시

## 사용자 흐름

1. **시작 화면** — 푸름이가 말풍선으로 안내
   - 생년월일 입력 (선택사항 — 별자리·라이프패스 넘버 계산용)
   - 상황/고민 설명 입력란 (선택사항 — AI 해석 맞춤화용)
   - "카드 뽑으러 가기" 버튼
2. **셔플**: "카드 섞기" 터치 → 셔플 애니메이션
3. **카드 선택**: 뒷면 카드 78장이 부채꼴로 펼쳐짐 → 터치로 5장 선택
   (선택할 때마다 카드가 스프레드 자리로 이동)
4. **공개**: 카드가 한 장씩 뒤집히는 애니메이션과 함께 5장 스프레드 완성
   - 포지션: ① 현재 상황 ② 장애물 ③ 과거의 뿌리 ④ 조언 ⑤ 예상 결과
   - 각 카드의 정/역방향은 뽑을 때 랜덤 결정 (역방향은 이미지 180° 회전 표시)
5. **즉시 해석 (정적)**: 각 카드를 탭하면 카드 상세 패널 표시
   - 카드 이름(한/영), 정 또는 역방향 의미, 키워드
   - 점성학 대응 (행성/별자리/원소)
   - 카드 숫자의 수비학 의미
   - 별도 요약 영역: 내 별자리(입력 시), 라이프패스 넘버, 5장 숫자 합산 "리딩 넘버"
6. **심층 리딩 (AI)**: "심층 리딩 보기" 버튼 → 로딩 표시 → AI 해석 표시
   - 전달 데이터: 상황 설명, 5장 카드(포지션·방향 포함), 별자리, 라이프패스 넘버,
     리딩 넘버
   - 응답: 포지션별 흐름을 엮은 종합 리딩 + 점성학·수비학 관점 코멘트 + 조언

## 세 가지 분석 축 데이터

### 타로 (cards-data.js)
78장 각각: `id, nameKo, nameEn, arcana(major/minor), suit, number, upright, reversed,
keywords[], astro(대응 행성·별자리·원소), image` 필드를 가진 정적 배열.
메이저 22장 + 마이너 56장(완드·컵·소드·펜타클 각 14장).

### 점성학
- 카드별 전통 대응(골든던 체계): 예) 황제=양자리, 탑=화성, 컵=물 원소
- 생년월일 → 12궁 별자리 계산은 프론트 JS에서 날짜 범위표로 처리
- AI 프롬프트에 "질문자의 별자리와 각 카드 대응의 궁합"을 해석하도록 지시

### 수비학
- 라이프패스 넘버: 생년월일 전체 자릿수 합을 한 자리(또는 마스터 넘버 11·22)까지 축약
- 리딩 넘버: 뽑힌 5장의 카드 숫자 합을 같은 방식으로 축약
  (메이저 아르카나 0~21, 핍 카드 1~10, 궁정 카드는 시종11·기사12·여왕13·왕14로 계산)
- 1~9, 11, 22 각 숫자의 의미 텍스트를 정적 데이터로 내장, AI에도 전달

### 카드 이미지
- 1909년 라이더-웨이트 덱 원본 (퍼블릭 도메인, Wikimedia Commons 등에서 수급)
- 78장 전부 webp로 변환·리사이즈해 용량 최적화, `images/`에 포함
- 뒷면 디자인 1장은 CSS 또는 간단한 SVG로 제작

## AI 워커 (/tarot 엔드포인트)

- 기존 `medi/server/worker.js`(공용)에 `/tarot` 라우트 추가
- 요청(JSON): `{ situation, cards: [{name, position, reversed, astro, number}×5],
  zodiac, lifePath, readingNumber }` — 생년월일 미입력 시 zodiac/lifePath는 null
- 프롬프트: 한국어 타로 리더 페르소나. 포지션 흐름(현재→장애물→과거→조언→결과)을
  하나의 이야기로 엮고, 점성학 궁합과 수비학 숫자를 근거로 인용하도록 지시.
  null인 축은 언급하지 않도록 지시.
- 모델: 기존과 동일 (Gemini `gemini-3.5-flash`, Anthropic 폴백)
- `maxOutputTokens: 4096` — thinking 토큰이 출력을 잘라먹던 기존 버그 재발 방지
- 배포: 수정된 worker.js를 Cloudflare 대시보드에 붙여넣고 Deploy (기존 수동 절차,
  단계별 안내 제공)

## 에러 처리

- AI 호출 실패/타임아웃: 정적 해석은 유지된 채 "심층 해석을 불러오지 못했어요"
  메시지 + 다시 시도 버튼. 앱 전체는 계속 동작.
- 생년월일 미입력: 별자리·수비학 축 없이 타로만으로 정상 동작 (UI에서 해당 요약
  숨김, AI 프롬프트에서 생략)
- 상황 설명 미입력: 일반 리딩으로 진행 (AI에 "일반 운세 리딩" 모드 지시)

## 테스트/검증

- 로컬에서 브라우저 미리보기로 전체 흐름(입력→셔플→5장 선택→공개→정적 해석) 확인
- 수비학·별자리 계산은 경계값(12/31, 마스터 넘버 생일 등) 수동 검증
- `/tarot` 워커는 배포 후 curl 테스트 → 프론트 연동 확인
- 모바일 뷰포트(375px)에서 부채꼴 선택 UI 조작성 확인
