# 허허서방 채널 · 1편 「머슴 돌쇠와 낡은 부채」 설계

작성: 2026-09-15 · 채널: 유튜브 **허허서방** @허허서방 (개설·채널아트 완료)

## 1. 목표

- 60~70대(+잠잘 때 틀어두는 40~50대)가 **틀어두고 끝까지 듣는** 20분짜리 역전 야담 1편을 만든다.
- 판단 기준은 **롱런 + 수익창출**. 한 편을 루카가 버스트 한두 번에 끝낼 수 있는 품이어야 하고, 2편부터는 대본·그림 프롬프트만 바꿔 같은 도구로 찍어낼 수 있어야 한다.
- 수십 개 AI 야담 채널과 **한눈에 구분**돼야 한다: 화면에 나오는 이야기꾼 허허서방 + 민화에 루카 아크릴 색감.

## 3. 한 편의 형식

- **길이 20분 내외** (허용 17~23분). 대본 약 5,000자, 느린 낭독 기준 분당 약 250자.
- 3~4편이 쌓이면 이어 붙여 **「허허서방 옛날이야기 모음 1집」(1시간 연속)**으로 한 번 더 올린다. 추가 제작 없음.
- 화면 1920×1080 가로. 소리는 잔잔하게(잠자리 시청자), 배경음악·효과음은 1편에서 넣지 않는다.
- 자막은 크게 굽는다(어르신 가독성). 한 줄 최대 약 24자, 화면 아래 반투명 띠.

### 흐름

| 구간 | 시간(약) | 내용 | 그림 출처 |
|---|---|---|---|
| ① 미리보기 훅 | 0:00~0:30 | 반전 장면을 먼저 보여주고 "그땐 아무도 몰랐지요"로 끊기 | 웹 무제한(반전 장면 재사용) |
| ② 허허서방 인사 | 0:30~1:00 | "허허, 어서들 오시게" → 부채 탁 → 이야기 시작 | 허허서방 포즈 |
| ③ 1막 | 1:00~5:00 | 무시당하는 주인공 + 착한 일(시청자가 응원하게) | Z Image |
| ④ 2막 | 5:00~15:00 | 악역 득세, 주인공 몰림, 반전 복선. 허허서방 끼어들기 2회 | Z Image, 음모 장면은 노을 실루엣 |
| ⑤ 3막 | 15:00~18:00 | 부채 탁! 역전, 사이다 결말 | 웹 무제한(동작 장면) |
| ⑥ 허허서방 한마디 | 18:00~19:30 | 짧은 여운 | 허허서방 포즈 |
| ⑦ 마무리 | 19:30~20:00 | "엽전 대신 구독 한 번" + 엔딩 카드 5초 | 허허서방 포즈 + 실물 작품 |

②⑦의 인사·마무리 대사는 매 편 같은 문장을 쓰고, 음성 파일도 재사용한다.

## 4. 1편 이야기 「머슴 돌쇠와 낡은 부채」

등장인물 3명 + 배경 인물: **돌쇠**(글 모르는 머슴, 20대 후반, 넝마 차림), **최 부자**(욕심 많은 부자, 뚱뚱, 비단옷·갓), **나그네**(초라한 늙은 선비 = 실은 암행어사). 배경: 사또(최 부자와 한패), 마을 사람들.

- **① 훅:** 노을 진 관아 마당, 넝마 입은 머슴 앞에서 비단옷 부자가 무릎 꿇는 장면. "글자 한 자 모르던 머슴이 사흘 뒤 고을 제일 부자를 무릎 꿇린다는 걸, 그땐 아무도 몰랐지요."
- **③ 1막:** 흉년. 돌쇠는 식은 보리밥 한 덩이에 헛간 잠. 굶는 옆집 아이에게 제 밥을 반 나눠 준다(착한 일). 눈 오는 저녁, 최 부자가 문전박대한 나그네를 돌쇠가 헛간으로 들여 살린다. 날이 밝자 나그네는 사라지고 낡은 부채만 남는다. (목소리 테스트 대본을 이어 쓴다.)
- **④ 2막:** 최 부자가 흉년에 곡식값을 올리고, 밤마다 관아 창고 곡식을 자기 곳간으로 빼돌린다(노을·달밤 실루엣). 돌쇠가 우연히 목격하자 최 부자는 돌쇠를 곡식 도둑으로 몰고, 한패인 사또가 돌쇠를 옥에 가둔다. 허허서방 끼어들기: "허허, 여기서 잠깐… 그 낡은 부채, 잊지들 마시게." / "억울한 일은 사흘을 못 간다 했지요."
- **⑤ 3막:** 형벌 직전, 돌쇠가 품에서 부채를 꺼내 들자 구경꾼 사이에서 "암행어사 출두요!" 나그네가 어사였고, 부채는 은인을 알아보라고 남긴 표식. 최 부자 곳간에서 관아 곡식이 나오고, 최 부자와 사또가 무릎 꿇는다. 곡식은 마을로 돌아가고 돌쇠는 억울함을 푼다.
- **⑥ 한마디:** 허허서방이 부채를 펼치며 "허허, 사람 겉만 보고 판단할 일이 아니지요. …그리고 이 부채가 바로 그 부채올시다." → 채널 전설의 시작(허허서방이 누구인지는 열어둔다).

역사 고증은 야담 수준으로만 맞춘다(암행어사·사또·환곡 정도). 실존 인물 이름은 쓰지 않는다.

## 5. 제작 파이프라인

기존 루릭 내레이션 스크립트(`docs/루릭내레이션/tts.py`, `gen_images.py`, `build.py`)를 복사해 **`docs/전래동화/도구/`**에 롱폼용으로 고친다. 루릭 스크립트는 건드리지 않는다.

폴더: `docs/전래동화/01_머슴돌쇠와낡은부채/` (대본.md, prompts.json, 웹프롬프트.md, audio/, images/, timeline.json, draft.mp4, final.mp4)

### 5-1. 대본 형식

루릭은 "문장 1개 = 그림 1장"이었지만 20분은 문장이 200개가 넘으므로 **한 줄에 장면 번호를 따로 둔다.**

```
| 번호 | 장면 | 내레이션 |
| 001 | S01 | 옛날 옛적, 경상도 어느 고을에 돌쇠라는 머슴이 살았습니다. |
| 002 | S01 | 돌쇠는 글자 한 자 읽을 줄 몰랐지만, … |
```

- 한 줄 = 1~2문장, 200자 이내(TTS 한 번 호출 단위, 자막 단위).
- 장면 하나에 보통 3~5줄(약 15~20초). 전체 장면 약 60~70개.

### 5-2. 목소리 (`tts.py` 수정)

- 워커 `/voice/tts`에 `{preset:"middleM", tone:"calm", voice:"Umbriel", style:"구수하고 능청스러운 50대 남자 장터 이야기꾼 목소리로. 낮고 굵은 중저음, 느긋하게 뜸을 들이며 옛날이야기를 풀어내듯"}`. 워커 재배포 없음.
- 번호 3자리 대응, `--only` 재생성, durations.json 병합은 루릭 방식 유지.
- 줄 사이 쉼 0.5초(루릭 0.35초보다 느긋하게), 장면이 바뀌는 줄 앞은 0.9초.
- 검증: 숫자·한자어·따옴표가 든 줄은 `/voice/stt` 왕복으로 받아쓰기 대조.

### 5-3. 그림 (`gen_images.py` 수정 + 웹 수작업)

`prompts.json`의 장면마다 출처 태그를 붙인다.

| 태그 | 뜻 | 만드는 쪽 |
|---|---|---|
| (없음) | 기본 민화·수묵 | CLI Z Image 16:9, 0.15크레딧 |
| `[SIL]` | 노을·달밤 실루엣 스타일 문구로 교체 | CLI Z Image |
| `[WEB]` | 동작이 복잡한 장면 | 스크립트가 `웹프롬프트.md`로 뽑아주면 루카가 힉스필드 웹(Nano Banana + Unlimited + 16:9 + 참고 그림)에서 생성 → 다운로드 → 클로가 `images/S번호.png`로 이름 바꿔 넣기 |
| `[HUH:포즈]` | 허허서방 포즈 라이브러리에서 가져옴 | 복사만 |

- 스타일 문구는 `그림체샘플/A_민화수묵/prompts.txt`, `A+루카/jobs.json`에서 가져온다. Z Image 프롬프트는 800자 미만 유지.
- Z Image는 참고 그림을 못 받으므로 인물 일관성은 옷차림 고정 문구로 잡는다(돌쇠 = "ragged patched gray hemp clothes, straw hat", 최 부자 = "fat man in rich purple silk robe and black gat"). 사람 여럿이 동작하는 장면은 `[WEB]` 또는 `[SIL]`로 보낸다.
- 웹 그림은 Z Image보다 색이 옅으므로 `build.py`에서 채도·한지색 보정을 한 번 거친다.

### 5-4. 허허서방 포즈 라이브러리 (1회 제작, 매 편 재사용)

`docs/전래동화/허허서방/`에 16:9 한지 배경 4장: **인사**(부채 든 채 고개 숙임), **부채탁**(땡땡이 점 튐), **뜸들이기**(부채로 턱 괴고 눈 가늘게), **껄껄**(크게 웃음). 웹 Nano Banana Unlimited로 `03_허허서방부채탁.png`를 참고 그림 삼아 생성. 크레딧 0.

### 5-5. 영상 조립 (`build.py` 수정)

- `audio`: 줄별 wav 합본 + timeline.json(장면 단위로 시작·길이 묶음).
- `video`: 장면 그림마다 **천천히 확대(켄 번스)** — 장면 길이 동안 100%→108%, 방향은 장면마다 번갈아. 1920×1080, 30fps. 끝에 엔딩 카드 5초.
- `subs`: 자막 굽기, 가로 기준 한 줄 약 24자, 맑은 고딕 굵게, 반투명 띠.
- 인트로의 "달항아리에서 점이 피어오르는" 애니메이션은 **1편에서는 만들지 않는다**(부채탁 정지 그림 + 확대로 대신). 2편 이후 검토.

### 5-6. 올리기 (루카 수작업)

- 썸네일 1280×720: 노을 실루엣 또는 반전 장면 + 큰 글자 3줄(루릭 썸네일 방식, 포인트 단어만 강조색).
- 제목 형식: `「이야기 한 줄 훅」 | 야담 | 옛날이야기 | 잠잘때 듣는 이야기`.
- 유튜브 "변경되거나 합성된 콘텐츠" 표시는 민화 그림이라 의무 대상 아님. 채널 설명에 AI 안내 한 줄 있음.

## 6. 비용·시간 예상

- Z Image 약 55장 × 0.15 + 재생성 여유 = **약 10~12크레딧**. 웹 그림·목소리 0원.
- 루카 손이 가는 일: 대본 확인(가장 중요), `[WEB]` 장면 5~8장 웹 생성, 최종 영상 시청, 업로드. 나머지는 클로.

## 7. 확인 방법 (완료 기준)

1. 대본을 루카가 끝까지 읽고 승인 (영상 강사 조언: 대본은 사람이 무조건 다 읽는다).
2. TTS 받아쓰기 대조에서 틀린 줄 0개 (숫자·한자어 줄 전수).
3. 전체 길이 17~23분.
4. 그림 전수 확인: 등장인물 옷차림 일관, 글자 새어 나옴 없음, 팔다리 오류는 재생성 또는 `[SIL]` 전환.
5. final.mp4를 처음부터 끝까지 재생해 소리 끊김·자막 밀림·그림 공백 없음 확인.
6. 루카가 틀어놓고 딴일 하면서 들어도 편한지 최종 판단.

## 8. 범위 밖 (이번에 안 함)
