# 다락방 합체 게임 (가칭 "다락방 머지") 설계

- 작성일: 2026-09-05
- 상태: 설계 승인 완료(루카), 구현 계획 작성 전
- 배포 경로: https://vaulted-bus-346411.web.app/merge (소스 `landing/merge/`)
- 벤치마킹: 개발놀이터 오락실(game.dev-play.kr)의 랭킹 구조. 그 오락실에 등록하는 것이 아니라 자체 랭킹을 만든다.

## 1. 한 줄 요약

수박게임(스이카) 방식으로 다락방 캐릭터를 떨어뜨려 같은 캐릭터끼리 합치며 진화시키는 모바일 웹 게임. 닉네임 기반 전체 랭킹 100위를 공용 클라우드플레어 워커 + KV로 운영한다.

## 2. 게임 규칙

### 2.1 판과 조작
- 세로로 긴 통. 모바일 세로 화면 기준, 카톡 인앱 브라우저의 짧은 화면에서도 통이 잘리지 않게 화면 높이에 맞춰 캔버스를 축소한다(짝꿍 찾기의 innerHeight 대응 방식 재활용).
- 통 위에 "현재 캐릭터"가 떠 있고, 터치(마우스)로 좌우 이동, 손을 떼면 낙하. 낙하 후 약 0.5초 동안은 다음 낙하 불가.
- "다음 캐릭터" 미리보기를 통 위 구석에 표시.

### 2.2 진화 사슬 (11단계)
| 단계 | 이름 | 이미지 | 지름(통 폭 대비) | 합체 점수 |
|---|---|---|---|---|
| 1 | 주주야 | jujuya.png | 8% | 1 |
| 2 | 루릭 | ruric.png | 11% | 3 |
| 3 | 푸름이 | pureum.png | 14% | 6 |
| 4 | 노바 | nova.png | 17% | 10 |
| 5 | 루나 | luna.png | 21% | 15 |
| 6 | 루카 | luka.png | 25% | 21 |
| 7 | 황금 루카 | luka-gold.png | 29% | 28 |
| 8 | 불꽃 루카 | luka-fire.png | 33% | 36 |
| 9 | 우주 루카 | luka-space.png | 37% | 45 |
| 10 | 천사 루카 | luka-angel.png | 41% | 55 |
| 11 | 전설 루카 | luka-legend.png | 45% | 66 |

- 합체 점수는 삼각수(n(n+1)/2). 11단계 둘이 만나면 둘 다 사라지고 보너스 100점.
- 7~11단계는 **전용 그림을 쓴다**(루카 의견: 단계마다 다른 그림이 있어야 보는 즐거움이 있다). 힉스필드 나노바나나 무제한 기간(~2026-09-10)에 `luka-gold.png`, `luka-fire.png`, `luka-space.png`, `luka-angel.png`, `luka-legend.png`를 생성해 투명 배경으로 넣는다. 그림이 아직 없는 단계만 루카 이미지 + 코드 효과로 임시 표시(그림 파일이 생기면 자동으로 그림 우선).
- 1~6단계도 원형 안에 들어가도록 얼굴 중심 크롭을 다시 잡는다(짝꿍 찾기 원본은 전신이라 작은 원에서는 얼굴이 안 보임). 여유가 있으면 나노바나나로 "원형 아이콘용 상반신" 버전을 새로 뽑는다.
- 떨어지는 캐릭터는 1~5단계 중 랜덤(가중치: 1단계 30%, 2단계 25%, 3단계 20%, 4단계 15%, 5단계 10%).

### 2.3 합체와 점수
- 같은 단계 원 둘이 닿으면 두 원의 중점 위치에 다음 단계 원 하나 생성. 같은 프레임에 여러 쌍이 닿으면 한 원은 한 번만 합체(중복 방지).
- 콤보: 직전 합체로부터 1.5초 이내 다시 합체하면 콤보 +1. 콤보 배율 = 1 + 0.25 × (콤보 − 1), 최대 ×3. 점수 = 단계 점수 × 배율(내림). 5콤보 이상이면 피버 표시(배율 변화 없음, 연출만).
- 화면 상단 HUD: 현재 점수, 콤보, 최고 점수(폰 저장).

### 2.4 게임 오버
- 통 위쪽에 경계선. 어떤 원이든 경계선 위에 1.5초 이상 머물면 게임 오버. 경계선 근접 시 경고 연출(§3).
- 게임 오버 시 원들이 한 번에 떨어져 내리는 붕괴 연출 후 결과 화면.

### 2.5 캐릭터 개입 (기존 게임 톤 재활용)
- 이번 판에서 5단계 이상을 처음 만들면 잠깐 멈추고 "○○ 등장!" 팝업 + 캐릭터 대사 1줄(캐릭터별 3종 랜덤).
- 게임 오버: 루릭이 까칠 코멘트. 결과 전달: 푸름이.
- 결과 화면에 "이번 판에 만난 캐릭터" 도감 아이콘 줄(만든 단계는 컬러, 못 만든 단계는 실루엣).

## 3. 도파민 연출

- 합체: 두 원이 서로 끌려 붙고, 새 원이 1.3배로 커졌다가 1.0으로 줄어드는 등장. 그 단계 색 파티클 폭발. 단계가 높을수록 파티클 수와 화면 흔들림 증가.
- 소리: 파일 없이 Web Audio 합성(리버스 스와이프 방식). 합체음은 단계마다 음정 한 칸씩 상승(C4부터 온음계). 콤보음, 피버 진입음, 경고 저음(심장박동), 게임 오버 하강음, 신기록 팡파르.
- 콤보 텍스트: 화면 중앙에 "×2 COMBO" 튀어나왔다 사라짐. 5콤보 이상 화면 테두리 발광.
- 위험 신호: 경계선 근접 시 선이 빨갛게 깜빡이고 심장박동 저음.
- 소리 토글 버튼(🔊/🔇) 우상단, 상태는 폰에 저장.

## 4. 랭킹 시스템

### 4.1 화면 흐름
- 결과 화면: 점수 · 최고 콤보 · 만난 캐릭터 → 이번 점수가 전체 100위 안이면 "이름 남기기" 입력창(닉네임 최대 10자, 폰에 저장되어 다음부터 자동 채움) → 등록하면 "전체 N위!" 표시.
- 100위 밖이면 등록 없이 "100위까지 OOO점 남았어요".
- 시작 화면·결과 화면에 "🏆 랭킹" 버튼 → 전체 100위 목록(순위·닉네임·점수·최고콤보). 내 닉네임 행 강조.
- 주간 랭킹·업적·로그인은 이번 범위 밖.

### 4.2 워커 API (공용 워커 `small-recipe-9345`, 파일 `docs/worker/worker.js`)
- `GET /merge/rank` → `{ ok, top: [{ name, score, combo, at }], updatedAt }` (최대 100건, 점수 내림차순). CORS 허용.
- `POST /merge/rank` 본문 `{ name, score, combo, merges, stages }`
  - `name`: 1~10자, 앞뒤 공백 제거, 제어문자 제거. 비속어 필터는 이번 범위 밖.
  - `score`: 0 이상 정수. `combo`: 최고 콤보(정수). `merges`: 총 합체 횟수. `stages`: 단계별 합체 횟수 배열(11칸).
  - 검증: (a) 단계별 점수 × 최대 배율 ×3으로 계산한 상한 이상이면 거절 (b) `merges`가 `stages` 합과 다르면 거절 (c) 같은 IP에서 1초 1회 초과 시 429 (d) 점수가 100위 밖이면 저장하지 않고 `{ ok, ranked: false, cutoff }` 반환.
  - 성공: `{ ok, ranked: true, rank: N }`.
- 저장: KV 네임스페이스 `MERGE_RANK`, 키 `top` 하나에 상위 100건 JSON. 읽기 부담 없음, 쓰기는 100위 진입 시에만.
- 랭킹 점수 상한 계산은 게임 쪽 순수 계산 모듈과 동일한 공식을 워커에도 둔다(§5.2 테스트로 동일성 확인).

### 4.3 실패 처리
- 워커 응답 없음/오류: "랭킹 서버가 잠깐 쉬는 중이에요" 표시, 게임과 폰 저장 최고 기록은 그대로 동작. 등록 실패 시 재시도 버튼.

## 5. 구현 구조

### 5.1 파일
- `landing/merge/index.html` — 게임 전체(바닐라 JS 단일 파일). 내부를 네 구역으로 나눈다.
  1. **순수 계산**: 진화 사슬 표, 지름 계산, 단계 점수, 콤보 배율, 점수 상한 계산, 낙하 캐릭터 가중 랜덤. DOM·물리 의존 없음.
  2. **물리·합체**: Matter.js(CDN, 버전 고정 0.20.0) 월드 구성, 충돌 이벤트에서 합체 처리, 게임 오버 판정.
  3. **연출·소리**: 파티클, 흔들림, 팝업, Web Audio 합성음.
  4. **랭킹·화면**: 시작/플레이/결과/랭킹 화면 전환, 워커 통신, 닉네임 저장.
- `landing/merge/img/` — 짝꿍 찾기의 투명 배경 6장 복사(jujuya, ruric, pureum, nova, luna, luka) + 7~11단계 전용 그림 5장 + `og.png`(1200×630, 카톡 미리보기용). 이미지 생성 프롬프트는 `docs/superpowers/specs/2026-09-05-다락방-합체-게임-이미지프롬프트.md`.
- `landing/merge/test.html` — 순수 계산 구역을 브라우저에서 돌리는 간단 테스트 페이지(콘솔 통과/실패 출력).
- `docs/worker/worker.js` — `/merge/rank` 두 갈래 추가. `docs/worker/wrangler.toml` — `MERGE_RANK` KV 바인딩 추가.
- `docs/worker/merge-rank.test.mjs` — 워커 검증 공식 테스트(Node 실행).

### 5.2 테스트
- 순수 계산: 지름 단조 증가, 단계 점수 삼각수, 콤보 배율 상한 ×3, 점수 상한 공식이 임의 플레이 로그에서 실제 점수 이상인지.
- 워커: 정상 등록·100위 밖·상한 초과 거절·이름 길이 거절·합체 수 불일치 거절·1초 연타 429.
- 게임/워커 공식 동일성: 같은 입력 5세트에 대해 두 구현이 같은 상한을 내는지.
- 수동: 카톡 인앱 세로 화면 통 잘림 여부, 60fps, 소리 토글, 랭킹 등록·조회, 워커 다운 시 게임 지속.

### 5.3 배포 순서
1. `docs/worker`에서 KV 생성(`npx wrangler kv namespace create MERGE_RANK`) → toml 반영 → `npx wrangler deploy`.
2. `firebase deploy --only hosting`.
3. 실제 주소에서 한 판 끝내고 랭킹 등록·목록 확인, 카톡 미리보기 확인.
