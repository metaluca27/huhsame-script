# 다락방 짝꿍 찾기 (Attic Cards) — 게임 설계 문서

**날짜:** 2026-07-04
**상태:** 사용자 승인 완료, 이미지 6종 확보 완료

## 개요

디지털 다락방 6인 캐릭터(루카·루나·노바·푸름이·루릭·주주야)가 모두 등장하는 카드 짝맞추기(메모리) 게임. 단계별 난이도 3레벨. 모바일 웹 기준, 기존 Firebase Hosting(`landing/cards/`)으로 배포 → `사이트주소/cards`.

## 게임 규칙 (3레벨)

- **레벨 1 — 워밍업**: 카드 6장(3쌍). 매 판 6명 중 랜덤 3명 등장. 제한 없음.
- **레벨 2 — 전원 집합**: 카드 12장(6쌍). 6명 전원 등장. 제한 없음.
- **레벨 3 — 스피드전**: 카드 12장(6쌍) + **제한시간 45초**. 시간 초과 시 해당 레벨 재도전(레벨 1·2로 돌아가지 않음).
- **뒤집기 판정**: 탭으로 카드를 뒤집는다(한 번에 최대 2장). 두 장이 같은 캐릭터면 매치 — 카드 고정 + 반짝 효과 + 캐릭터 팝업. 다르면 0.8초 후 다시 뒤집힌다. 뒤집힘 대기 중 다른 카드 탭은 무시.
- **별점**: 레벨 클리어 시간 기준 별 1~3개. 시간 측정은 레벨 인트로가 끝나고 카드가 배치된 시점부터 마지막 쌍 매치 시점까지.
  - 레벨 1: 15초 이내 ★3 / 25초 이내 ★2 / 그 외 ★1
  - 레벨 2: 40초 이내 ★3 / 60초 이내 ★2 / 그 외 ★1
  - 레벨 3: 25초 이내 ★3 / 35초 이내 ★2 / 클리어(45초 이내) ★1
- **전체 클리어**: 레벨 3 클리어 시 6명 전원 등장 축하 화면 + 총 별 개수(최대 9개) + 다시하기·공유 버튼.
- **저장(localStorage)**: 키 `attic-cards-best` — JSON `{ stars: 총별, l3time: 레벨3 최단 클리어 ms }`. 갱신 시 결과 화면에 신기록 표시.

### 캐릭터 팝업 (등장 방식 — B안 확정)

매치 성공 순간, 화면 하단에서 해당 캐릭터 단독 컷이 슬라이드로 솟아오르며 말풍선 대사 표시. 0.9초 후 자동으로 내려간다. 연속 매치 시 이전 팝업을 즉시 교체.

## 화면 흐름

1. **시작 화면**: 타이틀 "다락방 짝꿍 찾기", 6명 미리보기(카드 앞면 이미지 나열), 최고 기록(총 별·레벨3 기록), 시작 버튼.
2. **레벨 인트로**: "레벨 N" 표시 1초 후 카드 배치(모두 뒷면). 레벨 3은 시작과 함께 타이머 바 표시.
3. **플레이 화면**: 상단 — 레벨 표시, 경과 시간(레벨 3은 남은 시간 바), 하단 — 캐릭터 팝업 영역.
4. **레벨 클리어**: 별 1~3개 + 클리어 시간 표시 → 다음 레벨 버튼.
5. **최종 결과**: 6명 전원 나열 + 총 별 개수 + 신기록 여부 + 다시하기 + 공유하기(리버스 스와이프와 동일: navigator.share, 폴백 클립보드).
6. **레벨 3 시간 초과**: "시간 초과!" + 루릭 한마디 + 재도전 버튼(레벨 3만 다시).

## 기술 구조

- **바닐라 JS 단일 파일** `landing/cards/index.html` + 캐릭터 이미지 6장(`landing/cards/img/`) + OG 이미지 1장. 프레임워크·외부 라이브러리 금지.
- 내부 구조: 게임 상태 머신(start → levelIntro → playing → levelClear → result / timeout) / 카드 로직(셔플, 뒤집기 판정) / 렌더링(CSS grid 카드판, 3D flip 애니메이션) / 캐릭터 팝업 / 사운드(리버스 스와이프의 Web Audio 방식 재사용: 뒤집기 톡, 매치 딩동, 클리어 팡파레, 시간초과 붕) + 🔊 토글.
- 카드 셔플: Fisher-Yates.
- **모바일**: 뷰포트 고정, `touch-action: manipulation`(탭 게임이라 스크롤 방지 수준), 375px 기준 카드 그리드(레벨 2·3은 3×4).
- **localStorage 접근은 전부 try/catch** (사파리 프라이빗 모드 — 지난 게임 최종 리뷰 교훈).
- **이미지 경로는 절대 경로** `/cards/img/...` (지난 게임 trailingSlash 404 교훈).

## 테스트/검증

로컬 프리뷰 서버(launch.json `game` 서버 재사용 — landing 루트 서빙이므로 `/cards/`도 접근 가능)에서:

- 카드 셔플·뒤집기·매치/불일치 판정 (preview_eval로 상태 직접 검증)
- 레벨 전환(1→2→3), 레벨 3 타이머·시간 초과 경로
- 별점 계산 경계값(시간별 1~3개)
- 캐릭터 팝업·대사, 루릭 3연속 미스 리액션
- localStorage 신기록 저장·예외 경로(setItem throw 시에도 결과 화면 전환)
- 375px 모바일 레이아웃(카드 그리드 겹침 없음), 콘솔 에러 0, 이미지 404 없음
