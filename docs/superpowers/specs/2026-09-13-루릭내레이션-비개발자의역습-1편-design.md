# 「비개발자의 역습」 루릭 내레이션 1편 — 설계

작성: 2026-09-13
계기: 유튜브 튜토리얼(Leo, 스틱피겨 원시인 채널)의 "타임스탬프 대본 → 이미지 일괄 생성" 파이프라인을 루카 소재로 재현.

## 결과물

- 세로 9:16, 약 2분 숏츠. 디지털 다락방 채널(@metaluca8563)용.
- 그림판 스틱피겨 그림 약 28장 + 루릭 내레이션. 자막은 캔바에서 후처리.
- 잘 되면 같은 그림체로 후속편(60초 게임 삽질편, 파세오 산책편) 제작.

## 화자와 말투

- 화자: 루릭. 킬링보이스 워커 `/voice/tts` 프리셋 `rurik`(Leda + 네다섯 살 톤).
- 시점: 집사(루카)를 옆에서 지켜본 관찰담. 1인칭 원문("나는 코딩을 1도 몰랐다")을 "우리 집사는 코딩을 1도 몰랐다"로 전환.
- 성격: 게임 속 루릭의 까칠한 코멘트 유지. 집사 삽질을 살짝 놀리다가 마지막엔 은근히 자랑스러워함.
- "~냥" 어미는 포인트 문장에서만. 매 문장 사용 금지.
- 톤 옵션은 1문장 샘플로 먼저 비교 후 확정.

## 대본 구조 (28문장 안팎, 문장당 3~5초)

1. 훅: "우리 집사는 코딩을 1도 몰랐다."
2. 검은 화면 공포: 깜빡이는 막대기 하나에 벌벌 떨던 집사.
3. 물어보면 알려주더라: 필요할 때 필요한 만큼만.
4. 첫 게임 완성 → 카톡 미리보기 흰 화면, 공유 버튼 먹통.
5. 정신 차려보니 앱 여덟 개: 게임, 시장 앱, 타로, 번역기 등.
6. 애드센스 거절, 또 거절.
7. 결론 "근데 되더라." + 다음 편 예고.

원문 출처: `docs/비개발자의역습.md` 프롤로그와 게임 에피소드.

## 그림

- 모델: 힉스필드 Z Image (0.15 크레딧/장), 세로 9:16.
- 스타일 고정 프롬프트(모든 장면 공통): 그림판 못 그린 척 낙서, 흰 배경, 두껍고 삐뚤한 검은 선, 동그란 머리 스틱피겨, 점 눈, 단색 채우기, 음영·그라데이션 없음.
- 캐릭터: 스틱피겨 집사 + 낙서 고양이(루릭, 스핑크스라 털 없이 큰 귀·큰 눈).
- 그림에 글자 넣지 않음(테스트에서 오타 발생). 자막은 캔바.
- 문장 1개 = 그림 1장.

## 제작 흐름

1. 대본 md 작성 → 루카 확인.
2. 문장 단위로 쪼개 워커 `/voice/tts`에 `{text, preset:"rurik", tone}` 호출, PCM → WAV 래핑(커밋 f825f7d 패턴).
3. 문장별 WAV 길이로 타임스탬프 자동 산출(Whisper 불필요). `timeline.json` 생성.
4. 그림 생성 전 크레딧 재확인 → 루카 승인 → `higgsfield generate create z_image` 문장별 실행 → result_url 다운로드.
5. ffmpeg로 그림+음성 이어 붙여 자막 없는 `draft.mp4` 생성.
6. 루카가 캔바에서 자막·마무리.
