# 다락방 작업노트 (/attic) 설계

2026-10-30 · 루카와 브레인스토밍으로 확정

## 한 줄 요약
비개발자 루카가 AI로 만든 앱 6개를 3D 다락방 안의 물건으로 놓아두고, 방문자가 물건을 눌러 "어떻게 만들었는지"를 카드로 보는 **만져보는 교재**. 유튜브·블로그 설명란에서 루카 사이트로 데려오는 통로이고, 끝에서 전자책으로 이어진다.

## 왜 만드나
- CONNECT AI LAB 「구글 지니 4」 영상의 "영상 + 직접 만져보는 3D 교재" 형식에서 아이디어만 빌림. 결과물·디자인·문구는 전부 루카 것으로 새로 만든다.
- 루카 목표: 시간 파는 구조가 아니라 온라인 통로. 이 페이지가 유튜브·블로그 → 루카 앱들 → 전자책 흐름의 허브가 된다.

## 대상
혼자 링크 타고 들어온 유튜브·블로그 독자 (1번). 설명 없이 만져도 알아먹어야 한다. 강의 때는 QR로 그대로 재사용.

## 주소·이름
- 경로: `landing/attic/` → `https://vaulted-bus-346411.web.app/attic`
- 제목(가제): 「다락방 작업노트 — 비개발자가 AI로 만든 것들」
- 랜딩 첫 화면 "다락방 놀이터"에 카드 1장 추가

## 화면
- 노을빛이 창문으로 들어오는 나무톤 로우폴리 다락방. Three.js(0.170.0, 모닥불 전시장과 같은 버전) 코드로 직접 짓는다. 블렌더 모델 안 씀.
- 이동 방식: 걷기 없음. 드래그/스와이프로 방 안을 빙글 둘러보는 궤도 카메라(회전 범위 제한, 확대 제한).
- 물건 6개가 은은하게 빛나고 살짝 둥실거림 = "눌러 보세요" 신호.

| 물건 | 앱 | 경로 |
|---|---|---|
| 🎲 합체 병 | 다락방 합체 게임 | /merge |
| 🛕 작은 절 모형 | 냥사 | /nyangsa |
| 🃏 카드 더미 | 심연의 타로 | /tarot |
| 📻 무전기 | 마주톡 | /talk |
| 👂 보청기 상자 | 나좀봐 | /look |
| 🔥 작은 모닥불 | 모닥불 전시장 | /gallery |

물건은 단순 도형 조합(박스·원기둥·구)으로 만든 로우폴리 소품.

## 물건을 누르면
1. 카메라가 그 물건 쪽으로 부드럽게 다가감.
2. 카드 3장 패널이 뜸 (옆으로 넘김, 폰은 스와이프):
   - ① 왜 만들었나
   - ② AI한테 실제로 뭐라고 시켰나 (실제 대화 한 줄)
   - ③ 어디서 막혔고 어떻게 넘었나 (삽질담, 전자책 톤: 실패 그대로, 억지 해피엔딩 금지)
3. 마지막 카드에 **[직접 써보기]** → 실제 앱 새 탭.
4. 닫으면 카메라가 원래 자리로 돌아감.

## 모으는 재미
- 화면 아래 "6개 중 n개 봤어요" 표시. 본 물건은 빛이 잔잔해짐.
- 6개 다 보면 다락방 창문이 활짝 열리고 → "더 자세한 이야기는 전자책 「비개발자의 역습」에" + 크몽 링크(https://kmong.com/self-marketing/803533/YNgTd87HX2).
- 본 기록은 브라우저(localStorage)에만 저장. 서버·워커 안 씀.

## 푸름이
- 푸름이는 창턱에 앉아 있음. 처음엔 그림 등신대였다가 루카 요청으로 **3D 인형으로 바꿈**: 3D 에이전트 사무실 때 블렌더로 만든 앉은 인형(`tools/ai-office-3d/web/characters/char_pureum.glb`)을 `landing/attic/models/`로 복사해서 씀. 숨쉬듯 살짝 움직이고 카메라 쪽으로 몸을 조금 돌림.
- 누르면 말풍선 한 줄 (@pureum_3pm 말투, "집사야~ ~옹"). 장난·개그 톤 금지, 따뜻하게.
- 6개 다 보면 푸름이가 열린 창밖 쪽으로 몸을 돌림.
- 푸름이 대사는 초안을 쓰고 **루카 확인 후 확정**.

## 루나 (타로 지킴이)
- 다락방 식구 루나(어린 철학자)가 타로 탁자 옆 둥근 의자에 앉아 있음 (루카 아이디어). 푸름이와 같은 블렌더 앉은 인형(`char_luna.glb`).
- 타로 물건을 누르면 카드 패널이 뜨기 전에 루나가 철학자 톤 말풍선 한 줄 → 이어서 카드 3장.
- 루나 대사도 초안 → 루카 확인 후 확정.

## 소리
- 잔잔한 다락방 배경음 + 켜기/끄기 버튼. 첫 터치 전엔 재생 안 함(브라우저 정책). 음원은 기존에 루카가 가진 것 중 고르거나 루카 확인 후 정함.

## 파일 구성
```
landing/attic/
  index.html     화면 틀, 카드 패널, 진행 표시
  main.js        3D 방·카메라·클릭 처리
  props.js       물건 6개 모양 만들기
  stories.js     물건 목록 + 카드 글 (물건 추가 = 여기 한 덩어리)
  og.jpg         링크 미리보기 이미지
```
3D 코드와 글을 분리해서, 물건을 늘릴 때 `stories.js` + `props.js`만 건드리면 되게 한다.

## 카드 글 작성
- 각 앱의 메모리 기록·커밋 기록·관련 문서를 뒤져서 클로가 초안 작성 → 루카 확인 후 확정.
- 기록이 부족한 앱은 루카에게 한두 줄 물어봄. 지어내지 않음.

## 확인 방법
- 로컬 미리보기로 PC 크기·폰 크기(375px) 둘 다 열어서: 회전, 물건 6개 클릭, 카드 넘김, 직접 써보기 링크, 6개 완료 연출, 푸름이 클릭, 소리 켜기/끄기를 실제로 눌러 봄.
- 콘솔 에러 없는지 확인.
- 루카 승인 후 Firebase 배포 → 배포 주소로 다시 열어 확인.

## 이번에 안 하는 것
- 나머지 앱들(우리 시장 가자, 곁별, scan, 킬링보이스 등) — 나중에 하나씩 추가
- 가짜 채팅 "따라 해보기" 체험 — 나중에 물건 하나로 추가 가능
- AR(QR로 폰에 띄우기), 블렌더 고급 모델, 방문자 수 집계
