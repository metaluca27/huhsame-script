# 클로 텔레그램 봇 설계 (Claude 관리형 에이전트)

작성일: 2026-10-30

## 왜 만드나

- Max 5x 구독으로 받은 프로모션 크레딧 US$100(2026-11-23 만료, Agent SDK·API·배치·Playground·관리형 에이전트에 사용 가능)을 관리형 에이전트로 실험해 본다.
- 오픈클로(루릭·푸름이)는 미니PC에 의존해서 자주 먹통이 된다. 미니PC가 꺼져도 살아 있는 **비상용 두뇌**를 하나 둔다.

## 무엇을 만드나

루카 전용 텔레그램 봇 **클로**. 텔레그램에서 말을 걸면 클로드 관리형 에이전트가 답한다. 웹 검색과 작업 컴퓨터(파일·계산·코드 실행)를 쓸 수 있고, 대화를 기억한다.

## 흐름

```
루카 텔레그램 → 클로 봇 → 공용 워커 /clo/telegram → 관리형 에이전트 세션에 user.message 전송
관리형 에이전트 → (session.status_idled 웹훅) → 공용 워커 /clo/agent-webhook
  → 세션 이벤트 조회 → 마지막 루카 메시지 이후의 agent 답변 텍스트 → 텔레그램 sendMessage
```

1. **텔레그램 웹훅 수신** (`/clo/telegram`)
   - `X-Telegram-Bot-Api-Secret-Token` 헤더가 워커 시크릿과 다르면 401.
   - 보낸 사람 ID가 루카(`CLO_OWNER_CHAT_ID`)가 아니면 200을 주고 무시.
   - `/새대화`: 새 세션을 만들어 저장하고 "새 대화를 시작했어요" 응답.
   - 그 외 텍스트: 저장된 세션에 `user.message` 전송(세션이 없으면 새로 만듦), `sendChatAction(typing)`, 텔레그램엔 즉시 200.
   - 답을 기다리지 않는다(텔레그램 웹훅은 오래 기다려 주지 않고 재전송한다).
2. **관리형 에이전트 웹훅 수신** (`/clo/agent-webhook`)
   - 서명(HMAC) 검증 실패 시 401.
   - `session.status_idled`만 처리. 세션이 현재 저장된 세션과 다르면 무시.
   - 세션 이벤트를 조회해 최신 `session.status_idle`의 `stop_reason`을 본다.
     - `budget_reached`: "이 대화방 예산을 다 썼어요. /새대화 로 새로 시작해 주세요" 전송.
     - 그 외: 마지막 `user.message` 이후의 `agent.message` 텍스트를 이어 붙여 전송(4096자 넘으면 나눠 보냄).
   - 같은 idle을 두 번 보내지 않도록 마지막으로 전달한 이벤트 ID를 저장한다.

## 구성 요소

- **에이전트(한 번 생성, ID 보관)**: 모델 `claude-opus-5-5`, 관리형 기본 도구 세트(bash·파일·웹 검색·웹 가져오기), 멀티에이전트 없음.
  - 시스템 프롬프트: 안경 쓴 댕댕이 솜인형 분석가 클로. 해요체, 사용자 호칭 "루카". 텔레그램이라 마크다운 기호(`**`, `#`) 금지, 짧게 답하고 필요하면 이어서.
- **환경**: 클라우드 컨테이너, 네트워크 허용(검색·작업용).
- **세션**: 루카 대화방 하나를 계속 이어 쓴다. 생성 시 예산 상한 `$3` (`budget: {type: "limit", max_list_cost: {amount: 3, currency: "USD"}}`).
- **저장소**: 현재 세션 ID와 마지막 전달 이벤트 ID. 공용 워커의 KV를 쓴다(없으면 새 KV 네임스페이스 하나 추가).

## 비밀값 (전부 워커 시크릿, 코드·설정 파일 금지)

`ANTHROPIC_API_KEY`, `CLO_TELEGRAM_BOT_TOKEN`, `CLO_TELEGRAM_SECRET`, `CLO_AGENT_WEBHOOK_SECRET`, `CLO_OWNER_CHAT_ID`. 에이전트·환경 ID는 비밀이 아니므로 `wrangler.toml` vars 또는 코드 상수로 둔다.

## 비용 안전장치

- 루카 외 사용자 차단.
- 세션당 상한 $3 (모델 토큰 + 검색 $10/1,000회 + 실행 시간 $0.08/시간, 정가 기준).
- 프로모션 크레딧이 만료되면 유료 잔액과 자동 충전에서 빠진다. 만료 전에 계속 쓸지 판단하고, 안 쓰면 텔레그램 웹훅을 해제한다.

## 루카가 직접 할 일

1. 텔레그램 @BotFather에서 새 봇 생성, 토큰을 워커 시크릿으로 등록(명령어는 안내).
2. Anthropic 콘솔에서 관리형 에이전트 웹훅 주소 등록, 서명 비밀값을 워커 시크릿으로 등록.

## 1차 범위에서 뺀 것

- 클로가 만든 파일을 텔레그램으로 전송 (2차)
- 사진·음성 입력, 예약 자동 작업, 루릭·푸름이와 연동

## 확인 방법

- 루카 계정으로 "안녕" → 클로 말투로 답이 오는지.
- 검색이 필요한 질문(오늘 날씨 등) → 검색 결과가 반영되는지.
- 계산·파일 작업 요청 → 작업 컴퓨터를 쓰는지(콘솔 세션 뷰어에서 확인).
- 다른 계정으로 말 걸기 → 무시되는지.
- `/새대화` → 이전 대화를 기억하지 않는지.
- 콘솔에서 세션 비용이 기대 범위인지.
