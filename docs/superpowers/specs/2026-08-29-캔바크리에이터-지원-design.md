## 2. 전제 조건 — 가장 중요한 인식 전환

지원자는 그동안 **"기존 Canva 템플릿을 골라 내용을 바꾸는"** 방식으로 작업해 왔다.
제출해야 하는 것은 **"빈 페이지에서 직접 짠 템플릿"** 이다. 방향이 반대다.

| 구분 | 사용 가능 여부 |
|---|---|
| Canva **요소**(도형·아이콘·사진·일러스트·폰트) | ✅ 자유롭게 활용 가능 |
| Canva **템플릿**(타 크리에이터의 완성 레이아웃) | ❌ 수정해서 제출 시 탈락 |

**재료는 갖다 써도 되고, 레시피는 직접 짜야 한다.**

기존에 만들어 둔 Canva 파일들은 대부분 남의 템플릿 기반이므로 **그대로 제출 불가**.
다만 "이런 걸 만들고 싶다"는 설계도로는 활용한다.

| 브랜드 키트 슬롯 | 폰트 | 역할 |

**선정 근거**
- KoPub바탕체 — 굵기 선택지가 있고 획이 또렷해 포스터 크기로 키워도 무너지지 않음. Song Myung은 대제목에 너무 얇고, TDTD원명조는 개성이 강해 8개를 관통하기엔 물린다.
- Noto Sans Kr — 굵기 단계가 가장 넓어 "글꼴 크기 3단계" 규칙을 굵기로도 보강할 수 있다. 표정이 중립적이라 명조와 충돌하지 않는다.
- 대안: 코어 고딕 D/E/M (Pro 폰트, 계정에서 사용 가능). 취향이 안 맞을 때 교체 후보.

> **금지:** 업로드한 폰트(현재 계정에 9개)는 템플릿에 사용하지 않는다.
> 업로드 폰트는 해당 계정에만 존재하므로, 심사자나 다른 사용자가 템플릿을 열면
> 폰트가 대체되어 레이아웃이 깨진다. **Canva 기본 제공 폰트만 사용한다.**

> **확인 완료 (2026-08-29):** KoPub바탕체에 Bold 있음. 제목 슬롯에 Bold 적용 완료.
> 글꼴 구성 확정. 이후 변경하지 않는다.

### 4.3 여백·구조 규칙 5가지

1. **바깥 여백은 안쪽 여백의 2배** — 답답한 구성 원천 차단
2. **텍스트 상자는 여백 안쪽 끝까지** — 상자를 재단선까지 늘리면 긴 문구가 가장자리에 붙어 여백 규칙이 무너진다. 상자 폭 = 판형 폭 − (좌우 여백 × 2).
3. **한 화면에 글꼴 크기는 3단계까지** — 제목 / 소제목 / 본문
4. **모든 사진은 채도를 낮춘다** — 채도 -60~-80 또는 흑백·듀오톤 처리
5. **제목이 두 줄이 되어도 겹치지 않게 설계한다** — 아래 요소와 한 줄 높이 이상의 간격을 둔다. 세 줄까지는 보장하지 않는다.

### 4.3.1 긴 제목 테스트 (모든 템플릿 필수)

제작 후 제목 칸에 **평소보다 2배 긴 문구를 임시로 넣어** 실제로 확인한다.
겹치면 아래 요소를 내리거나 제목 크기를 낮춘다. 확인 후 원래 문구로 되돌린다.

**해결 순서** — 여백을 희생하지 말고 글자 크기를 먼저 낮춘다.
텍스트 상자를 넓혀 줄 수를 줄이는 방식은 여백 규칙(1·2번)을 깨뜨리므로 쓰지 않는다.

> 실측 예 (1번 포스터, A2 42×59.4cm, 좌우 여백 4cm)
> - 130pt → 한 줄에 약 8자 → 19자 제목이 3줄이 되어 아래 요소를 덮음
> - **110pt → 한 줄에 약 10자 → 19자 제목이 2줄에 들어가고 5cm 여유 확보**
>
> 실제 전시명은 대개 10자 내외이므로 평상시에는 한 줄로 들어간다.

### 4.4 사진 채도 규칙의 근거

포인트 색 `#D94F2B`(주황)은 화면에서 **유일한 색**이어야 힘을 갖는다.
원본 채도가 살아 있는 사진을 쓰면 사진의 색과 포인트 색이 서로 튀면서 양쪽 다 죽는다.
특히 파랑·보라 계열 사진은 주황의 보색이라 충돌이 가장 심하다.

사진을 잉크·오프화이트 톤으로 가라앉히면
- 포인트 색이 화면에서 유일한 색이 되어 "아트 컨트라스트" 의도가 성립하고,
- 서로 다른 사진을 쓴 8개 작품이 저절로 같은 톤으로 묶인다.

심사에서 "같은 사람의 작업"으로 읽히게 만드는 가장 값싼 장치다.

### 4.5 C와 A의 사용 구분

- **C (메인)** — 포스터, 프레젠테이션, 브랜딩 문서, 전시·행사물
- **A (서브)** — SNS 등 정보 전달이 우선인 것

A로 갈 때도 **포인트 색과 글꼴 조합은 유지**한다. 배경이 오프화이트→순백으로 바뀌고 명조 비중이 줄어드는 정도의 차이만 둔다. 그래야 포트폴리오가 두 덩어리로 쪼개져 보이지 않는다.

## 5. 포트폴리오 구성 (8개 + 예비 2개)

링크 1개 = Canva 디자인 1개. 프레젠테이션 12장짜리도 링크는 1개다.
→ **투입 대비 실력 증명 효율이 가장 높은 것이 프레젠테이션.**

| # | 카테고리 | 만들 것 | 톤 | 예상 시간 |
|---|---|---|---|---|
| 1 | 포스터 | 전시·공연 포스터 | C | 4h |
| 2 | 프레젠테이션 | 브랜드/사업 제안서 (10~12장) | C | 6h |
| 3 | 프레젠테이션 | 강의·워크숍 자료 (8~10장) | C | 5h |
| 4 | 문서 | 1페이지 프로필 시트 | C | 3h |
| 5 | 카드·초대장 | 초대장 앞·뒤 | C | 3h |
| 6 | 전단 | 소상공인 이벤트 전단 | C | 3h |
| 7 | 인스타 포스트 | 캐러셀 5장 세트 | A | 4h |
| 8 | 유튜브 | 썸네일 + 채널아트 | A | 3h |
| **소계** | **7개 카테고리** | | | **31h** |
| 9 (예비) | 명함 | 앞·뒤 | C | 2h |
| 10 (예비) | 인스타 스토리 | 세트 (7번 요소 재활용) | A | 2h |
| **합계** | **9개 카테고리 / 10개 링크** | | | **35h** |

### 구성 근거

- **기준1 (레이아웃 역량)** → 2·3번. 장수가 많아 실력을 숨길 수 없음
- **기준2 (다양성)** → 최대 9개 카테고리 커버. 공식 페이지가 두 번 강조한 항목
- **기준3 (한국어·로컬)** → 5·6번. 특히 6번은 한국 소상공인 맥락 그 자체
- **기준4 (템플릿 포맷)** → 전 작품에 4.3의 규칙 2번 적용
- **가점** → 2·3·4번 (프레젠테이션·문서 타입)

프레젠테이션만 카테고리가 중복되는데, 이는 유일한 명시적 가점 항목이기 때문에 의도된 배치다.

### 제출 순서

접수 폼에서 **1번 링크만 필수**이며, 심사자가 가장 먼저 여는 자리다.

- **1번 자리 → 전시 포스터.** 열자마자 차별점이 전달되는 유형
- **2·3번 자리 → 프레젠테이션.** 첫인상 다음에 실력 증명이 오는 구조

### 잘라내는 순서 (일정이 밀렸을 때)

**10 → 9 → 8 → 6 → 5** 순으로 포기한다.
**1·2·3·4번은 어떤 경우에도 유지** — 가점과 차별화가 전부 여기 있다.
최소 4개만 남아도 인쇄·프레젠테이션·문서·SNS 4개 카테고리가 커버된다.

### 대안 옵션

6번(소상공인 전단)은 정보를 빽빽하게 배치하는 작업으로, 전시 포스터와 정반대 성격이다.
작업이 맞지 않으면 **"한글 축하 카드 세트(돌·개업·명절)"** 로 교체해도 기준3은 충족된다.

## 7. 제작 진입 절차 — "정할 것 3줄"

빈 페이지 앞에서 시간을 흘려보내는 것이 가장 큰 리스크다.
**모든 템플릿은 Canva를 켜기 전에 아래 3줄을 먼저 적는다.**

```
1. 누가 언제 쓰나?   예) 소규모 갤러리 운영자가 개인전 홍보할 때

3. 사진 들어가나?    예) 대표 이미지 1장, 상단 60% 차지
```

3줄이 정해지면 작업은 헤딩이 아니라 조립이 된다.

## 7.1 템플릿 제작 공통 원칙 (8개 전부에 적용)

"예쁜 디자인"과 "잘 만든 템플릿"을 가르는 지점이며, 심사 기준 4번(템플릿 포맷 이해)에 직접 대응한다.

1. **캔바 표준 판형만 사용한다.** 커스텀 사이즈로 만들지 않는다. 표준 판형이어야 검색·분류에 정상적으로 잡힌다.
2. **사진은 반드시 [요소 → 프레임]에 넣는다.** 이미지를 그냥 배치하면 사용자가 교체하기 어렵다. 프레임을 놓고 그 안에 사진을 넣으면 사용자가 자기 사진을 끌어다 놓는 것만으로 교체된다.
3. **텍스트 상자는 실제 글자보다 넓게 잡는다.** 사용자가 더 긴 문구를 넣어도 레이아웃이 깨지지 않아야 한다. 제목은 두 줄까지 버티도록 미리 잡아둔다.
4. **사진·요소는 Canva 기본 제공분을 쓴다.** 본인 작품 사진을 넣으면 템플릿 게시 시 타인이 그 이미지를 사용하게 된다.
   넣은 뒤에는 반드시 **채도를 낮춘다** (4.3의 4번, 근거는 4.4).
5. **업로드 폰트를 쓰지 않는다.** (4.2 참조)
6. **문구는 "그럴듯하지만 가짜"로 채운다.** "제목을 입력하세요" 같은 표시는 미리보기에서 밋밋하다. 실명·실제 상호·연락처 등 개인정보는 넣지 않는다.

## 7.2 1번 작품 브리프 — 개인전 포스터

```
1. 누가 언제?   소규모 갤러리·작가가 개인전을 홍보할 때
2. 글자 덩어리?  작가명 / 전시명 / 기간·장소 / 관람안내 = 4개
3. 사진?        대표 작품 1장, 상단 약 58%
```

**판형** — 포스터(세로) 42 × 59.4cm, Canva 기본값

**레이아웃** — 원형 프레임 채택 (2026-08-29 제작 중 결정)

사각 프레임보다 전시 포스터 특유의 결이 산다. 배경 전체는 `#F4F1EA`.

```
┌─────────────────────┐
│    ╱─────────╲      │  원 지름 32cm (폭 42cm의 76%)
│   │           │     │  원 위쪽 끝 = 위에서 6cm
│   │  사진 원형  │     │
│   │   프레임    │     │
│    ╲─────────╱      │
│                     │
│ ▪ 작가명             │  글자 영역 = 아래에서 5~17cm
│                     │
│ 전 시 명             │
│ 두 줄 까 지           │
│                     │
│ 2026.10.1 – 10.20   │
│ 갤러리 이름, 서울      │
│                     │
│ 관람 안내 한 줄        │
└─────────────────────┘
```

원은 화면을 지배할 만큼 크게 잡는다. 작으면 공중에 뜬 것처럼 보이고 무게중심이 잡히지 않는다.
원 윗부분을 재단선 밖으로 살짝 걸치게 자르는 변형도 가능하다 (선택).

**글자 크기 — 3단계 고정**

| 요소 | 폰트 | 크기 | 색 |
|---|---|---|---|
| 전시명 | KoPub바탕체 Bold | **110pt** | `#141821` |
| 기간·장소 | Noto Sans Kr Regular | 32pt | `#141821` |
| 작가명 / 관람안내 | Noto Sans Kr Light | 22pt | `#4E5361` |

작가명은 크기를 관람안내와 같게 두고 **자간을 0.3em 정도 벌려** 라벨처럼 구분한다.
전시명은 반대로 **자간 -10**으로 조인다. 제목은 좁게, 라벨은 넓게 — 이 대비가 편집 디자인의 기본 문법이다.
한글은 글자마다 획 수가 달라 자간을 좁혀도 시각적 여백이 남는데, 이는 자간이 아니라 한글 구조의 문제이므로 -10 이상 조이지 않는다 (-15까지가 한계, 그 이상은 받침이 충돌).

전시명 텍스트 상자 폭은 **판형 폭 − 좌우 여백 4cm × 2 = 34cm**로 고정한다.

**포인트 색** — `#D94F2B`는 작가명 앞 작은 사각형 하나에만 사용한다.

**여백** — 좌우 바깥 여백 40mm / 글자 덩어리 사이 간격 20mm (바깥이 안쪽의 2배)

**샘플 문구**

```
작가명    ARTIST NAME
전시명    빛이 머무는 자리
기간      2026. 10. 01 – 10. 20
장소      갤러리 이름, 서울
관람안내  화–일 11:00–18:00 · 월요일 휴관 · 무료 관람
```

> **배경:** 지원자가 언젠가 열고 싶은 본인 개인전을 상상하며 만드는 작업이다.
> 구조와 감각은 그대로 가져가되, 실명·실제 갤러리·실제 날짜는 넣지 않는다 (7.1의 6번).
> 완성된 템플릿은 실제 개인전을 열 때 글자만 바꿔 그대로 쓸 수 있다.

**목표 시간** 4h (첫 작품이므로 5h까지는 허용). 여기서 확정한 여백과 크기 3단계는 나머지 7개에 그대로 재사용한다.

## 7.3 2번 작품 브리프 — 브랜드 제안서 프레젠테이션

```
1. 누가 언제?   소규모 스튜디오·프리랜서가 클라이언트에게 제안할 때
2. 글자 덩어리?  슬라이드 유형마다 다름 → 마스터 4종으로 통제
3. 사진?        표지 1장 + 내지 3장, 전부 채도 하향
```

**판형** — 프레젠테이션 16:9 (1920 × 1080px), Canva 기본값
**분량** — 12장
**주제** — "브랜드 리뉴얼 제안서" (업종을 특정하지 않아 범용성 확보)

### 핵심 원칙: 12장을 12번 디자인하지 않는다

**마스터 4종을 먼저 완성하고, 복제해서 12장을 채운다.**
이 단계를 건너뛰면 12장을 각각 디자인하게 되어 시간이 통제되지 않는다.

| 마스터 | 구조 | 쓰이는 슬라이드 | 장수 |
|---|---|---|---|
| **A. 표지형** | 큰 제목 + 이미지, 여백 위주 | 표지 · 간지 · 마무리 | 3 |
| **B. 본문형** | 슬라이드 제목 + 본문 단락 | 텍스트 중심 슬라이드 | 3 |
| **C. 분할형** | 2단 또는 3단 나열·비교 | 목차 · 비교 · 항목 나열 | 3 |
| **D. 이미지형** | 이미지 + 설명 텍스트 | 사례 · 시각 자료 | 3 |

### 글자 크기

| 요소 | 폰트 | 크기 |
|---|---|---|
| 표지 제목 | KoPub바탕체 Bold | 80pt |
| 슬라이드 제목 | KoPub바탕체 Bold | 54pt |
| 본문 | Noto Sans Kr Light | 20pt |
| 라벨·페이지 번호 | Noto Sans Kr Light | 14pt |

한 슬라이드 안에서는 3단계를 넘지 않는다 (표지는 별도 화면이므로 예외).

### 여백

- 좌우 바깥 여백 **140px**, 상하 **90px**
- 요소 간 간격 **60px** (바깥이 안쪽의 2배 이상)
- **슬라이드 제목의 위치와 상자 폭은 12장 전부 동일하게 고정**한다.
  장마다 제목 위치가 흔들리면 넘길 때 화면이 튀어 보이고, 템플릿 완성도가 떨어져 보인다.

### 포인트 색

`#D94F2B`는 슬라이드당 한 군데. 슬라이드 제목 아래 짧은 선 또는 강조 숫자에만 쓴다.

### 제작 중 확인된 것 (2026-08-30, 마스터 4종 완료 시점)

**좌표를 눈대중으로 잡지 말고 위치 패널에 숫자로 입력한다.**
Canva 상단 `위치 → 정렬 → 고급`에서 X·Y·가로·높이를 직접 입력할 수 있다.
빈 화면 앞에서 헤매는 시간이 사라지고, 12장 내내 위치가 흔들리지 않는다.

주의할 점 세 가지 (모두 실제로 걸린 것들):

1. **위치 패널의 "페이지에 맞춤 → 왼쪽"은 정렬이 아니라 이동이다.** 누르면 X가 0이 된다.
   글자 정렬은 상단 툴바의 `≡` 아이콘을 쓴다.
2. **텍스트 상자 가로를 넓히면 X가 밀린다.** 가로를 먼저 정하고 X를 나중에 입력한다.
3. **도형 크기를 바꿀 때는 비율 자물쇠를 먼저 푼다.** 잠긴 채로 가로를 바꾸면 높이가 따라 변한다.

**소제목은 크기를 키우지 않고 굵기와 색으로만 구분한다.**
글자 크기 3단계 규칙(4.3의 3번)을 지키기 위해, 3단 구성의 소제목은 본문과 같은 20pt를 쓰되
Bold + `#141821`, 설명은 Light + `#4E5361`로 대비를 만든다.

**이미지는 반드시 프레임에 넣는다.** 색이 채워진 사각형은 도형이지 프레임이 아니다.
프레임인지 확인하려면 사진을 끌어다 올려 본다 — 쏙 들어가면 프레임이다.

**일러스트 대신 사진을 쓴다.** 채도 하향 규칙(4.3의 4번)은 사진을 전제로 한 것이라,
플랫 벡터 일러스트는 채도를 낮춰도 회색 클립아트가 될 뿐 톤에 섞이지 않는다.
질감·빛·여백이 있는 저채도 사진(물결, 안개, 콘크리트, 그림자 등)을 고른다.

**작품마다 다른 사진을 쓴다.** 심사자가 링크 10개를 연달아 보므로 같은 사진이 반복되면 눈에 띈다.

### 조립 중 확인된 것 (2026-09-03, 12장 완성 시점)

**그리드 뷰 썸네일은 늦게 갱신된다.** 드래그·삭제·복제를 연달아 하면 썸네일이 옛날 그림을 보여줘
"표지가 사라졌다", "슬라이드가 중복됐다"로 보이지만 실제 슬라이드는 멀쩡한 경우가 있다.
이 착시 때문에 정상인 슬라이드를 지우거나 다시 복제하면 진짜 중복이 생긴다.

- 판단은 **썸네일이 아니라 큰 화면**으로 한다. 썸네일을 하나씩 클릭해 위 화면에 뜨는 내용을 확인한다.
- 썸네일을 강제로 다시 그리려면 해당 슬라이드에서 글자 하나를 넣었다 지운다.
- 디자인을 닫았다 다시 열어도 갱신된다. 캔바 앱에서는 F5가 듣지 않는다.

**순서 정렬은 한 번에 하지 않는다.** 12장을 동시에 맞추려 하면 헷갈린다.
앞자리부터 "이 자리엔 뭐가 와야 하지"만 보고 하나씩 끌어온다.
정답 순서는 없다 — 표지가 앞뒤에 있고 흐름이 자연스러우면 된다.

**한 단계마다 화면을 확인한다.** 복제 → 확인 → 이동 → 확인 → 삭제 → 확인.
여러 단계를 한 번에 하면 어디서 꼬였는지 찾을 수 없다.

### 작업 순서

1. 마스터 A~D 4종 제작 (여기에 시간의 절반을 쓴다)
2. 복제해 12장 배치
3. 각 장 내용 채우기
4. 페이지 번호 통일 삽입
5. 긴 제목 테스트 (4.3.1) — 슬라이드 제목이 두 줄이 되어도 본문을 덮지 않는지
6. 파일명 `02_프레젠테이션_브랜드제안서` → 공개 링크 발급 및 검증 (8장)

1일차에 마스터 4종까지, 2일차에 채우기와 마무리.

## 7.4 4번 작품 브리프 — 1페이지 프로필 시트 (문서)


> 2026-09 기준 Canva 인스타 프리셋에 1:1이 없고 4:5·3:4만 있다. 인스타가 피드 기본을 4:5로 바꾼 것을
> 따라간 것. 맞춤형 1080×1080을 만들지 않고 **표준 프리셋 4:5**를 쓴다 (7.1의 1번).
> 아래 Y값은 1350 높이 기준으로 조정한 값.
**분량** — 5페이지 (1 표지 · 2~4 팁 · 5 마무리)
**톤** — **서브 A (미니멀 에디토리얼)**. 배경 순백 `#FFFFFF`, 사진 비중 최소, 명조는 제목에만.
색·글꼴 조합은 그대로 유지 (4.5 참조). 1~6번과 다른 결이지만 같은 사람 작업으로 읽혀야 한다.
**주제** — "브랜드가 흔들릴 때 점검할 3가지". 2번 제안서의 스튜디오가 올릴 법한 콘텐츠.

### 여백·단위

1080px 판형에서 **바깥 여백 80px**, 요소 간격 40px. 전부 X 80, 가로 920.

### 글자 3단계 (px 판형이라 pt 값이 다름)

| 역할 | 폰트 | 크기 |
|---|---|---|
| 제목·소제목 | KoPub바탕체 Bold | **56pt** (표지) / **40pt** (팁 소제목·마무리) |
| 본문 | Noto Sans Kr Light | **22pt** |
| 라벨·페이지 표시 | Noto Sans Kr Light, 자간 +30 | **14pt** |
| 팁 번호 | KoPub바탕체 Bold | **96pt**, `#D94F2B` |

표지 56과 팁 40은 둘 다 "제목" 단계. 한 카드 안에서는 3단계를 넘지 않는다.

### 포인트 색 규칙 (캐러셀 전용)

카드마다 주황은 한 군데:
- **표지·마무리** → 라벨 앞 `▪`
- **팁 카드** → 큰 번호 `01` `02` `03` 자체가 주황. 이 카드엔 ▪ 없음.

### 1페이지 — 표지

```
┌──────────────────┐
│ ┌──────────────┐ │
│ │    사진       │ │  Y 80~520
│ └──────────────┘ │
│ ▪ BRAND CHECK    │  Y 580
│ 브랜드가 흔들릴 때  │  Y 630, 56pt
│ 점검할 3가지       │
│                  │
│        넘겨서 보기 → │  Y 960, 오른쪽 정렬
└──────────────────┘
```

| 요소 | 내용 | 스타일 | X | Y | 가로/높이 |
|---|---|---|---|---|---|
| 프레임 | 사진 | 채도 하향 | 80 | 80 | 920 × 560 |
| 라벨 | `▪ BRAND CHECK` | 14pt 자간+30 `#4E5361`, ▪ 주황 | 80 | 700 | 920 |
| 제목 | `브랜드가 흔들릴 때` ↵ `점검할 3가지` | 56pt 명조 Bold `#141821` | 80 | 750 | 920 |
| 안내 | `넘겨서 보기 →` | 14pt Light `#4E5361` **오른쪽 정렬** | 80 | 1230 | 920 |

### 2~4페이지 — 팁 카드 (마스터 1장 만들고 복제 ×2)

```
┌──────────────────┐
│ 01               │  Y 80, 96pt 주황
│                  │
│ 이름을 부르는       │  Y 360, 40pt
│ 방식이 같은가       │
│ 로고·상호·SNS…     │  Y 500, 22pt
│                  │
│ 02 / 05          │  Y 960
└──────────────────┘
```

| 요소 | 스타일 | X | Y | 가로 |
|---|---|---|---|---|
| 번호 | 96pt 명조 Bold `#D94F2B` | 80 | 80 | 300 |
| 소제목 | 40pt 명조 Bold `#141821` | 80 | 480 | 920 |
| 설명 | 22pt Light `#4E5361` | 80 | 640 | 920 |
| 페이지 | `02 / 05` 14pt Light `#4E5361` | 80 | 1230 | 920 |

**팁 내용:**
```
01  이름을 부르는 방식이 같은가
    로고·상호·SNS 아이디가 제각각이면 기억되지 않습니다.
    하나로 정하고 모든 접점에서 똑같이 씁니다.

02  색이 세 개를 넘지 않는가
    접점마다 다른 색을 쓰면 같은 브랜드로 읽히지 않습니다.
    주색 하나, 보조색 하나, 포인트 하나면 충분합니다.

03  새 서비스를 담을 자리가 있는가
    지금 구조가 5년 뒤 확장을 버티는지 확인합니다.
    자리가 없다면 지금이 정리할 때입니다.
```

| 요소 | 내용 | 스타일 | X | Y | 가로 |

| 계정 | `@studio_name` | 14pt Light | 80 | 1230 | 920 |

### 템플릿 요건

- 5장 전부 **여백 80 / X 80 / 가로 920** 동일. 넘길 때 요소가 튀지 않아야 한다.
- 팁 카드 3장의 번호·소제목·설명·페이지 Y가 **정확히 같아야** 한다 (복제로 보장).
- 긴 제목 테스트: 표지 제목 3줄 (`브랜드가 흔들릴 때 반드시 점검해야 할 세 가지`) → 안내 문구를 덮지 않는지
- 팁 설명 3줄까지 수용 → 페이지 표시를 덮지 않는지
- 사진은 1~6번과 다른 것. 채도 하향.

### 작업 순서

1. 인스타그램 게시물(정사각) 새로 만들기, 배경 **`#FFFFFF`** (오프화이트 아님 — 서브 A)
2. 2페이지(팁 마스터)부터 — 번호 → 소제목 → 설명 → 페이지 표시
3. 복제 ×2 → 번호·글자 바꾸기 (3, 4페이지)
4. 1페이지 표지 — 프레임 → 라벨 → 제목 → 안내
5. 5페이지 마무리 — 2페이지 복제해서 번호 지우고 라벨·문구로 교체
6. 페이지 순서 확인 (표지가 1번)
7. 사진 넣고 채도 처리
8. 긴 제목 테스트
9. 파일명 `07_인스타_캐러셀_브랜드체크` → 공개 링크 → 시크릿창 (5장 넘어가는지)

**예상 시간** 4h (실적 기준 2h 안팎 — 팁 카드가 복제라 실제 제작은 3장)
