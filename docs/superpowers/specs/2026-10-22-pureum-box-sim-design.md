# 푸름이 상자 시뮬레이터 — 설계

- 날짜: 2026-10-22
- 목적: 디지털다락방 숏츠 영상. "AI 푸름이가 상자에 들어가는 법을 스스로 배우는 과정"을 보여준다.
- 배경: CONNECT AI LAB 3주차 강의(무조코·강화학습·보상 설계)를 루카가 직접 해보기.

## 1. 세상 (MuJoCo)
- 바닥: 체크 무늬 평면.
- 상자: 갈색 종이 상자, 바닥 + 낮은 벽 4면, 위 개방. 벽 높이는 푸름이 키의 약 절반 → 점프해야 넘을 수 있음.
- 푸름이: 회색(러시안블루) 몸통 구 + 머리 구 + 세모 귀 2 + 노란 눈 2 + 꼬리 캡슐. 다리 없음(장난감처럼 미끄러짐).
- 에피소드 시작마다 푸름이·상자 위치를 조금씩 랜덤화.

## 2. 행동 (연속 3개, 범위 -1~1)
- 앞뒤 밀기(몸 방향 기준 힘), 좌우 회전(토크), 점프(바닥에 닿아 있을 때 0.5 이상이면 위로 힘).
- 몸이 뒤집히지 않도록 기울기는 막는다(위쪽 고정).

## 3. 관찰 (AI가 보는 정보)
- 상자 기준 푸름이 상대 위치(x, y), 몸 방향(cos, sin), 속도(x, y, z), 높이, 바닥 접촉 여부, 상자 안에 있는지.

## 4. 보상
- 상자 중심까지 거리가 줄어든 만큼 + (거리 셰이핑).
- 상자 안 바닥에 착지하면 +100, 에피소드 종료.
- 점프 1회마다 -0.05 (점프 남발 방지).
- 시간 제한: 약 10초(시뮬레이션 기준) 넘으면 종료.

## 5. 학습
- stable-baselines3 PPO, CPU, 병렬 환경 8개. 목표 10~30분.
- 체크포인트: 학습 0(무작위), 중간 여러 지점, 최종 저장.
- 성공 기준: 최종 모델이 무작위 시작 20회 중 15회 이상 상자 진입.

## 6. 영상
- 체크포인트별로 오프스크린 렌더링(세로 1080×1920, 30fps) → ffmpeg로 이어 붙임.
- 구성: 1번째 도전(벽에 쿵) → 중간(거의 다 옴) → 마지막(깡충, 쏙). 회차 숫자 라벨만 얹고, 나머지 글자는 루카와 정함.

## 7. 파일
- `tools/pureum-box-sim/` — `pureum_env.py`(세상+규칙), `train.py`, `render_video.py`, `requirements.txt`, `README.md`(루카용 실행법).
- 학습 결과·영상은 git에 넣지 않음(`.gitignore`).

## 8. 안 될 때
- 30분 학습 후 성공률 낮으면: 벽 높이를 낮춰 시작해 점점 높이는 커리큘럼.
- 그래도 실패하면 실패 과정 자체를 콘텐츠로 사용.
