# 「쑥쑥! 혁신제품」 설계서

- 날짜: 2026-10-19
- 목적: 2026 조달청 AI 게임·콘텐츠 공모전 **AI 게임 부문** 출품 (마감 11/22, 이메일 접수)
- 요강 정리: `docs/공모전/조달청_AI게임콘텐츠_2026/요강정리.md`
- 기반: 다락방 합체 게임 `landing/merge/` (Matter.js 물리 + 11단계 진화 + 콤보 점수) — **복사해서 새 게임으로**, 원본은 건드리지 않음

## 1. 한 줄 소개 (신청서용, 50자 이내)
작은 아이디어를 합쳐 혁신제품으로 키워 세계로 보내는 조달 합체 퍼즐

## 2. 심사 기준과 설계 연결
| 심사 항목 | 배점 | 설계에서 대응 |
|---|---|---|
| 주제적합성 | 20 | 11단계가 실제 혁신제품 제도 흐름(혁신시제품 → 혁신제품 지정 → 혁신장터·나라장터 → 시범구매 → 확산 → G-PASS 수출) |
| 활용도 | 20 | 공공 홍보물 톤 플랫 일러스트, 웹 주소로 바로 공유 가능, 도감 카드가 그대로 카드뉴스 소재 |
| 독창성 | 15 | 정책 흐름을 "합체 진화"로 표현 |
| 작품성(재미·조작 용이성·교육 효과) | 15 | 검증된 합체 손맛 + 한 손 조작 + 도감 카드 |
| 대중성 | 15 | 규칙은 "같은 거 둘 합치기" 하나, 쉬운 말 |
| 완성도 | 15 | 시작·게임·카드·결과 화면, PC/모바일, 오프라인 실행 |

## 3. 진화 11단계 + 도감 카드
1~5단계만 떨어짐. 같은 단계 둘이 닿으면 다음 단계. 11단계끼리 합치면 보너스와 함께 사라짐.

| # | 이름 | 도감 카드 문구 ("알쓸조달") |
|---|---|---|
| 1 | 💡 아이디어 | 모든 혁신은 작은 생각 하나에서 시작해요. |
| 2 | 📝 설계도 | 생각을 그림과 숫자로 옮기면 만들 수 있는 계획이 돼요. |
| 3 | 🔧 시제품 | 처음 만든 물건이에요. 조달청은 기술이 뛰어난 시제품을 '혁신시제품'으로 뽑아 공공기관이 써 볼 수 있게 도와요. |
| 4 | 🧪 시험·인증 | 안전하고 품질이 좋은지 꼼꼼히 검증받아요. 믿고 쓸 수 있어야 공공기관이 살 수 있으니까요. |
| 5 | 🏭 우리 동네 기업 제품 | 중소기업이 만든 진짜 제품이 탄생했어요! |
| 6 | ⭐ 혁신제품 지정 | 조달청이 기술력을 인정하면 '혁신제품'이 돼요. 공공기관이 입찰 없이 바로 살 수 있고, 지정 기간은 3년(최대 6년)이에요. |
| 7 | 🛒 나라장터 등록 | 나라장터는 공공기관이 물건을 사는 온라인 장터예요. 7만여 공공기관과 60만여 기업이 이용해요. |
| 8 | 🏫 첫 공공 납품 (시범구매) | 조달청이 혁신제품을 사서 학교·병원·소방서 같은 기관에 주면, 현장에서 직접 써 보며 성능을 확인해요. |
| 9 | 🏢 전국 공공기관으로 | 검증된 제품은 전국 공공기관으로 퍼져요. 우리나라 공공구매는 한 해 238조 원 규모예요. |
| 10 | 🌏 해외 수출 | 조달청은 경쟁력 있는 기업을 'G-PASS 기업'으로 뽑아 해외 공공조달 시장 진출을 도와요. |
| 11 | 🏆 K-혁신 대표기업 | 작은 아이디어가 세계적인 기업이 됐어요! 공공조달은 혁신기업의 디딤돌이에요. |

근거(2026-10 기사, 네이버 뉴스 검색): 혁신제품 수의계약·3년/최대 6년(큐빅 DTS 지정 기사 10-07), 혁신시제품 3년 혁신장터 수의계약(유니온바이오메트릭스 10-01), 시범구매 정의(혁신제품 시범구매 결과보고 기사 10-18), 나라장터 7만 수요기관·60만 기업(10-08), 연 238조 공공구매력(조달의 날 기사 09-30), G-PASS 정의(KG케미칼 선정 기사 09-29).
→ 접수 전 조달청 공식 누리집(pps.go.kr)과 한 번 더 대조.

## 4. 화면 흐름
1. **시작 화면**: 제목 「쑥쑥! 혁신제품」, 부제 "아이디어를 합쳐 세계로!", [시작] [도감] 버튼, 최고 점수
2. **게임 화면**: 통 + 다음에 떨어질 단계 미리보기 + 점수·콤보 + 11단계 진화표(작은 아이콘 줄)
3. **도감 카드 팝업**: 이번 판이 아니라 **처음** 만든 단계일 때만. 게임을 잠깐 멈추고 카드 표시 → 탭/클릭하면 닫히고 재개. 2초 후 자동으로 닫히지 않음(읽을 시간 보장).
4. **결과 화면**: "당신의 아이디어는 ○○까지 자랐어요!" (이번 판 최고 단계 아이콘·이름) + 점수 + 모은 카드 수(○/11) + [다시하기] [도감]
5. **도감 화면**: 11칸, 모은 카드는 그림·문구, 못 모은 칸은 실루엣과 "?"

## 5. 구성 (파일)
새 폴더 `landing/ssukssuk/` — 다락방 합체 파일 구조를 그대로 따름

| 파일 | 역할 | 다락방 합체 대비 |
|---|---|---|
| `ssuk-core.js` | 단계 데이터(이름·이미지·크기·점수·카드 문구), 점수 계산 — 순수 함수, Node 테스트 가능 | merge-core.js 복사 후 STAGES 교체, 카드 문구 필드 추가 |
| `ssuk-core.test.mjs` | 점수·확률·단계 데이터 무결성 테스트 | 기존 테스트 이식 + 11단계 모두 문구·이미지 있는지 |
| `ssuk-game.js` | Matter.js 물리, 떨어뜨리기, 합체, 게임오버 판정, "첫 달성" 이벤트 발생 | merge-game.js 복사, 랭킹 제거, 첫 달성 콜백 추가 |
| `ssuk-ui.js` | 시작·HUD·카드 팝업·결과·도감 화면 | merge-ui.js 복사 후 화면 재구성 |
| `ssuk-store.js` | 최고 점수·모은 카드·소리 설정 localStorage 저장 (try/catch, 실패해도 게임은 동작) | 신규 (merge-ui.js의 저장 함수들을 분리) |
| `index.html` | 화면 뼈대, 스크립트 로드(**상대 경로**) | 신규 |
| `vendor/matter.min.js` | Matter.js 0.20.0 로컬 사본 (MIT 라이선스 파일 동봉) | CDN 대신 로컬 |
| `img/stage01.png`~`stage11.png` | 원형 배지 일러스트 11장 | 힉스필드 Nano Banana 2 생성 |

**상대 경로 필수**: ZIP을 풀어 `index.html`을 더블클릭(`file://`)해도 동작해야 함 → 모든 경로 `./...`, 외부 요청 없음, 서버·워커 의존 없음.

## 6. 그림
- 11단계 원형 배지, 귀여운 플랫 일러스트, 밝은 공공 홍보물 톤, 단계마다 색이 확실히 다르게
- 투명 배경 PNG, 정사각 512px 이상, 글자 없음(이름은 화면 글자로 표시)
- 같은 스타일 유지: 1장을 먼저 만들어 기준으로 삼고 나머지는 그 그림을 참고 이미지로
- 조달청 로고·CI는 쓰지 않음 (공식 자료 제공 없음)
- 예산 약 22~30크레딧 (잔액 84)

## 7. 저장 데이터
- `ssuk.best` (최고 점수), `ssuk.cards` (모은 단계 번호 배열), `ssuk.sound` (on/off)
- localStorage 접근 실패(시크릿 창·file:// 제한) 시 메모리에만 두고 계속 진행
