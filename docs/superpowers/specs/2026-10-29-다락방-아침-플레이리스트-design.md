# 다락방 플레이리스트 시험판 — 「다락방의 느긋한 아침」

2026-10-29 승인. 참고: Groove Palette Cafe의 AI 재즈힙합 플레이리스트(그림 한 장 + 파형 + 가사 자막, 1개월 135만 회).

## 목표
디지털다락방 채널(@metaluca8563)에 약 20분짜리 플레이리스트 시험판 1편을 올려 반응을 본다. 반응이 좋으면 장면만 바꿔 시리즈화하고, 전용 채널로 키울지 정한다.

## 화면
- 다락방 창으로 아침 햇살, 6인(루카·루나·노바·푸름이·루릭·주주야)이 헤드폰 끼고 방 안 여기저기서 쉬는 장면. 참고 채널처럼 한 줄로 세우지 않는다.
- 캐릭터 원본(attic-cards 6장)을 참조로 힉스필드 나노바나나 → 후보 2~3장 → 루카가 고름.
- 움직임: 힉스필드 사진→영상 5~10초 반복. 어색하면 ffmpeg 천천히 확대·살짝 흔들기로 대체.

## 음악
- 아보카도 Popcorn 3.0 Pro(245cr/곡, 가사 필수), 영어 가사 재즈힙합 6곡.
- 1곡 먼저 생성 → 루카 청취 → 통과하면 나머지 5곡. 가사는 클로가 초안, 루카 확인 후 제출.
- 예상 약 1,470cr (시작 잔액 4,347).

## 합치기
- 반복 영상 + 6곡 연결 + 하단 파형 + 가사 자막 + 설명란 타임스탬프, ffmpeg.
- 썸네일: 장면 한 장 + 큰 글자.

## 올리기
- 업로드는 루카 직접. 클로는 제목·설명·타임스탬프 문구 준비. 'AI 생성 콘텐츠' 표시 켬.
- 유튜브 반복·대량생산 콘텐츠 정책 대비: 편마다 그림·컨셉을 다르게.
