# 3D 에이전트 사무실 「디지털 다락방」 설계

- 날짜: 2026-10-25
- 계기: CONNECT AI LAB 영상(블렌더 MCP로 3D 세트장 만들기)을 보고, 기존 픽셀 사무실(`tools/ai-office`)을 3D 웹 사무실로 키우기로 함
- 최종 목표: 온라인 주소(`vaulted-bus-346411` 의 `/office`)에 들어가면 3D 다락방 사무실에서 에이전트 7명이 **실제 상태대로** 일하고·쉬고·자는 모습이 보인다

## 이번 차수 범위 (루카 결정, 10-25)

> "일은 나중에, 일단 건물 안 책상 세팅부터"

**이번에 하는 것 = 1차: 건물과 책상 세팅**
1. 블렌더 설치 + blender-mcp로 클로드 코드와 연결
2. 블렌더에서 사무실 방(건물 내부) 만들기
3. 책상 7개를 배치하고 각자 설정표 소품 올리기
4. 렌더 사진으로 루카 확인 → GLB로 내보내기

**나중 차수 (이 문서에 방향만 기록)**
- 2차: 캐릭터 7명 모델 + 웹(Three.js) 사무실에 올리기, 가짜 상태로 동작 확인
- 3차: 미니PC 상태 보고원 + 공용 워커 연결 → 진짜 상태로 움직이기
- 후보: 사무실에서 에이전트에게 일 시키기, 새 프로필 반영, 픽셀 우편함 분류기 3D 이식

기존 픽셀 사무실 `tools/ai-office/` 는 그대로 둔다. 3D는 새 폴더 `tools/ai-office-3d/`.

## 사무실 배치 (1차에서 만드는 것)

벽 두 개를 잘라낸 방 단면, 비스듬히 내려다보는 시점.

- **뒷벽:** 창문, `DIGITAL ATTIC` 간판, 상태 전광판(1차는 빈 판)
- **헤르미 팀 구역:** 헤르미·주주야 책상 붙여서
- **루나 책상:** 헤르미 팀 옆, 노바와 이웃. 루나 → 헤르미 책상으로 가는 통로 비워둠(보고 장면용)
- **노바 책상:** 루나 옆, 대시보드 벽 앞
- **개발·기획 구역:** 푸름이·루릭·CLO 책상 나란히
- **쉼터:** 소파, 쿠션 2개(나중에 쉼/잠 상태용)
- **소품:** 화분, 나무 바닥

책상마다 의자 1개와 위 표의 소품. 캐릭터가 앉을 자리(의자 위치)는 2차에서 쓰도록 이름 붙여 둔다.

## 1차 제작 흐름

1. **블렌더 설치:** `winget` 공식 패키지. 무료 오픈소스.
2. **MCP 연결:** blender-mcp(오픈소스). 블렌더에 애드온 설치, 클로드 코드에 `blender` MCP 등록(`uvx` 사용, 이미 설치됨). 사용 통계 전송 기능이 있으면 끄고, 유료 3D 생성 연동(Hyper3D 등)은 끈다.
3. **모델링:** 방 → 가구 → 책상별 소품 순. 단계마다 렌더 사진을 뽑아 루카 확인 후 다음으로.
4. **내보내기:** 웹용 GLB. 1차 목표 용량 5MB 이하(캐릭터 들어간 최종은 10MB 이하, 폰에서 열리게).
5. **이름 규칙:** 블렌더 객체 이름에 자리 주인을 붙인다 (`desk_hermi`, `seat_hermi`, `prop_hermi_magnifier` …). 2·3차에서 웹 코드가 이 이름으로 찾는다.

파일 위치:
```
tools/ai-office-3d/
  blender/   office.blend (원본)
  renders/   확인용 렌더 사진
  web/       office.glb (2차에서 페이지 추가)
```

## 나중 차수 방향 (요약)

**2차 웹 사무실:** Three.js로 GLB를 띄우고 마우스로 회전·확대. 캐릭터는 도형 클레이 인형, 클릭하면 설정표 카드. 상태별 동작: 일함=자기 책상에서 고유 동작, 쉼=쉼터 소파, 잠=쿠션에서 Zzz.

**3차 상태 연결:**
```
미니PC 상태 보고원 ─(1분마다, 상태만)→ 공용 워커 /office/status ←(읽기)─ 웹 사무실
```
- 판정: 일함(최근 5분 활동) / 쉼(켜져 있고 한가) / 잠(꺼짐·고장)
- 오픈클로 3명: 게이트웨이 생존·채널 상태 + `agents/<id>/sessions` 갱신 시각
- 헤르미: 헤르메스 `gateway_state.json` (실행 중·텔레그램 연결·active_agents)
- 루나: 헤르메스 「루나」 이름 예약 작업 실행 여부, 텔레그램 배달 시 보고 장면
- 노바: `~/.codex/sessions` 갱신 시각 / CLO: 클로드 코드 대화 기록 갱신 시각
- 오픈클로 `nova`(카톡봇)는 읽지 않음
- 보고원은 읽기만, 내용·경로는 안 보냄, 워커 쓰기는 비밀 열쇠(환경변수/워커 시크릿)
- 10분간 보고 없으면 사무실 "퇴근 시간 🌙"

- [ ] 블렌더 설치되고, 클로드 코드에서 blender MCP 도구로 블렌더 장면을 조회·수정할 수 있다 (실제 호출로 확인)
- [ ] 방 + 책상 7개 + 소품 + 쉼터가 들어간 렌더 사진을 루카가 OK 했다

- [ ] `office.glb` 가 5MB 이하이고, 웹 GLB 뷰어에서 열린다
- [ ] `office.blend`, 렌더, GLB가 커밋되어 있다

캐릭터 모델, 웹 페이지, 움직임, 상태 보고원·워커, 배포.
