# 3D 에이전트 사무실 「디지털 다락방」 설계

- 날짜: 2026-10-25
- 계기: CONNECT AI LAB 영상(블렌더 MCP로 3D 세트장 만들기)을 보고, 기존 픽셀 사무실(`tools/ai-office`)을 3D 웹 사무실로 키우기로 함
- 최종 목표: 온라인 주소(`vaulted-bus-346411` 의 `/office`)에 들어가면 잔디 섬 위 「디지털 다락방」 집에서 에이전트 7명이 **실제 상태대로** 일하고(사무실 책상)·쉬고(앞마당 데크 카페)·자는(다락방) 모습이 보인다

## 이번 차수 범위 (루카 결정, 10-25)

> "일은 나중에, 일단 건물 안 책상 세팅부터" / "앞마당은 데크 카페, 책상은 사무실 안에 — 노트북 설치하고 일하는 모습"

**이번에 하는 것 = 1차: 건물과 책상 세팅**
1. 블렌더 설치 + blender-mcp로 클로드 코드와 연결
2. 블렌더에서 네모 블록 받침(길모퉁이) + 3층 다락방 집 + 앞마당 데크 카페 + 연못 정원 만들기
3. 집 안 사무실 층에 책상 7개(전원 노트북)와 설정표 소품 세팅
4. 렌더 사진(바깥 모습 / 앞벽 걷어낸 안 모습)으로 루카 확인 → GLB로 내보내기

**나중 차수 (방향만 기록)**
- 2차: 캐릭터 7명 모델 + 웹(Three.js) 사무실, 가짜 상태로 동작 확인
- 3차: 미니PC 상태 보고원 + 공용 워커 연결 → 진짜 상태로 움직이기
- 후보: 사무실에서 에이전트에게 일 시키기, 새 프로필 반영, 픽셀 우편함 분류기 3D 이식, 실제 시간에 맞춘 낮/밤

기존 픽셀 사무실 `tools/ai-office/` 는 그대로 둔다. 3D는 새 폴더 `tools/ai-office-3d/`.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 분위기 | 네모 블록 받침 위 로우폴리 다락방 집 + 길모퉁이 미니어처(루카 참고 이미지 2장, 10-25) + 말랑 클레이 캐릭터. 노을/저녁 조명, 창문 불빛 |
| 건물 | 유리 타워 아님. 3층 집 + 박공지붕 다락(동그란 창) |
| 3D 제작 방식 | A안: 섬·집·가구는 블렌더 MCP + 블렌더 파이썬 스크립트로 도형 조합 제작. **캐릭터만 10-25 변경**: 도형 찰흙 인형이 설정표와 너무 안 닮아서(루카 "너무 찰흙인형") 허깅페이스 이미지→3D로 — 설정표 → FLUX.1-Kontext 앉은 그림 → TRELLIS GLB → `prep_models.py` 로 줄여 `web/characters/char_<이름>.glb` (office.glb 와 따로). 모델 파일이 없으면 찰흙 인형으로 대신함 |

| 상태 | 처음부터 진짜 상태 연결이 목표(3차). 공개는 일함/쉼/잠만 |

## 섬과 집 배치 (1차에서 만드는 것)

좌표: 받침 중심 (0,0), 카메라는 남쪽(-y) 앞에서 비스듬히 내려다봄. 단위 m.

- **네모 블록 받침 (루카 결정 10-25, 코너 가게 미니어처 참고):** 22×22 잔디 블록. 앞(남쪽)과 오른쪽(동쪽) 가장자리에 차도+인도가 만나는 **길모퉁이**, 횡단보도 2개, 전봇대 3개와 전깃줄, 자전거. 나무 8그루, 집 앞 길, 가로등 2개
- **집 앞 디테일:** 1층 창문 위 차양(참고 이미지)
- **연못 정원 (마당 왼쪽, 데크 카페 맞은편):** 둥근 연못(물), 돌 테두리, 연잎 몇 장, 갈대, 작은 벤치 (루카 요청 10-25)
- **집:** 가로 8 × 세로 6 (x -4~4, y -1.5~4.5), 층 높이 3, 4층 + 다락 (1~3층 사무실, 4층 춤 연습실)(박공지붕, 앞 박공에 동그란 창, 굴뚝). 앞벽 1층 가운데 문, 문 위에 `DIGITAL ATTIC` 간판. 창문은 따뜻한 불빛
- **층별 사무실 (책상은 모두 뒷벽을 등지고 앞쪽을 보게 → 캐릭터 얼굴과 노트북 뒷면 로고가 보임)**
  - 1층 비서실: 헤르미, 주주야
  - 2층 전략실: 노바, 루나 (노바 뒷벽에 대시보드)
  - 3층 개발·기획실: 푸름이, 루릭, CLO (루릭 뒷벽에 포스트잇 보드)
- **본관 4층 = 춤 연습실 (루카 요청 10-25):** 거울벽, 발레 바, 스피커, 미러볼, 색 조명
- **다락 = 밴드 연습실 「다락방 밴드」:** 드럼, 기타, 베이스, 키보드, 앰프, 마이크
- **숙소동 = 잠자는 곳:** 본관 왼쪽 뒤 3층 작은 건물, 개인 방 7개(1층 헤르미·주주야·루나, 2층 노바·푸름이, 3층 루릭·CLO). 방마다 침대(각자 색 이불)·협탁 조명·러그, `sleep_<이름>` 자리. 앞벽 `dorm_front_` 는 숨김용
- **앞마당 데크 카페 = 쉬는 곳:** 나무 데크, 파라솔 테이블 3개, 카페 카운터, 쉬는 자리 7개 (`rest_<이름>`)

층 배정은 루카 확인 전 초안이다. 자리 좌표는 `desks.py` 의 표 한 곳에만 있어 바꾸기 쉽다.

## 이름 규칙

블렌더 객체 이름은 아래 머리말로만 시작한다 (2·3차 웹 코드가 이 이름으로 찾음).

| 머리말 | 뜻 |
|---|---|
| `island_` | 받침 블록, 나무, 길, 가로등, 길모퉁이(차도·인도·횡단보도·전봇대·전깃줄·자전거), 연못 정원(`island_pond_`) |
| `house_` | 집 본체. 그중 `house_front_` 는 웹에서 숨길 앞벽·앞창·문·간판·앞 박공 |
| `attic_` | 다락(지붕, 굴뚝) |
| `studio_dance_`, `studio_band_` | 4층 춤 연습실, 다락 밴드 연습실 |
| `dorm_` | 숙소동. 그중 `dorm_front_` 는 웹에서 숨길 앞벽, `dorm_room_<이름>_` 은 개인 방 |
| `deck_` | 앞마당 데크 카페 |
| `desk_<이름>`, `chair_<이름>_…`, `prop_<이름>_…` | 책상, 의자, 소품 |
| `seat_<이름>` / `rest_<이름>` / `sleep_<이름>` | 일할 자리 / 쉴 자리 / 잘 자리 (빈 표시 물체) |
| `cam_`, `light_` | 카메라, 조명 |

`<이름>` = `hermi`, `jujuya`, `luna`, `nova`, `pureum`, `rurik`, `clo`

## 1차 제작 흐름

1. **블렌더 설치:** `winget` 공식 패키지. 무료 오픈소스.
2. **MCP 연결:** blender-mcp(오픈소스). 블렌더에 애드온 설치, 클로드 코드에 `blender` MCP 등록(`uvx`). 사용 통계 전송이 있으면 끄고, 유료 3D 생성 연동(Hyper3D 등)은 끈다.
3. **모델링은 파이썬 스크립트로:** `tools/ai-office-3d/blender/*.py` 가 장면 전체를 만든다(다시 돌리면 똑같이 나옴). 블렌더 MCP로는 열린 블렌더에서 같은 스크립트를 돌리고 화면을 보며 다듬는다.
4. **확인:** 단계마다 렌더 사진(바깥/안)을 뽑아 루카 확인. 검사 스크립트가 이름 규칙·필수 객체·GLB 용량을 확인.
5. **내보내기:** `web/office.glb`, 1차 5MB 이하.

파일 위치:
```
tools/ai-office-3d/
  blender/   build_office.py, check_office.py, lib.py, island.py, house.py, deck.py, desks.py, props.py, office.blend
  renders/   office_outside_<버전>.png, office_inside_<버전>.png
  web/       office.glb, check-viewer.html (GLB 열리는지 확인용)
  vendor/    blender-mcp 애드온 파일
```

## 나중 차수 방향 (요약)

**2차 웹 사무실:** Three.js로 GLB를 띄우고 회전·확대, 집 클릭하면 앞벽이 사라지며 안으로. 캐릭터는 도형 클레이 인형, 클릭하면 설정표 카드. 일함=`seat_` 에서 노트북 타닥, 쉼=`rest_` 데크 카페, 잠=`sleep_` 숙소동 자기 방 침대 Zzz. 후보: "놀이" 상태(예: 루릭 음악 작업 → 밴드실, 춤 연습실)는 2·3차에 규칙 정함.

**3차 상태 연결:**
```
미니PC 상태 보고원 ─(1분마다, 상태만)→ 공용 워커 /office/status ←(읽기)─ 웹 사무실
```
- 판정: 일함(최근 5분 활동) / 쉼(켜져 있고 한가) / 잠(꺼짐·고장)
- 오픈클로 3명: 게이트웨이 생존·채널 상태 + `agents/<id>/sessions` 갱신 시각
- 헤르미: 헤르메스 `gateway_state.json` (실행 중·텔레그램 연결·active_agents)
- 루나: 헤르메스 「루나」 이름 예약 작업 실행 여부, 텔레그램 배달 시 루나→헤르미 보고 장면
- 노바: `~/.codex/sessions` 갱신 시각 / CLO: 클로드 코드 대화 기록 갱신 시각
- 오픈클로 `nova`(카톡봇)는 읽지 않음
- 보고원은 읽기만, 내용·경로는 안 보냄, 워커 쓰기는 비밀 열쇠(환경변수/워커 시크릿)
- 10분간 보고 없으면 "퇴근 시간 🌙"
- 후보: 창문 불빛으로 층별 상태 표시
