# 기능 지도 — 다락방 머지 (/merge)

> AI가 "이 버튼 이상해" 한마디나 스크린샷 한 장만 받아도 바로 찾아가고, 고친 뒤 같은 길로 눌러 확인하라고 만든 안내서.
> 코드를 바꾸면 이 문서도 같이 고친다. (기준: 2026-10-29)

- 실주소: https://vaulted-bus-346411.web.app/merge (끝 슬래시 없음)
- 코드: `landing/merge/` — 화면 뼈대·스타일 `index.html`, 숫자·규칙 `merge-core.js`, 물리·그리기·소리 `merge-game.js`, 화면 전환·랭킹·공유 `merge-ui.js`
- 랭킹 서버: 공용 워커 `docs/worker/merge-rank.js` (라우팅은 `docs/worker/worker.js`의 `/merge/rank`), 저장소 KV `MERGE_RANK`의 키 `top` 하나
- 이미지: `landing/merge/img/*.png` 11장 + 공유 표지 `og.png`

## 화면 흐름

```
시작 화면 ──시작!──▶ 플레이 ──(경계선 위 1.5초)──▶ 결과 ──다시하기──▶ 플레이
   │                                              │
   └──🏆 랭킹──▶ 랭킹 화면 ◀──🏆 랭킹───────────────┘
                 └─닫기─▶ 온 곳으로 돌아감
```

화면 4개는 전부 `index.html`의 `<section id="screen-…">`이고, `merge-ui.js`의 `show(name)`이 `.show` 클래스를 붙였다 뗐다 하며 전환한다.

## 2. 플레이 화면 `#screen-play`

**위쪽 HUD `#hud`**
- 왼쪽 점수 `#hud-score`: 위험 상태면 빨간색(`#screen-play.danger`)
- 가운데 콤보 `#hud-combo`: 2콤보부터 "N콤보 ×배율"
- 오른쪽 NEXT `#hud-next`: 다음에 떨어질 캐릭터

**게임판 `<canvas id="game">`**: 논리 크기 400×640, 폰 화면에 맞춰 늘이고 줄임(`fitCanvas()`)
- 손가락이나 마우스를 좌우로 움직이면 위쪽 캐릭터와 점선 조준선이 따라온다. **손을 떼면 떨어진다.** (`merge-game.js` 입력 부분 `onMove / onDown / onUp`)
- 떨어뜨린 뒤 0.5초 동안은 다시 못 떨어뜨린다(`dropLockMs`)
- 같은 캐릭터 둘이 닿으면 합체해서 한 단계 위 캐릭터가 된다(`merge()`). 전설 루카 둘이 닿으면 둘 다 사라지고 +100점
- 위쪽 흰 점선 = 경계선(y=120). 떨어진 지 0.8초 넘은 캐릭터가 선 위로 삐져나온 채 1.5초 지나면 게임 끝. 위험할 땐 선이 빨갛게 깜빡이고 "둥" 소리가 난다(`checkDanger()`)
- 게임이 끝나면 벽과 바닥이 사라지며 와르르 무너지는 연출, 0.9초 뒤 결과 화면

**연출**
| 언제 | 무엇이 | 코드 |
|---|---|---|
| 합체할 때마다 | 색 파티클 터짐 + 화면 흔들림 + 도레미 음(단계가 높을수록 높은 음) | `burst()`, `sfxMerge()` |
| 2콤보 이상 | 판 가운데 "×1.25 COMBO 2" 같은 노란 글자 | `merge()` 안 `popups` |
| 5콤보 이상 | 화면 테두리가 노랗게 펄럭(피버) + 팡파레 | `#fever-frame.on`, `sfxFever()` |
| 루나(5단계) 이상을 이 판에서 처음 만들 때 | 0.7초 슬로모션 + 아래쪽 흰 말풍선 "OO 등장! 대사" 1.4초 | `slowMo()`, `merge-ui.js` `charPopup()`·`LINES` |

## 4. 랭킹 화면 `#screen-rank`

| 화면 문구 | 원인 | 코드 |

## 손맛 조절 손잡이 (숫자만 바꾸면 됨)

| 바꾸고 싶은 것 | 어디 | 지금 값 |
|---|---|---|
| 콤보가 이어지는 시간 | `merge-core.js` `comboWindowMs` | 1500ms |
| 콤보 최대 배율 | `maxMultiplier` (콤보당 +0.25배) | 3배 |
| 경계선 위에서 버티는 시간 | `dangerHoldMs` | 1500ms |
| 연속 낙하 간격 | `dropLockMs` | 500ms |
| 떨어지는 속도(중력) | `merge-game.js` `gravity: { y: 1.6 }` | 1.6 |
| 통 크기·경계선 높이 | `merge-game.js` `W, H, DANGER_Y` | 400×640, 120 |
| 통통 튀는 정도 | `makeBall()` `restitution` | 0.15 |
| 등장 말풍선 대사 | `merge-ui.js` `LINES`, 게임오버 대사 `RURIC_OVER` | — |

⚠️ 점수 숫자(`STAGES[].score`, `legendBonus`, `maxMultiplier`)를 바꾸면 **워커 `merge-rank.js`의 같은 숫자도 함께 바꾸고 워커를 다시 배포**해야 한다. 안 그러면 정상 점수가 `score_over_cap`으로 튕긴다. (워커 테스트가 두 숫자가 같은지 검사함)

   - 상태 엿보기: `MergeUI._game().state` → 점수·콤보·단계별 합체 횟수·발견한 캐릭터

3. **배포**: `firebase deploy --only hosting`. js는 캐시를 안 하게 설정돼 있어서 바로 반영된다. 실주소에서 한 번 더 확인

## 알아둘 함정

- `/merge`는 끝 슬래시 없이 열리니까 스크립트·이미지 경로는 꼭 `/merge/...` 절대 경로로 쓴다
- 물리는 타이머로, 그리기는 화면 새로고침 주기(rAF)로 돈다. 탭을 숨기면 물리도 멈추고(시간이 쌓이지 않음), 다시 보면 이어진다
- 캔버스는 폰 해상도 배율(최대 3배)로 그린다. 흐릿해지면 `fitCanvas()`부터 본다
- 말풍선은 `word-break:keep-all`로 단어 중간 줄바꿈을 막았다(10-13 "등/장!" 사건)
- 물리 엔진은 외부 Matter.js 0.20.0 (cdnjs)
- `index.html`의 `basapal-verify` 메타 태그는 바사팔 등록 인증용이니 지우지 않는다
