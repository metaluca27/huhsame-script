편지를 보내면 판단 AI가 한 질문씩 차례로 판단하는 과정이 여기 보여요.

👑 대표님 결정 필요

질문 → 대답에 따라 행동(부서)으로 가거나 다음 질문으로 이어져요. 확신이 기준보다 낮으면 어느 단계에서든 👑 대표(루카)에게 가요. 주황 테두리는 마지막 편지가 지나간 길이에요.

🧑‍💼 부서(행동) — 하나 추가할 때마다 사무실에 책상과 직원이 생겨요

💾 설정 저장

설정은 이 브라우저에 자동 저장돼요.
시간편지질문별 대답 (확률)처리시간맞았나요?

💡 왜 이렇게 설계했나

  • 첫 질문은 "어떤 메시지?" 하나로 크게 나눠요. 루카 우편함에 오는 건 질문·문제 신고·응원·제안·스팸 다섯 갈래예요. 판단 AI는 갈래가 적고 설명이 또렷할수록 잘 맞혀요.
  • 질문이면 → "무엇에 대한 질문?" 허허서방 야담, 강의·전자책, 앱·게임은 대답하는 사람(부서)이 달라서 한 번 더 나눠요.
  • 문제 신고면 → "돈이 걸렸나?" (예/아니오) 결제·환불은 실수하면 안 되니까 결제 지킴이에게 따로 보내고, 루카에게도 알림이 가는 부서로 잡았어요. 돈 얘기가 아니면 앱 수리공이 받아요.
  • 제안이면 → "얼마나 구체적?" (점수형) 실험해 보니 판단 AI가 "예산 50만원·11월"처럼 구체적인 제안과 뭉뚱그린 단체 메일을 잘 구분했어요. 구체적일수록 루카가 직접 봐야 하니 3단계 중 맨 위는 👑 대표 책상으로 바로 가요.
  • 스팸은 지우지 않고 "숨김 후보"로만. 작은 모델이라 스팸을 틀릴 때가 있어요(실험에서 광고를 질문으로 91% 확신한 적도 있어요). 그래서 삭제는 늘 사람이 해요.
  • 확신이 낮으면 무조건 👑 대표에게. 기본 기준은 0.5예요. 애매한 "감기 조심하세요!" 같은 인사는 확신이 낮게 나와서 대표 책상으로 와요. 대표가 고른 답은 그대로 학습 데이터가 돼요.

🧪 만들기 전에 실험해서 알아낸 것 (2026-10-07, 미니PC)

  • 편지는 한 줄 글로 보내요. [YouTube comment] 메시지 내용 형태요. 보낸 사람·제목·본문을 칸칸이 나눈 서류(JSON) 형태로 주면 거의 다 틀렸어요.
  • 질문은 한 번에 하나씩 물어요. 다섯 개를 한꺼번에 물으면 모두 "질문·야담"으로 쏠렸어요. 한 질문에 2.5초쯤 걸려서, 편지 하나에 보통 5초 안팎이에요.
  • 선택지 설명은 영어로 자세히. 짧은 설명보다 자세한 설명일 때 협찬 메일 판단이 68% → 99%로 올라갔어요. 화면엔 한국어, 판단 AI에는 영어 설명이 가요.
  • 점수형 질문의 확신도는 늘 낮게 나와요(0.05~0.35). 그래서 점수형은 "가장 높은 단계의 확률"을 확신도로 써요. "얼마나 급한가"는 거의 찍기 수준이라 뺐어요.

🔁 피드백으로 계속 강해지는 회사

  1. 내 회사 질문 정의 (🌳 판단 흐름 탭)
  2. 행동 저장 (모든 판단이 📋 일지에 남아요)
  3. 사람 피드백 — 👍 맞음 / 👎 틀림 + 정답 고르기, 👑 대표 결정
  4. JSON 데이터 — "학습 데이터 내보내기"
  5. 다시 학습 — 아래 두 가지가 이 화면 안에서 바로 일어나요.

🧠 강화학습은 이렇게 작동해요

  • 보상과 벌점. 👎를 누르고 정답 부서를 고르면, 판단 흐름에서 "AI가 간 길"과 "정답으로 가는 길"이 갈라진 질문을 찾아요. AI가 고른 선택지엔 벌점(−0.5), 정답 쪽 선택지엔 보상(+0.5)을 줘요. 👍는 지나온 길 전체에 작은 보상(+0.2)을 줘요. 👑 대표가 골라준 것도 똑같이 배워요.
  • 판단에 반영. 다음 편지부터는 "AI 확률 × e점수"로 다시 계산해요. 그래서 판단이 실제로 바뀌고, 사이드 패널에 "🧠 학습 반영: AI는 원래 ○○% → △△%"로 보여줘요.
  • 경험 기억. 사람이 정답을 정해준 편지와 글자가 55% 넘게 겹치면 그 정답을 따라가요. 같은 스팸이 반복될 때 특히 잘 통해요.
  • 솔직한 한계. 점수는 "질문별 버릇"이라 편지 내용과 상관없이 그 선택지를 전체적으로 밀어줘요. 너무 쌓이면 다른 편지까지 쏠릴 수 있어서 ±2.5에서 멈추고, 언제든 끄거나 초기화할 수 있어요. 판단 AI 모델 자체를 다시 훈련하는 건 아니에요. 그건 내보낸 JSON으로 나중에 할 일이에요.
